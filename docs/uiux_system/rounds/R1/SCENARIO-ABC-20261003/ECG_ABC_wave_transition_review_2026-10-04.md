## 1. 이번 단계와 아이디어의 위치

지금은 **A/B의 TUNE 수정과 C 초안 검토** 단계다. 파형·전환은 도입부 장식이 끝난 뒤에 붙이는 효과가 아니라 각 안의 핵심 사건이다. 따라서 아래 제안을 지금 검토하고, 채택한 아이디어를 해당 씬의 전·중·후 프레임에 반영한 뒤 시나리오와 제작 순서를 정한다. 제작 후에는 실제 구도의 약점을 출발로 새로운 2–3개를 추가 제안한다. 두 과정은 서로 대체하지 않는다.

아래 6개는 **기존 마이닝 결과와 후보 세계를 바탕으로 만든 독자 확장**이다. 새 사이트에서 실제 관찰한 효과라고 귀속하지 않는다. 좌표·각도·표본 수는 우리 초기 설계값이며 품질 검증값이 아니다. 기준은 1920×1080. `p`는 장면 진행률, `t`는 연속 신호 재생 시계다. 전환 내부의 `q=0→1`은 해당 p 구간을 정규화한 값이다.

공통 유지: 관찰 구간의 2.5초 창·심장/R 이벤트 동일 시계·입력의 낮은 앰버 명도·출력의 청록·sweep 소멸부 국소 fade·새 선의 짧은 잔광. 극적 전환 중 형상 변형은 허용한다. 정확 비교 화면에서는 별도의 실제 데이터 렌더러로 인계한다. 아래 배열·막·압인은 실제 알고리즘 내부나 계산 성능을 입증하지 않는다.

## 2. A — 서고의 깊이가 그래프와 처리 공간으로 이어진다

### A-W1 / A7 파형 전시: 서가의 수평선이 그래프의 깊이를 연다

**기존안 대비 새 점:** 격자를 그래프 뒤에 붙이는 수준에서, 서가의 수평선이 파형을 떠받치는 3개의 얕은 공간 면으로 연결되게 확장한다. 책장이 필터로 변하는 것은 아니다.

- **시작 구도:** 심장 중심 `(460,550)`, 높이 340px. 입력 파형은 `x930–1805,y365–755`. 뒤 서가의 세 수평선이 파형 면보다 어둡게 남는다. 제목은 `x940,y180`, 그래프와 다른 전경 면이다.
- **중간 프레임:** 카메라가 오른쪽으로 6–8° 돌아가면 수평선이 앞으로 연결된 얇은 격자 면의 옆모서리가 보인다. 가까운 파형 면, 40–60px 뒤로 보이는 잡음 설명층, 가장 뒤 격자가 겹친다. 잡음층은 입력에서 출력으로 바뀌기 전의 공간적 설명이며 정밀한 성분 분리가 아니다.
- **도착:** 카메라가 대부분 정면으로 돌아와 P-QRS-T와 심장이 함께 읽힌다. 격자 바닥은 화면 아래 `y760–850`에 작게 남아 깊이만 제공한다. 심장이 오른쪽 파형에 가려지지 않는다.
- **움직임:** 등장이 p에 따라 펼쳐지고, 열린 뒤에는 t로 sweep을 계속 재생한다. 포인터 이동에는 앞선이 조금, 뒤 격자가 더 적게 이동한다. 빛줄기로 파형을 덮지 않고 선의 자체 발광과 낮은 배경 밝기로 공간을 만든다.
- **TUNE 확인:** 세 면이 3개의 독립 ECG처럼 보이면 잡음층을 띠/점 형태로 낮추거나 없앤다. 그래프가 책장에 박힌 장식처럼 보이면 전극에서 오는 연결 경로를 더 일찍 노출한다.

### A-X1 / A8 전환: ‘표본 막’을 통과하는 입력

**기존안 대비 새 점:** 투명도 교차나 전체 입자 폭발 대신, 그래프 공간에 얇은 디지털 표본 막이 생기고 입력/처리/출력이 동시에 보이는 순간을 만든다.

- **q0:** 오른쪽 그래프 중앙 `x1350`에 세로 막의 얇은 옆면이 나타난다. 12–16개의 작은 직사각 셀이 높이 방향으로 빛나지만 긴 기법 설명은 없다. 막 아래 `디지털 처리` 18–20px.
- **q.35:** 입력 리본은 막 바로 앞에서 짧은 조각으로 나뉜다. 카메라는 오른쪽으로 약 10° 움직여 막 앞의 앰버, 셀의 깊이, 막 뒤의 청록을 한 구도에 보인다. 제거되는 설명 조각은 화면 뒤 아래로 물러나고 청록 조각은 저장 출력 형상으로 연결된다. 모든 입자를 화면 밖으로 폭발시키지 않는다.
- **q.70:** 막의 위치가 오른쪽으로 옮겨지며 출력 전시 영역이 넓어진다. 막 근처에만 작은 빛 반응을 주고 심장은 계속 가장 중요한 박동 광원으로 남긴다.
- **q1:** 막이 오른쪽 프레임 밖으로 나가고 청록 출력이 관찰 자리를 채운다. 별도의 저장 출력 렌더가 현재 t의 표본으로 이어받아 다음 박동에서 자연스럽게 sweep한다.
- **상태:** p가 멈추면 막의 위치/전환 비율은 정지하되 표본 흐름과 심장은 t로 계속된다. 역스크롤은 q를 되돌릴 뿐 t를 되감지 않는다. 다음 R을 기다리며 스크롤을 잠그지 않는다.
- **Story 적용:** PLI의 촘촘한 흔들림, BW의 저주파 들썩임, EMG의 짧은 burst는 막 앞에서 각기 다르게 보인다. 처리 장면 문법은 공유하고 원인 발견 구도는 유지한다.
- **문서 검토 판정:** 우선 시험 추천. 서고→그래프→디지털 처리의 연결이 있다. 막이 장벽/차단처럼 보이는 위험은 셀 통과와 출력을 동시에 보여 확인한다. 전체 A는 여전히 TUNE.

## 3. B — 종이의 물성이 신호를 드러내고 처리 공간을 연다

### B-W1 / B5 파형 전시: 종이에서 살짝 들리는 압인 선

**기존안 대비 새 점:** 공중 리본만 두는 대신 표면의 압인 흔적과 떠오르는 선 사이의 간격으로 깊이를 만든다. 레퍼런스의 실제 압인 효과를 복제했다는 주장은 없다.

- **시작:** 심장 `(520,550)`, 종이 `x850–1860,y260–820`. 종이에는 흐린 격자가 있고, 파형이 생성되는 위치의 얕은 압인 홈은 가까운 헤드 주변에서만 보인다. 종이 전체를 갈라진 조각으로 만들지 않는다.
- **중간:** 새 표본이 그려지는 헤드에서 앰버 선이 종이 표면에서 들어 올려진다. 접선광을 받는 홈과 선 사이로 좁은 그림자가 생기며, 카메라 12° 측면에서 간격이 읽힌다. 선은 종이 표면보다 10–20cm 앞이라는 기존 설계를 유지한다.
- **도착:** 활성 리본은 앞 면, 희미한 압인 흔적은 바로 뒤, 종이의 접힘은 더 뒤에 있다. 제목은 종이 상단 `x930,y135`의 큰 면으로 유지한다. 압인 흔적은 sweep 지움과 함께 사라져 두번째 ECG로 남지 않는다.
- **재생:** 홈은 전체 종이를 실시간 변형하는 대신 짧은 국소 normal/displacement 또는 화면 합성 시험으로 비교한다. 밝기는 선 헤드에 집중하고 종이의 따뜻한 색은 그대로다. 이 구현 방식은 제안이며 실제 종이 재질 시험이 필요하다.
- **TUNE 확인:** 고무/플라스틱 튜브처럼 보이면 리본 두께와 광택을 줄인다. 압인과 활성선이 서로 다른 타이밍을 보이면 같은 표본 시계로 다시 묶는다.

### B-X1 / B6–B7 전환: 접힌 뒤편의 ‘빛나는 등록 격자’

**기존안 대비 새 점:** 종이의 절개와 샘플 배열을 유지하면서, 종이 앞면·디지털 뒤편·복귀한 출력의 표면 위치가 정확히 겹치는 순간을 와우로 만든다.

- **q0:** 종이 가운데 `x1360`의 기존 틈이 열리며 카메라는 우측 3/4로 조금 돌아간다. 앞 종이 면에 앰버 입력, 뒤 `x1260–1510`에 어두운 디지털 격자의 일부가 보인다. 입력의 행 위치가 뒤 격자와 연결되어 갑자기 별개의 방이 생긴 느낌을 줄인다.
- **q.35:** 종이의 좁은 접힘 면이 지나가며 신호를 단위 조각으로 가린다. 각 조각은 뒤 격자에 정렬됐다가 청록 출력 조각으로 돌아온다. 종이 접힘의 가림은 p, 흐르는 파형은 t를 따른다. 종이 자체가 신호를 치료한다는 의미가 되지 않도록 뒤 처리 공간과 `디지털 처리` 표시가 먼저 읽힌다.
- **q.70:** 카메라가 조금 정면으로 돌아오면 앞 종이의 비어 있는 홈, 뒤 청록 선, 떠오르는 출력 조각이 같은 기록 자리에 겹쳐 보인다. 출력을 위해 종이 한 장을 갈아 끼우지 않는다.
- **q1:** 틈이 작아지고 출력은 앞 면의 동일 좌표 `x925–1800,y380–730`에서 재생된다. 뒤 격자의 빛은 접힘 이면에 잠깐 남았다가 사라진다. 출력에는 B-W1의 짧은 홈/잔광만 남긴다.
- **Story 적용:** 장을 넘기는 큰 종이 회전과 각 장의 작은 처리 틈을 구분한다. PLI/BW/EMG마다 전체 설치물을 다시 회전시키지 않는다. 모니터의 박동 흔적은 상태 보조이며 실제 계산 진행바가 아니다.
- **문서 검토 판정:** 우선 시험 추천. 종이의 기록성과 디지털 처리가 한 화면에 연결된다. A-X1과 비슷한 통과 방향이지만 B는 접힘/가림/등록 위치가 핵심이다. 틈이 단순 지퍼처럼 보이면 B2의 큰 공간 개방과 규모를 구별한다. 전체 B는 TUNE.

## 4. C — 파형 자체가 공간을 차지하고 처리 방향을 드러낸다

### C-W1 / C0–C2 파형 전시: 가장자리에서 보는 신호 단면

**기존안 대비 새 점:** 두꺼운 유광 리본에 카메라가 ‘그 안/그 옆’으로 접근하는 시점을 추가한다. 보기 좋은 표면에서 끝나지 않고 신호의 출처가 드러나는 전환에 활용한다.

- **C0:** 큰 앰버 리본은 기존 `x650–1950,y240–1030`, 제목은 왼쪽 `x100–720`. 앞쪽 가까운 R 곡면이 화면 오른쪽 일부를 잘라내고 낮은 파형 구간 사이로 뒤 무대가 보인다.
- **C1 중간:** 카메라가 가장자리 아래를 지나갈 때 가까운 리본 면이 화면 오른쪽 35%를 잠시 가린다. 가림이 지나가면 왼쪽에 심장·전극이 드러나고 리본의 얕은 단면과 그 뒤 잡음층 2–3개가 한꺼번에 보인다. 심장을 신호 면 안에 집어넣거나 R 피크를 터널처럼 통과하지 않는다.
- **C2 도착:** 심장 `(420,560)`와 오른쪽 리본 전시 자리로 돌아온다. 리본 두께는 낮아져 파형이 읽힌다. 뒤의 흐린 층이 전면 신호보다 밝지 않다.
- **재생:** 카메라의 회전은 p, 움직이는 선 헤드는 t. 같은 QRS 덩어리를 반복 자전시키는 대신 실제 재생 창이 흐른다. 반사광의 지나감과 박동 발광을 구분한다.
- **TUNE 확인:** ‘정체를 알 수 없는 금속 조각’으로 보이면 C0의 R 형태와 제목 대비를 강화한다. 두께 변화가 데이터 진폭으로 오해되면 조형 구간에 축/수치 표기를 넣지 않는다.

### C-X1 / C3–C5 전환: 폭발 대신 접혀 펼쳐지는 표본 셔터

**기존안 대비 새 점:** 기존 입자 처리실의 대안이다. 입자 밀도를 계속 올리기보다, 리본이 얇은 직사각 표본 면으로 열리고 배열을 지나 다시 닫히는 큰 실루엣 변화를 만든다.

- **q0:** 입력 리본의 국소 구간이 24–40개의 작은 평면 조각으로 나뉜다. 이 수는 조형 예산이며 실제 샘플 개수가 아니다. 왼쪽 심장 자리와 입구 방향은 유지한다.
- **q.30:** 조각들이 짧은 축을 중심으로 60–80° 회전한다. 카메라에서는 번쩍이는 앞면이 가느다란 옆면으로 바뀌어 입력이 순식간에 ‘열려’ 보인다. 조각 전체를 빠른 섬광으로 점멸시키지 않고 순차적으로 뒤집는다. 배열 입구 `(1120,540)`가 그 사이로 보인다.
- **q.60:** 카메라가 가까운 어두운 기둥 옆을 지나며 전경 가림→조각 행→뒤 청록 출력의 세 층을 본다. 앰버 주변 조각은 뒤 아래로 물러나고 출구쪽 조각은 청록의 저장 출력 위치로 모인다. 설명용 잡음 조각과 데이터 출력 표본을 같은 것으로 주장하지 않는다.
- **q1:** 면들이 눕고 서로 연결돼 출력 리본이 된다. 마지막 연결부는 현재 t의 출력 형상과 겹쳐 이어받는다. 화면을 하얗게 덮는 flash 없이 물체의 옆면/표면 변화 자체가 전환을 만든다.
- **상태:** 정지 p에서는 열린 각도가 고정되고 t의 흐름/국소 잔광은 유지한다. 역스크롤 시 각도와 배열 배치를 되돌린다. 빠른 스크롤에서도 시작·도착의 형태가 남아야 하며 시간으로 긴 전환을 강제하지 않는다.
- **Story 적용:** 동일 셔터를 반복하되 PLI는 규칙적 좁은 간격, BW는 넓은 완만한 면 이동, EMG는 손 쥠과 같은 t에 국소 조각 묶음이 나타난다. 전체 처리실이 세 번 새로 폭발하지 않는다.
- **문서 검토 판정:** 기존 입자 안과 나란히 시험할 대안. 작은 밝은 점보다 큰 실루엣 변화를 확보할 가능성이 있으나 ‘금속 블라인드’로 기억되는 위험이 있다. ECG 형태의 시작/끝과 디지털 배열의 중간을 필수 프레임으로 비교한다. C 채택은 미확정.

## 5. 이번 검토 결과와 다음 작업

| 후보 | 파형 전시 후보 | 전환 후보 | 권장 검토 순서 / 남은 판단 |
|---|---|---|---|
| A | A-W1 그래프 깊이 | A-X1 표본 막 | 우주/장소 TUNE와 별도로 A7/8 검토. 서가→격자 연결 및 처리 인과가 유지되는가 |
| B | B-W1 압인/들뜸 | B-X1 접힘 뒤 등록 격자 | B1–3 물성 계획과 B5–7을 함께 검토. 종이의 따뜻함과 디지털 사건이 공존하는가 |
| C | C-W1 단면 접근 | C-X1 표본 셔터 | 기존 C3–5 입자안 vs 셔터 대안. 핵심 실루엣·방향·심장 재등장을 비교 |

**지금 제안하는 우선 방향:** A-X1과 B-X1은 해당 세계의 기존 구조를 더 잘 이용하므로 검토의 기본 후보로 추천한다. C는 기존 입자안도 유지해 셔터와 비교한다. 사용자의 선택 없이 기본 시나리오를 교체하지 않았다.

각 안의 사용자 피드백은 `유지할 요소 / 채택·조합·보류할 카드 / 구도 수정 / 우려 / 다음 씬`으로 기록한다. 시나리오 수정은 안별로 한다. 공통 상태 규칙만 시스템으로 승격한다.

구체성 자체 점검: 6개 모두 화면 점유율/좌표, 전·중·후 프레임, 움직임을 만드는 p/t, ECG 연결 의미, 구현 방식 후보, 실패 모습이 있다. **이미지·실제 모션 검증은 없다.** 이 문서는 아이디어를 검토하기 위한 명세이며 시각 품질 KEEP 판정이 아니다.

다음 순서: 이 카드와 A/B TUNE 검토 → 해당 씬 수정 → 후보 비교/제작 순서 → 선택 안 최종 시나리오 피드백 → 목업 → clay/프리비즈 → 씬 구현 → 캡처를 보고 신규 아이디어 제안. 최종 피드백 전 이미지 생성 보류 유지.
