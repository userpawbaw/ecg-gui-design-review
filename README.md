# ECG GUI Design Review

ECG denoising 졸업작품의 GUI를 독립적으로 재설계하고, 이전 산출물과 비교한 뒤 최종 프로토타입과 검증 근거를 만드는 저장소입니다.

## 원본 프로젝트

- [ECG_denoising_method_comparision](https://github.com/userpawbaw/ECG_denoising_method_comparision)
- 원본 연구·학습 코드는 검토 자료로 사용하며, 이 저장소에서 GUI 작업을 분리해 기록합니다.
- 분석 시 원본 커밋 SHA를 고정하고 문서의 주장과 실제 구현을 구분합니다.

## 진행 순서

1. **연결 확인:** 이 README를 수정·커밋하고 원격 파일 및 커밋 SHA를 다시 조회합니다.
2. **프로젝트 재이해:** 목적, 데이터, 기법, 실험, 평가, 실행 제약을 원본 코드에서 확인합니다.
3. **독립 설계:** 기존 GUI 파일을 재열람하지 않고 설계안·인터랙티브 시안·평가 기준을 만든 뒤 동결 커밋합니다.
4. **비교 검증:** 기존 산출물을 열어 동일한 사용자 과제와 실패 시나리오로 두 안을 비교합니다.
5. **최종 제작:** 채택·수정·삭제 이유를 남기고 장점을 통합한 GUI 및 팀 인계 자료를 제작합니다.
6. **최종 감사:** 실제 수행한 검사, 실패, 미검증 항목, 잔여 통합 작업을 기록합니다.

## 기록 원칙

- 매 단계의 목표·산출물·검사·판정·다음 행동을 Markdown과 커밋으로 남깁니다.
- 이미 대화에 노출된 기억을 제거할 수는 없으므로, 독립성은 기존 파일 재열람 금지와 선행 동결 커밋으로 관리합니다.
- 새 모델이나 높은 노력 수준 자체를 품질 근거로 사용하지 않습니다.
- 모의 파형·예시 수치·미연결 하드웨어를 실제 실험 또는 LIVE 결과로 표시하지 않습니다.
- 검사하지 않은 항목은 `NOT VERIFIED`, 미구현은 `PENDING`으로 명시합니다.
- 실제 ECG·모델·AFE 연결 완료와 GUI 프로토타입 완료를 별도로 판정합니다.
