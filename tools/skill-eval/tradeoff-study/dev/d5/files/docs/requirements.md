# 홀터 뷰어 요구사항 (v0.3 초안)

- 기록: 1채널, 250 Hz, 24시간(2,160만 표본), 장비 ADC 12비트 → 파일은 int16 (43 MB).
- 판독의는 24시간 전체를 한 화면에서 훑다가 의심 구간을 눌러 10초 창까지 확대한다. 확대는 0.2초 안에 반응해야 한다.
- 10초 창에서는 원본 표본을 그대로 그린다(판독 정확성). 전체 · 1시간 보기에서는 박동의 높낮이 변화와 이상 박동이 보이면 된다.
- 병원 판독실 PC(8 GB RAM, 크롬). 태블릿 지원은 내년 검토.
- 기록 파일은 병원 내부 서버에서 받는다. **판독 중 네트워크가 끊겨도 계속 볼 수 있어야 하는지는 미정**(임상팀 회신 대기).
- 기준선 필터(0.5 Hz 고역통과)는 화면 표시용이며 켜고 끌 수 있어야 한다.
