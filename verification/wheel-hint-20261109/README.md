# 도입부 파형 단계 휠 안내 (D-163, 2026-11-09)

| 파일 | 내용 |
|---|---|
| 01_icon_candidates | 마우스 · 화살표 아이콘 후보 6종(① 휠 점 흐름 ② 휠 위아래 화살표 — 사용자 안 ③ 옆 세로 화살표 ④ 휠 단면 ⑤ 휠 ↔ 결과 미리보기 막대 — 제안 안 ⑥ 트랙패드) |
| 02_arrows_user_idea_frames | 사용자 안 한 주기(3 s)를 0.3 s 간격으로: 아래 화살표(→ 출력, 청록) 강조 → 위 화살표(→ 입력, 주황) 강조, 휠도 같은 방향으로 움직임 |
| 03_preview_proposed_frames | 제안 안 한 주기: 휠이 내려가며 막대가 입력(주황) → 출력(청록)으로 차고, 휠이 올라가며 비워짐 |
| 04 · 05 | 실제 도입부(`?p=0.86`) 안의 모습, 애니메이션 0.9 s 시점에서 멈춤 |

프레임(02 · 03)은 같은 CSS를 따로 띄운 페이지에서 애니메이션을 시각별로 멈춰 찍었다(이 환경은 GPU가 없어 3D 도입부가 초당 1 프레임 안팎이라 실시간 녹화가 맞지 않는다). 04 · 05는 실제 도입부 화면이다.
나타나는 조건: 파형이 돌기 시작한 뒤 진행 0.81 ~ 0.95, 마지막 휠 · 키 입력에서 1.2 s 지난 뒤, 최대 불투명도 0.6. 휠을 굴리면 곧 사라진다. 움직임 줄이기에서는 정지 그림.
비교 주소: `?wheelhint=arrows`(기본, 사용자 안) · `?wheelhint=preview`(제안 안) · `?wheelhint=off`.
