## 2. 공통 상태와 화면 계약 — 이번에 정리한 것

1920×1080, 좌상단 원점. `p`는 장면/카메라/전환 비율, `t`는 저장 신호 재생 시간, `q`는 해당 전환 구간의 p를 0–1로 정규화한 값이다.

1. **정지 p:** 카메라와 형태 전환 비율은 멈춘다. 심장·표본 흐름·sweep은 현재 t로 계속된다. ‘열린 표본 조각’은 고정 배열 위치를 따라 신호가 흐르는 상태로 보이며 별도의 과거 프레임으로 얼지 않는다.
2. **출력 도착:** q=1에서 현재 t의 저장 출력 형상을 사용한다. 전환 첫 프레임의 R을 마지막까지 운반하지 않는다. 재형성 도착과 심장 이벤트의 정합은 같은 시계에서 계산한다.
3. **빠른 스크롤:** q=1이면 즉시 해당 도착 상태를 만들 수 있어야 한다. 다음 박동/네 박동을 기다리느라 스크롤을 잠그지 않는다. 박동마다 남는 4개 흔적은 보조 상태 표시이며 출력 전환 조건이나 실제 계산 시간으로 쓰지 않는다.
4. **역스크롤:** p의 구조를 되돌리고 t는 계속된다. 장 재진입은 현재 신호 상태를 사용한다. 포인터 시차는 기본 카메라에 작은 오프셋으로 더하고 장면 목적지를 바꾸지 않는다.
5. **관찰 구도:** 왼쪽 심장/원인, 오른쪽 2.5초 파형을 읽을 자리를 둔다. 도입부·Story 변형은 허용하되 관찰 자리에서는 R과 박동의 연결이 쉽게 보여야 한다. 격자 대비/입력 앰버/잔광은 현재 만족 요소를 기준으로 조정한다.
6. **표기:** 특정 ‘최선 기법’은 그 장의 실제 선택 조건과 비교 근거가 확보됐을 때 풀네임으로 한 줄 표시한다. 없으면 `디지털 처리`만 사용한다. 제안받은 기법명을 임의로 우승자로 지정하지 않는다.
7. **비교 인계:** 단순히 3D 리본을 정면으로 돌리는 것만으로 정확성을 복원했다고 판단하지 않는다. 연출 객체를 종료하고 실제 데이터/시간/단위/Reference/Difference 계약의 렌더러로 인계한다.

## 3. A 수정안 — 한 기록이 있는 장소로 접근한다

**A-W1:** 수정안에 반영하되 3개의 ECG 선으로 층을 만들지 않는다. 앞은 실제 입력 리본, 중간은 작은 설명 조각, 뒤는 격자 면이다. **A-X1:** 표본 막을 반영. 기존 리본→전체 입자 폭발→큰 배열은 보류해 C와 구별한다. A5 바닥→의자 대안은 미채택으로 보존하고 현재 승인된 H5/3전극 재료와 기본 위치를 사용한다.

### A7 / .70–.82 — 그래프 공간이 펼쳐지는 입력 관찰

**시작:** 심장 `(460,550)`, 높이340. 서가의 수평선이 오른쪽 파형 뒤에 어둡게 남는다. 제목 `잡음이 섞인 심전도`는 `x940,y150`의 66px 2행, 보조 정보는 y300에서 분리한다.

**중간:** 카메라가 6° 측면으로 돌며 얕은 격자 면의 옆모서리를 드러낸다. 앞 리본 `x930–1805,y365–755`, 뒤 격자는 화면상 40px 뒤로 물러나고 바닥 모서리는 y810. 설명 조각은 긴 파형 모양을 만들지 않는다.

**도착:** 카메라가 읽는 방향으로 돌아와 심장과 R 피크가 동시에 보인다. 입력은 살아 있는 sweep이고 전체 앰버를 과도하게 밝히지 않는다. 큰 제목이 먼저 자리하고 그래프 면이 그 아래 늦게 펼쳐져 공간/정보 순서를 만든다.

### A8 / .82–1 — 동일 그래프에 표본 막이 지나간다

**전:** x1350의 얇은 디지털 막, 입력 리본과 뒤 격자. 막 아래 `디지털 처리` 19px. 새로운 큰 방으로 카메라가 이동하지 않는다.

**중(q.4):** 카메라 10° 측면. 막 앞 앰버 조각→막의 셀→뒤 청록 출력이 오른쪽 한 프레임에 보인다. 제거 설명 조각은 뒤 아래로 물러난다. 심장은 왼쪽에 남고 환경광은 강해지지 않는다.

**후:** 막이 오른쪽 바깥으로 나가고 출력이 같은 그래프 자리를 채운다. 제목은 `잡음 제거 결과`로 교대하되 면 위치는 고정한다. 현재 t의 출력이 이어받고 헤드 잔광/sweep fade가 유지된다.

**확인 프레임:** 지구 지형/역광, 구름 속 목적지, 보 앞뒤 깊이, A5 인체, A7 R 관찰, A8 입력/처리/출력 동시. A의 가장 큰 잔여 질문은 ‘이 경로에서 지구가 필요한가’이며 빛점 연결만으로 해결됐다고 판정하지 않는다.

**B-W1:** 압인 선을 헤드 주변의 짧은 구간만 반영. 뒤 종이에 완전한 동일 파형을 남기지 않는다. **B-X1:** 접힘 뒤 등록 격자를 반영하되 새 절개를 뚫지 않는다. B2의 큰 골이 내부 무대를 열고, B6은 이미 있는 오른쪽 작은 접힘의 뒤편을 읽는 구도로 변경한다.

### B5 / .50–.62 — 압인에서 살짝 떠오르는 신호

**전:** 심장 `(520,550)` 높이400, 종이 `x850–1860,y260–820`. 제목은 **오른쪽 상단 `(930,135)` 62px**로 통일한다. 기존 B-T6의 ‘왼쪽 면’ 지시는 이 씬에서 폐기한다. 좌측은 심장의 자리, 오른쪽은 제목/신호의 자리다.

**중:** 헤드 바로 뒤 40–80px 구간에만 얕은 홈이 보인다. 선이 종이에서 떠오르며 사이에 좁은 그림자. 리본의 몸통은 낮은 명도, 헤드는 잠깐 밝고 홈은 더 어둡다. 홈과 활성선은 같은 t로 이동한다.

**후:** 12° 측면에서 얇은 선·간격·종이 접힘이 구분된다. 완전한 압인 ECG를 배경에 남기지 않고 홈은 sweep 소멸과 함께 지운다. 글자는 종이와 함께 가파르게 기울지 않는 전경 면이다.

### B6 / .62–.75 — 새 구멍 대신 기존 접힘의 뒤편

**전:** 오른쪽 접힘 축 x1360. 카메라가 8° 더 측면으로 움직이며 접힘 면이 20–30° 열리고 뒤 격자 `x1260–1510` 일부를 드러낸다. B2 같은 거대한 문/90px 절개를 다시 만들지 않는다.

**중:** 입력이 짧은 조각으로 뒤 격자에 등록된다. 기록의 행 위치가 유지되고 뒤 컴퓨터 방향의 가는 연결이 처리 주체를 암시한다. 작은 `디지털 처리`가 격자 옆에 먼저 나타난다. 종이가 신호를 정화하는 마법으로 읽히지 않게 하는 구도다.

**후:** 카메라가 정면으로 돌아오며 청록 출력 조각이 같은 기록 자리에 붙는다. 앞의 종이/중간 표본/뒤 처리층을 얕은 3층으로 유지하고 새 배열 방으로 떠나지 않는다.

### B7–B9 / .75–1 — 출력과 Story로의 복귀

B7은 청록 `x925–1800,y380–730`, 제목 `(930,135)` 위치 유지. 틈 뒤 빛이 이면에 짧게 남았다 사라지고 심장/R/sweep은 계속된다. B8에서는 카메라가 물러나 동일 설치물과 3개 탭을 보며, B9의 큰 종이 넘김은 **장 전환 전경**이다. 장을 넘겨도 안의 사람/컴퓨터/전선 좌표를 새로 초기화하지 않는다.

**확인 프레임:** B1 종이 이면, B2 틈의 작은 사람, B3 전경 margin/같은 사람, B5 국소 홈과 활성선, B6 앞/뒤 처리층, B7 같은 자리의 출력. 압인/처리 격자/전체 장 넘김을 한 씬에 동시에 강조하지 않는다.

## 5. C 수정안 — 표본 셔터를 대표 와우로 선택한 비교 초안

### C 카드 판단

**C-W1:** 단면 접근을 반영하되 카메라는 R 피크 안으로 통과하지 않는다. **C-X1:** v4 수정안의 대표 전환으로 반영. 기존 C3–5 전체 입자안은 별도 대안으로 보존한다. 두 버전을 모두 비교할 계획이며 동시에 중첩하지 않는다. 이는 제가 작성한 추천 수정안이며 사용자 승자 선정은 아니다.

### C0–C2 / .00–.35 — ECG 실루엣에서 출처 발견

- C0 제목 왼쪽 `(100,180)` 88px, 리본 `x650–1950,y240–1030`. 높은 R 실루엣이 있고 잡음층은 뒤에 있다. 무작위 곡면만 보여주지 않는다.
- C1 카메라는 가까운 리본 가장자리 아래 옆을 지나간다. 리본이 오른쪽35%를 가린 뒤 왼쪽에 심장/전극이 보인다. 리본 단면은 두꺼워 보이지만 신체 안에 파고들지 않는다.
- C2 도착: 심장 `(420,560)` 높이360, 오른쪽 읽는 리본 `x800–1810,y330–800`. 두께/반사는 낮아지고 t의 2.5초 창이 분명히 읽힌다. 제목은 `잡음이 섞인 심전도`로 교대.

### C3 / .35–.49 — 열린 표본 면

**전:** 오른쪽 입력 리본에 불연속 작은 면들이 생기되 전체 실루엣은 아직 R이다. 24–40면은 조형 예산이며 실제 표본 개수를 뜻하지 않는다.

**중:** 순차 회전으로 앞면이 옆면이 되고 배열 입구 `(1120,540)`가 보인다. 조각 전체를 흩뿌리지 않는다. 심장은 왼쪽 `(420,560)`에 작은 국소 발광으로 남긴다. 제목 `디지털 처리` 68px는 상단 왼쪽, 심장과 겹치지 않는다.

**후:** 열린 표본 면이 방향을 가진 행으로 배열에 들어간다. 탈락 설명 조각만 8–16개의 큰 덩어리부터 시험하고 전경 입자눈보라를 만들지 않는다.

### C4 / .49–.65 — 처리 공간을 통과하는 중간 와우

카메라가 가까운 왼쪽 기둥 옆으로 전진한다. 어두운 앞면은 왼쪽 화면1/3을 잠시 가리고 뒤의 표본 행은 밝다. 출력의 청록 시작은 오른쪽 뒤 `(1690,570)`. **가까운 어두운 구조→중간 정렬 면→뒤 청록 출력**의 세 층이 한 프레임에 보인다.

이 순간에는 심장이 전경 가림 뒤로 잠시 숨을 수 있지만 박동 시계는 계속된다. 가림이 끝난 C5에서는 동일 심장 위치/위상으로 복귀한다. 심장을 모든 씬에서 억지로 최대로 밝게 그려 깊이를 없애지 않는다.

### C5 / .65–.81 — 같은 신호 창에 재결합

표본 면들이 눕고 현재 t의 저장 출력 형상으로 연결된다. 카메라가 왼쪽으로 돌아 심장 `(410,550)` 높이360, 청록 리본 `x800–1810,y330–800`을 함께 되찾는다. R 부분만 먼저 붙여 과거 R을 다음 심장 박동처럼 보이게 하지 않는다. 전체 도착 형상은 현재 창으로 갱신한다. 출력 제목이 등장하고 뒤 격자는 낮은 대비로 펼쳐진다.

C6–C7은 기존 같은 처리실의 컴퓨터/바닥 전원선으로 이동한다. 새 원형 링이나 두번째 입자 폭발을 추가하지 않는다.

**확인 프레임:** C0 ECG 실루엣, C1 가림 뒤 출처, C2 박동 관찰, C3 열린 표본, C4 3층 처리 구도, C5 같은 t의 출력. 기존 입자안과 셔터안은 동일 카메라 시작/도착과 동일 신호 창으로 비교해야 차이를 판단할 수 있다.

## 6. Story 수정 — 공통 의미, 서로 다른 표현

도입 이후 세 잡음은 기존 저품질 Story를 재사용하는 대신 각 안의 같은 세계에서 새로 만든다. 아래는 **세 장의 처리 문법을 같게 유지하면서 원인 발견과 입력의 모습은 다르게 만드는 수정안**이다.

| 장 | 원인 발견과 입력 | A의 처리 / B의 처리 / C의 처리 | 반복을 줄이는 수정 |
|---|---|---|---|
| PLI | 사람 왼쪽/컴퓨터 오른쪽/바닥 콘센트의 전선 연결. 콘센트 근접의 작은 AC 표식→원경 물결2–3회→가슴/입력 관찰 | A 표본 막 / B 작은 접힘 뒤 격자 / C 짧은 표본 셔터. 모두 모니터의 보조 박동 흔적과 연결 가능 | 물결은 물체 주변의 설명 효과이며 60Hz 환경 점멸로 표현하지 않음. 물결2–3회는 관찰 목표이지 스크롤 차단 조건이 아님 |
| BW | 측면 흉곽과 심장, 오른쪽 느린 기준선 변동. 그 기록의 저주파 경향에 호흡 설명 동작을 대응 | 같은 처리 구조를 더 짧게 재사용. 기준면 이동이 줄어든 출력이 도착하되 P-QRS-T는 남음 | 모든 기록을 3초 호흡으로 고정하지 않음. 실제 호흡 측정이 없으면 설명 동작임을 기록. 호흡이 모든 기저선 변동의 유일한 원인이라는 주장 없음 |
| EMG | 손/전완·가슴을 같은 구도, 잡음 burst 포락과 같은 t에 쥠/풀림. 인체의 손 형태가 실제로 읽혀야 함 | A 막 앞 국소 조각 / B 특정 행의 작은 등록 조각 / C 일부 셔터 묶음. 전체 화면을 또 폭발시키지 않음 | 사다리 손은 현재 A 맥락, B/C는 각 세계의 손동작. 근육 동작은 설명 연출이고 실제 기록자의 동작 증거가 아님 |

PLI/BW/EMG 모두 **입력 관찰 → 처리 사건 → 출력 관찰**을 가진다. 처리 시간/성능 숫자를 스크롤 길이에서 만들어내지 않는다. 최선 기법의 조건이 확보되면 출력 직전 한 줄로 드러내고, 조건 미확인이면 placeholder 우승자를 넣지 않는다.

## 7. 구체성 자체 검토와 남은 검증

| 요구 | 이번 문서에 있는 것 | 판정 범위 |
|---|---|---|
| 씬마다 화면이 그려지는가 | 주요 좌표/크기, 앞뒤 면, 제목 위치, 전·중·후 구도 | 문서 수준 충족. 실제 구도 검증 전 |
| 와우와 프로젝트가 융합되는가 | A 장소→신호, B 기록의 뒤편→처리, C ECG 자체→표본/출력 | 연결 설명 있음. 관람객이 그렇게 읽는지는 결과 확인 필요 |
| 움직임과 정지 상태가 구체적인가 | p/t/q, 가림/회전/접힘, 정지/역방향/빠른 입력/출력 인계 | 명세 충족. 실제 매끄러움 미검증 |
| 원본과 독자 확장이 구별되는가 | 기존 마이닝 근거 유지. 이번 전환/압인/셔터는 독자 확장 | 귀속 구분. 새 레퍼런스 조사 없음 |
| 빛과 모델링이 연결되는가 | A 수광/shaft 보호, B 앞뒤 틈빛, C 어두운 구조/발광 면 | 설계 연결. 실제 렌더/웹 색 일치 미검증 |
| 데이터 정확성 범위가 지켜지는가 | Intro/Story 조형 허용, 동기 유지, 정확 비교 렌더 별도 | 계약 명시. 데이터 조건·실행 검증은 제작 단계 |

문서 분량/검사 통과를 시각적 완성도로 환산하지 않는다. 아직 A/B/C의 실제 이미지가 없으므로 와우의 강도나 인체/종이/지구 품질에 점수를 매기지 않았다.

## 8. 첫 제작 시험 추천과 작업 상태

**최종 피드백 이후의 첫 시험 추천: B → C → A.** 전체 구현 승자/실행 순서 확정은 아니며, 지금 검토할 제안이다.

- **B 먼저:** 사용자가 느낀 종이·기록물의 공간감을 가장 직접적으로 확인할 수 있다. B1–B3의 얇은 종이/이면/틈 품질을 먼저 보면 이 안의 핵심 가능성을 빠르게 판단한다. 기존 레퍼런스에 없는 독자 공간이므로 성공을 낙관해 통과시키지 않는다.
- **C 다음:** ECG가 첫 프레임부터 주제이며 처리 사건의 실루엣이 크다. 같은 C3–C5 구도로 기존 입자안과 셔터안을 비교한다. B와 무드가 달라 대안으로 가치가 있다.
- **A 세번째:** 사용자의 원형 아이디어를 보존하지만 지구 품질·스케일 연결·템포까지 성공해야 한다. 현재 승인된 서고/H5 조명 작업은 이 후보 순서 제안과 별도로 계속 추적한다. A의 기존 작업을 멈추거나 기각한다는 결정이 아니다.

| 트랙 | 이번 완료 | 다음 판단 |
|---|---|---|
| A-REVIEW / A-WAVE | A-T2/3/5/6/7 문서 수정, W1/X1 조합 초안 | 지구 경로·관찰 구도·표본 막 유지/수정. 실제 A-T1/4 품질 미검증 |
| B-REVIEW / B-WAVE | B-T2/4/5/6/7 문서 보완, 국소 압인/작은 뒤편 처리 조합 | 큰 틈과 작은 처리 구별, 제목 위치, 종이 물성 방향 |
| C-REVIEW / C-WAVE | 셔터 중심 수정 초안과 기존 입자 대안 분리 | 단면/셔터 채택 여부 및 입자 대안 비교 우선도 |
| SYS-STATE | 박동 흔적의 전환 차단 폐기, p/t/q와 인계 조건 명확화 | 이후 실제 모션에서 상태 문제 발견 시 보완 |
| PRIORITY-01 | 첫 시험 B→C→A 추천 근거 작성 | 사용자 제작 순서와 최종 시나리오 피드백 |

다음은 이 v4의 안별 구도/전환/추천 순서에 대한 최종 피드백을 반영하는 단계다. 그 뒤 핵심 목업 프레임을 만든다. 제작 중에는 씬마다 결과 캡처를 보고 새 파형·전환 아이디어를 계속 제안한다.
