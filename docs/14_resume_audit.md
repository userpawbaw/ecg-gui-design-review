## 보존 범위와 재개 방법

복구 브랜치에는 코드, lockfile, 생성 스크립트 및 검증 기록을 커밋한다. 대용량 52조건 JSON과 설치된 의존성은 Git에 넣지 않는다. 현재 로컬에 보존되어 있으나 영구 원격 자료 보관 완료로 주장하지 않는다. 파일별 SHA-256은 검증 기록에 남긴다. 자료가 유실되면 고정 원본 SHA에서 재생성할 수 있으며, 향후 생성기 변경 시 이전 파일을 존재 여부만으로 재사용하지 말고 생성 조건/버전을 먼저 대조한다.

다음 순서: W1–W10 공간 배치 및 상태 전환 문서 → 자체 검수 → 사용자 와이어프레임 검토 → R1a/R1b → R2 98조건 완성·청크 패키징 → R3–R5. 기존 승인과 새 계획의 차이를 숨기지 않으며, 구현 완료 또는 최종 검수 완료로 보고하지 않는다.
