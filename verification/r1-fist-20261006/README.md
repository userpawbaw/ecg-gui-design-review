시점 차이: 엄지 쪽·손등 쪽 촬영은 손가락이 서로 가려 값이 흔들립니다(곡선 그림 `curves.png`는 저장소 밖). 그래서 손바닥 쪽 두 구간만 썼습니다. 두 구간의 끝 각도는 1–4° 안에서 일치했습니다.

## 리그에서 한 일
- **끝 주먹**: 목표는 MCP 85–92·PIP 100·DIP 0.7×PIP(평평한 휴지 손 기준)입니다. 손끝이 손바닥에 2 mm 넘게 파고들면 손가락 전체를 비례로 줄입니다. 결과는 검지 79/93/65, 중지 79/90/63, 약지 74/82/57, 새끼 73/79/55(°)입니다. 손가락은 굽히면서 중지 쪽으로 모읍니다(펼친 상태 벌어짐의 85 %, 영상의 '벌림 → 0').
- **엄지**: 검지·중지 중간마디 앞을 가로질러 놓이게 탐색합니다(CMC 세 축 + MCP + IP). 엄지 MCP·IP 굽힘 방향은 손바닥 법선이 아니라 새끼손가락 쪽입니다.
- **엄지 경로**: 처음에는 엄지 각도를 직선으로 보간했습니다. 그러자 펼 때 엄지가 감긴 검지를 6.7–7.5 mm 뚫고 지나갔습니다(관문이 잡음). 엄지 전체를 IP 곡선(마지막에 들어오고 먼저 나감)에 맞추자 직선 경로로도 최대 2.9 mm가 되었습니다(피부 눌림 범위). 그래서 우회 오프셋은 쓰지 않습니다. 탐색 코드는 남겨 두었고, 동점이면 우회가 가장 작은 쪽을 고릅니다.
- **관문**: 쥠 21프레임과 폄 21프레임 전부를 검사합니다. 손가락 가동 범위는 `pose-check-v3`, 손가락·엄지·손바닥 캡슐 충돌은 반지름을 메시 단면에서 잽니다. 엄지 MCP·IP 가동 범위도 봅니다. 결과 FAIL 0(`verification/pose-check/fist.json`).

## 고친 결함(이 작업에서 발견)
- **검증기 손가락 측정식이 주먹에서 특이점**: MCP가 약 90°가 되면 기준축(손바닥 법선을 앞 마디에 투영한 것)이 사라져 'PIP 과신전 −101°' 같은 값이 나왔습니다. 경첩 축(앞 마디에 실린 휴지 축) 기준으로 바꿨습니다(`pose-check-v3.py` `finger_axis`).
- **Poser 손가락 굽힘 축이 뒤집힘**: `curl`·`wrap_bar`가 '뼈 × 현재 손바닥 법선'을 축으로 썼습니다. 90°를 넘게 감긴 손가락에서는 이 축이 뒤집혀, 사다리 쥠의 약지·새끼 끝마디가 실제로 −43° 뒤로 꺾여 있었습니다. 예전 측정식도 같은 곳에서 무너져 PASS로 보였습니다. 검증기와 같은 경첩 축으로 바꾼 뒤 다섯 자세 모두 FAIL 0입니다.
- **휴지 손의 MCP를 굽힘으로 셈**: 검증기가 휴지 자세의 원시 각도(MCP 18–33°, 손바닥뼈와 손가락뼈 방향 차이)를 '이미 굽은 양'으로 더했습니다. 메시의 휴지 손은 평평합니다. 그래서 측정 90°가 실제로는 60°였고, 첫 주먹은 옆에서 보면 구멍이 났습니다. 휴지 기준으로 바꿨습니다.
- **조절점 스케일 새어 듦**: `pose_bone.matrix`에 쓰면 Rigify 손가락 사슬 아래에서 비균일 스케일이 쌓였습니다(중지 끝마디 (0.12, 10, 0.86)). 회전마다 스케일을 1로 되돌립니다.
