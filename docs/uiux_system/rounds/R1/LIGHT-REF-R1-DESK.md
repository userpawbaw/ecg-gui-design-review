## 5. 권장 순서와 판단

H5(램프 다듬기, 사용자 지적) → H1(그림자) → H2(원뿔 자르기) → H3(접촉 그늘) → H4(반사) → H6(재질 결). H7은 앞의 결과를 보고 결정.
- H1 + H2가 "선명한 그림자와 아닌 부분"을 가장 크게 바꾼다. 둘 다 같은 그림자 지도 한 장을 쓴다.
- H4는 정적 큐브맵이면 비용이 낮지만, 구운 재질과 결이 다를 위험이 있어 앞 단계 뒤에 본다.
- 모든 후보는 디버그 패널에서 켜고 끌 수 있게 만들어 전후를 비교한다.

공통 원칙(L9–L13 + REF-002 §11):
1. 빛은 해 하나. 작은 원반이라 가까운 물체의 그림자가 선명하다.
2. 흐린 그림자는 화면 밖에 있는 먼 가림막(창 밖 식물, 큰 가지)이 만든다. 그림자 모양이 장면 안 물체와 연결되지 않아야 "자유분방"하게 보인다.
3. 소품은 직선·베벨의 단순 형태. 품질은 텍셀 밀도와 빛에서 나온다.
4. 그늘은 반사광으로 따뜻하게 채운다. 검은 구멍을 만들지 않는다.
5. 어둠에도 층위가 있다(사용자 2026-10-16, REF-002 다락방 왼쪽 구석):
   - 책장 안쪽으로 들어간 칸의 구석은 빛이 닿지 않아 더 어둡다.
   - 같은 어둠 속에서도 빛이 오는 쪽 면에는 약한 반사광이 보인다.
