## 자체 검토 (매뉴얼 §17 루브릭 · D-050)
| 항목 | 판정 | 근거 |
|---|---|---|
| 빛의 출발점 | CONDITIONAL | 바닥 장면에서 창은 화면 밖, 대신 사다리를 지난 갈래 → 바닥 무늬로 경로는 읽힘. 사다리 장면에 창이 보임 |
| 무엇이 빛을 쪼개는가 | PASS | 바닥 패치에 블라인드 살 줄무늬 + 사다리 그림자(점토 A에서도 보임) — 지난 L1(무늬 없는 막대) 해소 |
| 수광면이 증명 | PASS | 바닥(줄무늬)·사다리 옆대·사람 무릎이 같은 갈래를 받음 |
| 어둠이 남는가 | PASS | 닫힌 창 쪽 서가·창 아래 벽 장면 양옆 서가가 어둠 기준 |
| 볼륨이 공간감만 | PASS | 방 전체가 뿌옇지 않음(점토 A와 아름다움 컷의 검은 수준 비슷) |
| 후처리 없이 성립 | PASS | 점토 A(볼륨·발광 끔)에서도 바닥 장면 구도 성립 |
| 사람 영역에서 심장이 가장 밝다 | PASS | 다섯 장면 모두 |
| 장면마다 새 구역 | PASS | 사다리 발치 → 카트·의자 → 책상 → 창 아래 틈 → 사다리 위 |
| 원인이 화면에 | CONDITIONAL | 책상 장면에 멀티탭·전원선이 화면 밖 → 다음 시안에서 구도에 넣기. 근육 장면의 쥔 손이 작음 |
| 선 길이 | CONDITIONAL | 창 아래 벽 자리는 카트에서 약 2.9 m — 트렁크가 바닥을 길게 가로지름(점선이 시선을 끔) |
