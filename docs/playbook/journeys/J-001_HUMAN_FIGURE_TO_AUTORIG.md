## 출발점

도입부(D-041)에 심장을 품은 사람 한 명이 필요했다. 나중에 Story에서 그 사람이 앉아서 숨을 쉬고 주먹을 쥐어야 했다(D-053). 처음에는 사람을 "심장을 담는 윤곽" 정도로 보았다. 그래서 형태 품질, 머리, 손, 골격을 차례로 다시 만들게 되었다.

이 여정의 줄기는 한 가지다. **표현 방식을 바꿔 품질 문제를 피하려 할 때마다, 그 문제는 다음 자세에서 다시 나왔다.** 문제는 메시에서 손, 손에서 골격, 골격에서 피부 가중치로 내려갔다. 마지막 원인은 관절 위치와 피부 가중치였고, 이 둘은 우리가 직접 만든 것보다 자동 리깅이 나았다.

사용자 회고 `[대화]`(2026-10-09): "처음엔 인체의 퀄리티를 너무 실사같이 하면 결과물에서 일정한 품질을 보장할 수 없을 것 같아 머리를 둥글게 만들기도 했다가 나중에 결과물 불만족으로 수정한 적도 있었고, 또 높은 퀄리티의 리깅을 보장할 수 없는 상황에서 메시를 원형 고리, 우유빛 유리 껍데기 느낌으로 수정하기도 했잖아?"

## 도착점

- **P-001** 사람 메시에 뼈대를 붙일 때 → 우리 메시를 Mixamo 자동 리깅에 올린다.
- **P-002** 다른 골격의 자세·동작을 옮길 때 → 같은 메시 리그끼리는 월드 회전 + 접촉 IK. 다른 골격에서 옮길 때는 골격 충실도를 피부보다 먼저 본다.
- **P-003** 사람의 겉모습(표현·머리·원본 메시)을 정할 때 → 품질 문제를 표현 양식으로 피하지 않는다. 실제 쓰일 자세에서 비교한다.
- **P-004** 사람 자세·피부 결과를 보여 주기 전 → 수치 관문 + 클로즈업 비교. 눈대중 PASS는 금지.

아직 열려 있는 것:
- Story 숨 키를 자동 리깅으로 옮기는 일(미착수).
- 주먹 중간 프레임 확인.
- 피부 검출기의 접촉 허용 목록(deform-qa §2).

## 여정에서 얻은 것

1. **문제는 한 층씩 아래로 내려갔다.** 표현 → 메시·머리 → 손 → 골격 → 관절 위치·가중치 순서였다. 위층에서 덮으면 다음 자세에서 아래층 문제가 다시 나왔다(T2 → T4 → T6 → T12). 같은 불만이 두 번 나오면 한 층 아래를 의심한다(P-003, P-001).
2. **사람이 먼저 원인을 찾은 순간이 판단을 바꿨다.** 사용자가 원인을 짚은 순간은 네 번이었다. "골격 모델 쓰는게 낫지 않아"(T6), "자체 피드백 루프가 없다"(T8), "겨드랑이와 무릎이 맞닿게"(T12), "자동 리깅이 훨씬 퀄리티가 높은 것 같은데"(T14). AI는 그때마다 지금 쓰는 도구 안에서 수치를 줄이고 있었다(P-004).
3. **수치가 맞아도 인상이 틀릴 수 있고, 검출기가 틀려도 눈이 맞을 수 있다**(T13, T14). 검증기는 결함 위치를 찾는 데 쓰고, 후보끼리 순위는 같은 자세의 클로즈업으로 정한다(P-004).
4. **직접 만든 리그의 관절 위치 오차(팔꿈치 4.9 cm)는 T7부터 T14까지 드러나지 않았다.** 다른 리그와 나란히 놓았을 때만 보였다(P-001).
