# 주소 뒤에 붙이는 값(URL 옵션) 모음

`npm run story`로 연 주소(http://127.0.0.1:5173/) 뒤에 붙여 화면을 바꾼다. 처음 값은 `?`로, 두 번째부터는 `&`로 잇는다.

- 예: `http://127.0.0.1:5173/?route=lab&ray=3&vz=4.0,1.3`
- 값을 바꾼 뒤에는 주소 창에서 Enter(새로 고침)를 누른다. 저장되지 않으므로 주소를 지우면 기본값으로 돌아간다.
- 이 문서는 사용자가 비교·검토에 쓰는 값을 모았다. 새 값을 코드에 추가하면 같은 커밋에서 이 문서도 고친다.
- 근거 기록(D-…)은 `docs/uiux_system/records/D_DECISIONS.md`.

## 1. 화면 이동

| 값 | 뜻 | 기본 |
|---|---|---|
| `route=lab` | 도입부(Story)를 건너뛰고 실험실부터 연다 | 도입부부터 |
| `step=3` | Story의 해당 단계로 바로 간다(0부터) | 처음 |
| `story=noise` | 잡음 장면 하나만 연다(`cond=pli`·`bw`·`ma`·`all`과 함께) | — |
| `reduced=1` | 움직임 줄이기(운영체제 설정과 같은 효과) | 운영체제 설정 |
| `live=iframe` | 실시간 측정 탭을 A안(브리지 자체 화면 `live.html`을 iframe으로, D-151)으로 연다 | B안(이 앱이 직접 그림, D-157) |
| `bridge=127.0.0.1:8765` | 브리지에 **직접** 붙는다. A안에서는 그 주소의 화면을 띄우고, B안에서는 브리지가 CORS를 낼 때만 된다(지금 브리지는 안 낸다) | 앱 서버의 같은 출처 프록시 `bridge/…` → `127.0.0.1:8765` |

- 실시간 측정 B안의 브리지 주소를 바꾸려면 앱을 띄우기 전에 환경 변수 `ECG_BRIDGE`(예: `http://192.168.0.5:8765`)를 둔다. 기본은 `http://127.0.0.1:8765`.

## 2. 실험실 배경 — 서고(D-074 이후)

### 2.1 서고와 경로

| 값 | 뜻 | 기본 |
|---|---|---|
| `sun=` | 어느 굽기 결과를 쓸지. `x` 레퍼런스(REF-002) 다락방을 실측 배치로 다시 지은 방, 모든 물체 텍스처 굽기(D-158) · `w` 수평 하강 + 해치 웅덩이·오른쪽 반사광(D-155) · `v` 수평 하강용 첫 안(D-154) · `orig` 처음 서고(D-080 이전 기본) · `e3` 처음 해 + 천창·높은 창(D-080) · `d16` D안 + 해 1.6배(D-080) · `lab` C안 + 큰 해치(D-079) · `30` 해 30°(D-077) · `15` 해 15°(D-078) | `w` |
| `path=` | 카메라 경로. `r` 레퍼런스 카메라(세로 22.9°, 수평, 아래로만, D-158) · `v1` 통로 앞에서 수평으로 아래로만(D-154) · `v2` 통로 안에서 수평 하강 · `c1` 통로를 앞으로 나아가며 내려옴(D-077) · `c2` c1 + 마지막에 책장 틈 보기 · `c3` D-074의 처음 하강 | `v1` |
| `rz=위,아래` | `r` 경로의 카메라 높이(m, 위층 바닥 0 기준). 예: `rz=-0.44,-3.19` 레퍼런스 전체 하강(−2.5보다 아래에서는 바닥 끝이 보임) | `-0.44,-2.45` |
| `vz=위,아래` | `v1`·`v2`의 내려가는 높이(m). 예: `vz=4.0,1.3` 전체 하강 | `3.9,3.0` |
| `bg=0` | 배경을 끈다 | 켬 |

### 2.2 빛기둥·움직임

| 값 | 뜻 | 기본 |
|---|---|---|
| `ray=` | 빛 커튼이 옆에서 보이는 정도(D-153). `0` 그대로 · `1` 보이게 · `2` 1 + 빛 방향의 결 · `3` 2 + 밝은 줄과 그림자 줄 | `0` |
| `shaft=` | 빛기둥 세기 0–100(10 단위, 50이 설계값). 값을 주지 않으면 `sun=x`는 설계값의 0.6배(D-158, "빛 커튼이 좀 강한 감") | 50 |
| `aurora=` | 빛 커튼 일렁임 세기 0–100(D-077 S1) | 50 |
| `amb=` | `0` 상시 움직임 끔 · `1` 소프트웨어 렌더에서도 강제로 켬 | GPU면 켬 |

### 2.3 화면 위 겹침

| 값 | 뜻 | 기본 |
|---|---|---|
| `curtain=` | 배경 위 검은 막의 진하기 0–100 | 70 |
| `ui=` | 패널 불투명도 0–100 | 90 |

### 2.4 화질·성능(D-153)

| 값 | 뜻 | 기본 |
|---|---|---|
| `bgres=` | 방을 그리는 해상도 배율(1 = 화면 해상도) | GPU 1 · 소프트웨어 0.35 |
| `msaa=` | 방의 안티에일리어싱 표본 수(`0` 끔, `4`) | GPU 4 · 소프트웨어 0 |
| `fogres=` | 빛기둥 계산 해상도(방 해상도 대비) | 0.5 |
| `tone=agx` | 톤 매핑을 AgX로(비교용, D-154: 더 평평해서 기본은 ACES) | ACES |

## 3. 파형

| 값 | 뜻 | 기본 |
|---|---|---|
| `labfx=0`·`1`·`2` | 파형 빛 번짐 단계를 고정(D-073). 없으면 프레임이 느릴 때 자동으로 낮춘다 | 2(자동) |
| `long=0` | 600초 긴 재생 자료를 쓰지 않는다 | 씀 |

## 4. Story 장면 점검용(QA)

장면 비교·캡처에 쓴다. 평소 관람에는 필요 없다.

| 값 | 뜻 |
|---|---|
| `t=초` | Story 시간을 그 시점에 멈춘다 |
| `debug=1` | 잡음 장면의 선택 패널을 연다 |
| `cam=x,y,z,lx,ly,lz,세로화각` | 카메라를 고정한다 |
| `msaa=0` | Story 장면의 안티에일리어싱을 끈다 |
| `look=v1`·`v2`, `shot=`, `signal=clean`·`noise`·`off` | 도입부 표현·컷·신호 미리보기 |
| `comp`·`speed`·`ac`·`sonar`·`fade`·`light`·`set`·`fist` | 잡음 장면 연출 안 선택(D-068–D-072). 기본 A1·B2·C1·D2·Eb·L0·A·F2 |
| `heart`·`hfill`·`breathk`·`legib`·`chest`·`bwexpo`·`bwray`·`bwedge`·`setk`·`lamp`·`scr`·`cone`·`macam`·`legacyDesk` | 잡음 장면의 세기·표현 미세 조정(코드 주석 참고) |

## 5. 자주 쓰는 조합

| 보고 싶은 것 | 붙일 값 |
|---|---|
| 새 기본 실험실 | `?route=lab` |
| 바로 전 서고(D-155)와 비교 | `?route=lab&sun=w` |
| 바로 전 안(D-154)과 비교 | `?route=lab&sun=v` |
| 빛 줄기 강조 | `?route=lab&ray=3` |
| 수평 하강 전체 | `?route=lab&vz=4.0,1.3` |
| 이전 처음 서고 + 직진 경로 | `?route=lab&sun=orig&path=c1` |
| 배경만 크게 보기 | `?route=lab&curtain=0&ui=0` |
