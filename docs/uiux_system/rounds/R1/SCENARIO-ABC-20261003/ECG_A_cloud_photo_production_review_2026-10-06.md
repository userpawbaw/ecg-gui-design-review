## 제작 명세와 실제 변경

- 참고: J5v7의 큰 왼쪽 군집·오른쪽 군집·중앙 통로, 첨부 실사진의 넓은 음영과 부드러운 경계. 사진에서 voxel을 복원한 것은 아니다.
- 신규 에셋: 128³ 밀도, 8×4×8km 범위의 합성 군집, 밀도 atlas, fixed-sun 빛 통과 두께와 지표 그림자 f16 cache. 준비 script/manifest/registry/NOTICE 보존.
- 큰 융기와 중간 덩어리를 분리하고 주기적인 sine 변형을 비주기 value noise 3개 규모로 교체했다. 얇은 상부 층은 별도 density/profile이다.
- 근접 렌더: 144 ray samples, full-resolution, 밀도와 bake sigma 6/km 정합. 단일 직접광+근사 다중산란+차폐를 고려한 주변광. 물리적 다중산란/GI 정합의 증명은 아니다.
- 광역 구름과 근접 bank 인계 범위를 늘리고 카메라를 bank 밖에서 접근하도록 조정했다.
- 서고 조명·소품과 ECG clock은 수정하지 않았다.

### 빛 처리 점검

광원 → 구름 밀도 blocker → 적분 transmittance → 구름 scattering / 지표 receiver → 카메라 → bloom/ACES 순서.
고정 광원 방향에 맞춘 cache이며 광원을 바꾸면 rebake가 필요하다.
light-depth와 density 파일을 동일 조형에서 다시 생성했다. 새 Blender/Cycles 동일카메라 gold render 성공을 주장하지 않는다.

## 내부 수정과 실제 검토

1. 초기: 큰 매끈한 덩어리·지나치게 밝은 면. 광량/중간 조형/좌우 위치 보완.
2. 반복 stripe를 확인해 비주기 밀도 변화, full-resolution/144 samples로 보완. 변경 도중 잘못된 GLSL 숫자7.5.로 compile error 발생, 7.5로 수정. 새 검증 탭에서 error 로그 없음.
3. 카메라가 이미 bank 앞부분에 들어가 양감만 과대 표시하는 문제를 밖에서 접근하는 구도로 조정, 중간 덩어리와 밀도 변화 보완.

초기+3 내부 품질 보완 종료. 내부 결과를 최종 채택으로 처리하지 않는다.

## 실패시 두 대안의 비교 계획

동일 지구/궤도 출발·서고 도착과 비교 구간을 사용한다.

| 대안 | 제작 범위 | 퀄리티 확인 |
|---|---|---|
| 구름 제거 | 궤도 하강→공간/서고 전이, 빛·카메라·가림 물체로 접합 설계 | 빈 공간/급격한 scale jump 없이 주제와 흐름 유지 |
| AI 생성 영상 | 궤도→구름 하강 구간의 연속 영상, 끝 프레임 서고 도착에 맞춰 접합 | 프레임간 cloud identity/빛/카메라 일관성, 압축·seek·정지·역스크롤 |

①도 품질 있는 도입부로 제작하며 ②는 정지 이미지를 영상처럼 표현한 것으로 대체하지 않는다. 현재 callable 영상 생성 도구/실제 영상은 확보하지 않았다. 조건 발동 후 사용 가능한 생성 경로 또는 사용자 영상 입력을 구체적으로 점검한다.
최종 판단은 질감·양감·빛·움직임·접합·프로젝트 개연성 중심이며, 실기 성능/seek가 체감을 훼손하는지도 함께 비교한다.
