### S1 — 지형 접합을 먼저 수정

높이·법선·색·재질 반응에 일관된 경계 가중치를 적용할 수 있는지 확인한다. 실제 변형 geometry의 normal과 동일 광원 좌표를 사용한다. 화면에 들어오는 지형은 최소 부모 relief로 채우고, 고해상도 자식만 점진적으로 기여하게 한다. SSE/예측 로딩/히스테리시스와 연속 geomorph를 우선 검토한다. 단계 수 증가만으로 불일치가 해결됐다고 간주하지 않는다. alphaHash로 다시 자글거림을 만들지 않는다.

**산출물:** 기준/수정 비교 4구도 이상, 구름 ON/OFF, 실제 휠 정역 영상. **통과:** 정상 관람 크기에서 직선 사각 테두리·모서리가 식별되지 않고, 정역 이동에 높이 계단·툭 생성·구멍이 없다. 승인된 능선 디테일과 1.5×를 유지한다. 구름 ON에서만 숨겨지면 지형 통과가 아니다. 일부 남으면 위치와 강도를 TUNE으로 기록한다.

### S2 — 구름의 국소 입체 광학

고정 coverage/UV/태양을 유지하고 필요한 두꺼운 군집에만 높이 H·광학 두께 tau와 국소 조명 후보를 부여한다. 얇은 층은 지면이 비치고 섬세한 결을 유지한다. H/tau는 연출용 근사이며 사진에서 측정한 밀도가 아니다. 기존 D113 공식/업계 연구와 Takram 소스에서 실제 지원 경로를 확인한 후 평면/높이·광학 proxy/국소 volume 후보를 같은 구도로 대조한다.

**통과:** 두꺼운 군집의 밝은 면·어두운 면이 읽히며 얇은 구름과 구름 틈의 지면이 유지된다. 원경 전체가 부풀거나 타원 덩어리·플라스틱 면·넓은 흰 막으로 보이면 TUNE. 가까이 갈수록 필요한 디테일만 증가한다.

### S3 — 새 원경 그림자 기여 검토

원경 구름 높이와 world-space 태양 방향으로 지면 투영을 설계한다. 같은 지면 위치에서 카메라만 바꿔 그림자 방향·위치 정합을 확인한다. 이 작업은 기존 근경 그림자 결함 추적 보류와 분리한다.

**통과:** 구름과 그림자가 같은 방향 관계를 유지하고 카메라 중심을 따라 이동하지 않는다. 사각 암부를 새로 만들지 않는다. 필요성이 낮으면 명시적으로 보류한다.

### S4 — 동일 구름군의 원경→근경 전이

광역/지역 확대/접근/커튼빛/가장자리 통과/서고 가림의 6구도를 고정한다. p=.235/.265/.300/.345/.365는 초기 샘플이며 실제 인계 구간에 맞춰 보완한다. 같은 footprint·태양·지형에서 far/near 기여와 밝기·투과를 연속 연결한다. TAA reset/누적 조정은 실제 잔상 진단 이후 적용한다.

**통과:** 새 구름이 툭 생기거나 다른 지형으로 바뀌지 않고 이중 밝기·흰막 점프가 없다. 실제 휠 전진/역진/중간 정지와 20~30초 영상에서 커튼빛과 지형 위치가 이어진다.

### S5 — 성능·움직임 검증

1280×720 비교와 사용자 실제 viewport를 구분한다. 동일 경로에서 frame time/FPS·composer GPU p50/p95·context/error·resident texture 예산을 기록한다. 잠정 데스크톱 목표는 60fps/16.7ms frame budget이며 사용자 확정 또는 보장값이 아니다. 총 GPU query와 실제 frame time은 별개다. 10.7MiB는 구름 텍스처 명목값이지 총 GPU 메모리가 아니다.

**통과:** 실제 정역 경로에서 재현 가능한 오류·새 자글거림·뚜렷한 잔상·프레임 정지가 없다. 잠정 budget 미달이면 품질을 몰래 낮추지 않고 비용/품질 대조안을 제시한다. 다른 PC와 장시간 검증은 별도 미검증으로 남긴다.

### S6 — 서고 연결과 사용자 리뷰

S1/S2/S4의 자체 검증 뒤 승인된 서고 공간·소품·빛으로 연결한다. 구름 가림은 실제 장소 전환에 사용한다. 사다리/인체/ECG와 Story는 각 파트의 별도 게이트를 유지한다.

**통과:** cloud→서고 화면 점프가 없고 승인된 서고가 보존된다. 실제 렌더 정지/움직임을 함께 사용자에게 제시하고 KEEP/TUNE/REJECT를 기록한다. 자체 기술 PASS는 사용자 품질 승인으로 승격하지 않는다.
