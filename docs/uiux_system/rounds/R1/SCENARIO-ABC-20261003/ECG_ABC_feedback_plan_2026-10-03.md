## 2. 산출물의 역할을 분리하는 방법

이 파일은 **순서와 상태의 색인**이다. A는 v2에 남기고 B·C는 각각 별도 씬 문서에서 수정한다. 시스템 v3는 모든 후보에 공통으로 적용하는 규칙만, 마이닝 보고서는 실제 레퍼런스의 관찰/기술/재료만 담는다. 예를 들어 `B2 틈이 너무 좁다`는 B 문서를 수정하고, `레퍼런스에 없는 효과를 원본에서 본 것처럼 서술했다`는 시스템과 해당 REF 카드를 수정한다. 하나의 수정이 두 파트에 영향을 줄 때는 작업 ID를 상호 링크하며 완료 상태를 각각 갱신한다.

**이미지 생성 상태:** 사용자 지시대로 보류. 이번에는 새 목업을 생성하지 않았다. 참고 사이트의 실제 화면 캡처는 분석 근거로만 저장했다.

1. **SYS-01 / VAL-01 규칙 반영 — 완료:** 도입부·Story 연출 자유도, 원본/확장 구분, 결과 기반 게이트, 신규 아이디어 루프를 기록.
2. **MIN-01 레퍼런스 마이닝 — 범위 내 완료:** Editorial New 실제 DOM/소스, 현재 Lusion의 히어로와 공간/타이포, My Little Storybook의 같은 공간 카메라/대사, Igloo의 실제 첫 공간과 제작자의 입자 메커니즘을 분석. 아직 직접 못 본 구간은 보고서에 명시.
3. **AB-TUNE / B-01 / B-02 보완 — 초안 완료:** A/B 수정 항목을 각각 작성. B를 원본 재현과 독자 확장으로 분해해 상세 프레임을 작성. A는 v2 + A-T 수정 명세로 검토.
4. **C-01 새 시나리오 — 초안 완료:** 레퍼런스에서 실제 확인된 입체 물성/공간 전환과 제작자에게 확인된 입자 재형성에 기반해 C를 작성.
5. **A/B/C 공동 검토 및 제작 전 아이디어 — 현재:** A/B/C 각각 신규 파형·전환 카드와 TUNE 항목을 함께 검토하고, 사용자의 유지/수정/보류 사항을 해당 씬에 반영. **제작 순서**와 각 안의 재사용 가능 부분을 확정.
6. **최종 시나리오 피드백 → 목업:** 선택한 안의 핵심 프레임 4장과 연결 장면을 생성하고 구도·빛·물성·주제 전달을 검토. 목업 수정도 안별 기록.
7. **구도와 전환 예비 동영상:** 정지 목업만으로 알 수 없는 카메라/가림/형태 변화를 회색 재질의 짧은 프리비즈로 확인. 해당 씬의 와우와 인과가 살아 있는지 판정.
8. **핵심 효과 구현 → 사용자 피드백 → 확장:** 아래 §4 순서를 선택 안의 씬마다 반복. 원격 제품 구현은 A/B/C 순서 결정 후의 단계.

레퍼런스 조사에서 단순 소개글로만 확보한 후보를 ‘완료’로 만들지 않는다. 이번 보고서의 완료는 **명시한 분석 구간**의 관찰·기술 분리와 ECG 번안까지다. 원본 효과의 모든 입력/시점과 전체 페이지의 완전 재현 검증은 이후 제작 카드의 별도 작업이다.

| **C-LIGHT** | 자체 발광 리본과 환경광 분리, 처리 배열의 밝은 모서리·어두운 골·입자 수광면 명시 | C3–C5 처리 방향/재형성 시험. 효과의 의미와 퀄리티를 따로 판정 |

세 후보의 보완은 [A·B·C 조명 씬 명세](ECG_ABC_lighting_scene_spec_2026-10-04.md)에 따로 기록했다. **A/B는 TUNE, C는 새 제안**이다. 이번 “진행”은 첨부 분석과 설계 반영을 진행하는 것으로 기록하며, 후보 선택·제작 순서·최종 시나리오 피드백 완료로 확대하지 않는다. CLOSE-01은 종료 유지.

순서: **LIGHT-01/SYS-LIGHT 설계 기록(완료) → A/B/C 신규 파형·전환 카드 및 장면·자세 검토 → 해당 씬 수정 → 제작 순서 검토 → 선택 안의 최종 시나리오 피드백 → 목업 → clay/짧은 프리비즈 → 해당 씬 구현 → 사용자 피드백 → 신규 연출 2–3개 제안 → 영향 구간 재검증.** 현재 진행 브랜치의 승인된 서고 조명 작업과 후보 선택 작업은 별도 상태로 추적한다.

목업·새 제품 구현·실제 조명 렌더 검증은 이번에 수행하지 않았다. 문서의 파라미터 예시는 초기 시험값이며, 실제 크기·엔진·카메라에 맞춰 조정한다.
