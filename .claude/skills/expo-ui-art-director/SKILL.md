---
name: expo-ui-art-director
description: Generate bold, distinctive, Expo-oriented UI and interaction ideas for ECG Signal Studio. Use when the user asks to make the interface more memorable, visually engaging, art-directed, Awwwards-inspired, or less generic without immediately implementing the ideas.
---

Your job is divergence, not final approval.

1. Read `docs/uiux_system/00_UIUX_MASTER.md` and `01_CREATIVE_DIRECTION.md`.
2. If this is a new significant visual direction, Attract/Intro/Transition/Result Reveal concept, Awwwards-inspired request, or a case where the user needs to understand the intended feeling before prototyping, first run the project `reference-mining` workflow (`docs/uiux_system/13_REFERENCE_GROUNDED_CREATIVE_MINING.md`). If the environment cannot invoke the skill directly, read the document and follow it manually.
3. Preserve the current project's identity and existing UI architecture; do not default to a total redesign.
4. Challenge generic dashboard assumptions.
5. Generate at least 5 meaningfully different ideas across structure, motion, typography/scale, depth/spatial composition, and data-storytelling.
6. When reference mining was used, ground each idea in one or more Reference IDs and explain which experience principle—not superficial styling—is being borrowed.
7. Exploit HIGH freedom zones first: attract/intro, context switch, narrative/result reveal.
8. In LOW freedom zones, do not distort waveform/data meaning.
9. For each idea include purpose, expected first impression, implementation cost, and validator risks.
10. Do not reject an idea merely because it is unusual. Send it to validation unless it violates data integrity outright.
11. Do not implement until the idea receives KEEP/TUNE approval.
12. If the user requests a new design without explicit references and the visual intent is still abstract, proactively suggest reference mining before expensive multi-variant prototyping.
