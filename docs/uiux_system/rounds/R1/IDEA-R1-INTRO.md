### B8 공통 감각 (U10)

- Lenis 하나(duration 1.2–1.6), ScrollTrigger scrub 1, pin. 모든 값은 진행률의 함수 → 되돌리면 역순 복원.
- 프레임률 무관 감쇠 `x += (목표 − x)(1 − e^(−dt/τ))`.
- 마우스: τ ≈ 0.35 s, 카메라 ±2–3°, 층별 깊이(심장 1.0, 파형 0.3, 문구 0.15). 파형은 기울이지 않고 평행이동만.
- 선택 아이디어 **V1**: 스크롤 속도 충격 — 휠을 굴리면 지구 기본 회전이 잠깐 빨라졌다 0.7 s에 걸쳐 돌아온다(EFX-001-04 방식). 지구 구간에만.
- 정지 상태에도 "살아 있음": 심장 박동·잔광·마우스 추종이 계속.

| 근육 잡음 | 사다리 위로 올라 높은 칸의 상자를 꺼내며 옆대를 쥠 | 무거운 기록 상자를 들어 올림 | 쥠 형태 키 + RA 빨간 고리(F-030 규칙) |

### 13.4 주의
1. 한 화면에 사람은 **항상 한 명**(겹쳐 보이는 순간 없음), 모습·전극 같음 → 같은 사람으로 읽혀야 함.
2. 재배치 횟수는 4번 이하, 매번 같은 문법(숨은 컷 우선).
3. 재배치는 왕복의 "멀어짐" 절반을 대신 — 스크롤 길이를 늘리지 않는다.
4. 자세·자리는 연출이며 오른쪽 파형은 저장값 — 화면에 "장면 연출" 표시, 자세가 데이터의 측정 조건이라고 말하지 않는다(데이터 계약).
5. 거꾸로 스크롤해도 같은 숨은 컷으로 되돌아감.
6. 자세마다 메시·전극 위치·선 경로가 따로 필요(빌드 비용) → 자세 5개가 상한.
7. 빛 라운드와 맞물림: hero 갈래 하나로 모든 자리를 비출 수 없으므로 **자리마다 빛 서명**(첫 등장 = 발치의 낮은 갈래, 측정 = hero 창, 전원 = 책상 스탠드(이것도 전기 기기), 기저선 = 창가 확산광, 근육 = 높은 칸의 강한 갈래).
