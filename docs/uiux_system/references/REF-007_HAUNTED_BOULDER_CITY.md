### EFX-007-01 현재 항목만 채워지는 대형 목록 (외곽선 → 채움 + 앞으로 16 px + 세로선)

**선정 이유**: 사용자 지목("가운데 오는 글귀가 마치 앞으로 튀어나오듯 강조되다가 위로 올라가면 다시 원상복귀", 17–22 s) `[대화]`, 재사용 메커니즘(긴 목록을 지루하지 않게 읽히는 법).
**지각**: 거대한 좁은 대문자 제목들이 지그재그로 쌓여 있다. 화면 가운데에 온 제목만 속이 꽉 찬 밝은 글자로 바뀌며 살짝 앞으로(오른쪽으로) 나오고 왼쪽에 금색 세로선이 길게 자란다. 지나간 제목과 다가오는 제목은 속이 빈 외곽선이라 뒤로 물러나 보인다. 아래에서 들어오는 제목은 흐리게 떠오른다. 배경 사진이 현재 주제에 맞게 바뀐다.
**입력 모델**: 문턱 발동(스크롤 위치로 "현재 항목"을 고르면 CSS 전환이 시간으로 실행).
**판별 근거**: `renderHighlights()` — 매 스크롤 프레임에 각 항목의 `rect.top + 0.4·높이`와 화면 52 % 높이의 거리가 가장 작은 항목에 `is-current` `[코드]`. 녹화 17.5–22.5 s: 한 번에 한 항목만 채워짐 `[영상]`.
**구현 메커니즘**:
```

h3 기본: color transparent, -webkit-text-stroke 1px #c0ccb9, translateX(−16px)
h3.is-current: color #e7e9d8, stroke 투명, translateX(0)
```

### EFX-007-02 양방향 흐림 등장 + 테마 전환 섹션

**선정 이유**: 사용자 지목("25초 부근에선 윗부분과 테마가 다르다는 느낌이 팍 들 수 있게 다른 효과를 적용했지? 이번에는 글자가 스크롤을 내림에 따라 fade in") `[대화]`.
**지각**: 사진이 깔린 어두운 장면에서 단색 초록 면으로 바뀌며, 가는 가로선과 양 끝의 작은 고정폭 라벨이 먼저 보이고, 거대한 제목과 살짝 기운 사진이 흐린 상태로 아래에서 떠올라 선명해진다. 위로 되돌리면 위쪽으로 빠졌던 요소는 위에서 다시 내려온다.
**입력 모델**: 문턱 발동(요소가 12 % 보이면 CSS 전환 시작).
**판별 근거**: `.reveal`: opacity 0, blur 12 px, translateY 45 px → `.in-view`에서 0으로, 전환 opacity 0.9 s ease · filter 1.1 s · transform 1.1 s cubic-bezier(.2,.75,.25,1). IntersectionObserver threshold 0.12, rootMargin 아래 −25 px. 화면을 완전히 벗어나면 `in-view`를 빼고, 위로 나갔으면 `from-above`(translateY −45 px) `[코드]`. 녹화 25.2–27.3 s에서 "COLD BEER." 흐림 → 선명 `[영상]`.
**구현 메커니즘**:
```
enter observer: threshold .12, rootMargin "0px 0px -25px 0px" → add .in-view
exit observer : threshold 0 → 완전히 나가면 remove .in-view, top < 0 이면 .from-above
.reveal            {opacity:0; filter:blur(12px); transform:translateY(45px)}
.reveal.from-above {transform:translateY(-45px)}
.reveal.in-view    {opacity:1; filter:blur(0); transform:none}
사진은 같은 규칙 + rotate(1deg) 유지
섹션 머리: 1 px 선(#35463d) + 양 끝 SpaceMono 12 px 라벨("03 / …", 오른쪽 문구)
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 흐림 | 12 px → 0, 1.1 s | `[코드]` |
| 이동 | ±45 px → 0, 1.1 s cubic-bezier(.2,.75,.25,1) | `[코드]` |
| 투명도 | 0 → 1, 0.9 s ease | `[코드]` |
| 발동 | 12 % 보임, 아래 25 px 여유 | `[코드]` |
| 표면 | #192a23 단색, 사진 기울기 1° | `[코드]` |
**타임라인**: 문턱 통과 → 0.9–1.1 s 전환. 스크롤을 멈춰도 끝까지 진행.
**에셋**: 없음(CSS).
**성능 기법**: filter blur는 전환하는 동안만. 관찰자 두 개로 양방향 처리.
**접근성·폴백**: reduced-motion이면 `.motion-ready`가 붙지 않아 처음부터 보임 `[코드]`.
**근거**: `[코드]`, `[영상]`, `[대화]`.
**재현 요구사항**: IntersectionObserver 2개 + CSS. 난이도 하.
**수용 기준**: (1) 12 % 보일 때 시작, 1.1 s 안에 완료. (2) 위로 나갔다 돌아오면 위에서 내려온다. (3) 테마 전환 섹션은 배경·선·라벨이 제목보다 먼저 보인다.

### EFX-007-03 읽는 위치를 따라 켜지는 단어

**선정 이유**: 사용자가 말한 "글자가 스크롤을 내림에 따라 fade in"의 두 번째 구현 형태, 재사용 메커니즘(긴 설명문을 읽게 만드는 법).
**지각**: 문단의 단어들이 처음엔 흐리고 옅다가 스크롤하는 만큼 앞에서부터 차례로 선명해진다. 되돌리면 뒤에서부터 다시 흐려진다.
**입력 모델**: 스크롤 위치.
**판별 근거**: `readProgress = clamp((0.9·innerHeight − top) / (높이 + 0.05·innerHeight))`, 단어 i는 `readProgress > i / 단어 수`이면 `.visible` `[코드]`.
**구현 메커니즘**:
```
문단의 텍스트 노드를 단어 span으로 쪼갬(공백은 그대로)
.word {opacity:.22; filter:blur(3px); transition: .25s}
.word.visible {opacity:1; filter:none}
매 스크롤 프레임: p = clamp((0.9vh − rect.top) / (rect.height + 0.05vh)); 단어 i visible ⇔ p > i/N
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 흐린 상태 | opacity 0.22, blur 3 px | `[코드]` |
| 전환 | 0.25 s | `[코드]` |
| 읽는 구간 | 문단 윗변이 화면 90 %에 올 때 시작, 문단 높이 + 5 vh 동안 | `[코드]` |
**타임라인**: 문단이 화면 아래 10 %를 지나면서 시작, 문단이 거의 다 올라오면 전부 켜짐.
**에셋**: 없음.
**성능 기법**: class 토글만(단어 수백 개 이하).
**접근성·폴백**: reduced-motion이면 쪼개지 않음(처음부터 전부 보임) `[코드]`. 스크린 리더는 원문 그대로.
**근거**: `[코드]`.
**재현 요구사항**: 텍스트 분할 + 스크롤 진행률. 한국어는 어절 단위로 쪼갠다. 난이도 하.
**수용 기준**: (1) 켜진 단어 수 = ⌊p·N⌋ + 1 이내. (2) 되돌리면 역순.
**ECG 번안**: 도입부 부제·끝 문장("같은 심장, 같은 기록 — …")이나 잡음별 장면의 한 줄 설명에 쓴다. 파형 교차(X4)의 진행률과 같은 p를 쓰면 "문장이 켜지는 만큼 신호가 깨끗해진다"로 묶을 수 있다.
**재현 상태**: `none`

### EFX-007-04 가로 pin 장(章) 넘김: 사진은 글자 속도의 55 %, 장 사이에만 안개

**선정 이유**: 녹화 14–16 s의 장면 전환 방식, 재사용 메커니즘(단계형 이야기의 장 넘김).
**지각**: 화면이 고정된 채 사례 파일 세 장이 가로로 넘어간다. 글자 판은 빨리, 뒤 사진은 느리게 반대로 밀려 깊이가 생긴다. 넘어가는 동안에만 안개가 끼었다가 읽는 동안에는 걷힌다.
**입력 모델**: 스크롤 위치.
**판별 근거**: `render()` — `p = (y − storyTop)/storyTravel`, `stage = 2p`, 장마다 `transition = clamp((fraction − 0.16)/0.68)`에 smoothstep, 트랙 `translateX(−position·폭)`, 사진 `shift = clamp(position − i, −1, 1)·폭·0.45`(= 글자의 55 % 속도), 안개 opacity `sin(π·transition)²·0.58` `[코드]`.
**구현 메커니즘**:
```
p ∈ [0,1] over pin; stage = 2p; segment = min(1, floor(stage)); fraction = stage − segment
transition = smoothstep(clamp((fraction − .16) / .68))   // 앞 16 %·뒤 16 %는 멈춤(읽는 시간)
position = segment + transition;  track.x = −position·W
photo_i.x = clamp(position − i, −1, 1)·W·0.45          // 반대 방향 → 화면 속도 55 %
mist.opacity = sin(π·transition)²·0.58;  mist.x = (1 − 2·transition)·8 %
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 장 수 | 3 | `[코드]` |
| 멈춤 구간 | 각 전환의 앞·뒤 16 % | `[코드]` |
| 사진 상대 속도 | 0.55 | `[코드]` |
| 안개 최대 | 0.58 | `[코드]` |
**타임라인**: 장마다 읽기(멈춤) → 넘김(smoothstep) → 읽기. 안개는 넘김 한가운데 최대.
**에셋**: 장별 사진·영상, 안개 텍스처.
**성능 기법**: transform 두 종류(트랙·사진), 안개는 opacity만.
**접근성·폴백**: 작은 화면은 세로 배치 + 약한 세로 시차로 바꿈, reduced-motion은 이동 없음 `[코드]`.
**근거**: `[코드]`, `[영상]`.
**재현 요구사항**: pin 구간 + 진행률 분할. 난이도 중.
**수용 기준**: (1) 장 사이 멈춤이 스크롤 거리의 32 %. (2) 사진 속도 = 글자의 55 %. (3) 안개는 멈춤 동안 0.
**ECG 번안**: 잡음별 장면(전원 간섭 → 기저선 변동 → 근육 잡음) 세 장을 넘기는 구조로 쓸 수 있다. "읽는 멈춤" 동안 파형이 재생되고, 넘기는 동안만 안개(잡음 느낌)가 끼게 하면 장 전환이 주제(잡음)와 이어진다.
**재현 상태**: `none`

## 8. 성능·접근성·폴백

- 모든 효과가 transform·opacity·filter와 class 토글이다. filter blur는 전환 중에만.
- reduced-motion: 관성 스크롤·등장·단어 분할·시차 모두 끔. 터치 기기는 관성 스크롤 끔.
- 우리 환경 주의: 헤드리스(소프트웨어 렌더)에서는 Canvas 2D 블러가 매우 느렸다(O-006). DOM의 CSS blur는 합성 단계에서 처리되지만 전시 PC에서 측정 필요.
