# CASE-007. 시나리오 피드백이 연출 범위와 레퍼런스 검증을 바꾸다

2026-10-03 · D-050 / F-033 / R-020 · 문서·조사 결과, 제품 구현 전

## 배경

## 논의 흐름
1. **문제 → AI 응답:** 이전 v2는 와우·구도·검증을 담았지만 Intro까지 파형 왜곡을 제한하고 Editorial New의 기록물 표현을 3D 틈 진입으로 확장했다. 이전 판단은 해당 v2 문서를 보존한다 [재구성].
2. **사용자 반론:** "파형이 왜곡되지 않는 게 필수적인건 이후 비교 패널에서만", "카메라가 ... 틈 안으로 들어간다는 느낌을 눈으로 확인하질 못했어" [대화]. 사용자는 더 자세한 B 프레임, 추가 마이닝, 지금 C 제작, 제작 중 게이트 보완을 요구했다.
3. **판단 변화:** 공개 코드/브라우저가 F-031을 확인했다. B의 카메라 진입은 독자 확장으로 정정하고 Intro/Story 스펙터클 자유도를 높였다. 정확 비교 경계는 따로 유지.
4. **추가 질문:** "A,B 안 모두 TUNE 대상 ... 고칠 부분" [대화]. 긍정 평가와 전체 채택을 구분해 A-T1–7/B-T1–7을 제안했다.
5. **시스템:** 파트별 ID/상태/순서, 원본과 확장 증거, 실제 캡처 뒤 신규 아이디어, 결과 기반 게이트를 문서화. C는 신호 입자 처리실로 작성, 사용자 검토/순위/최종 피드백 이후 목업으로 연결.
