# ECG GUI v2.2 — 와이어프레임 검토안

작성: 2026-09-11. 상태: **W1–W10 배치안 작성 및 정적 자체 검수 완료 / 사용자 검토 대기**.

기준: [v2.1 기능 계획](12_expo_gui_plan_v2_1_final.md), [v2.2 전시 계획](13_expo_gui_plan_v2_2_final.md). [화면별 보드](wireframes/index.html)는 실행 앱이 아닌 설계 도면이다. 격자는 파형 공간 예약이며 실제 ECG나 방법 출력이 아니다. 원본 S5 GUI와 중단 전 v2 코드는 변경하지 않았다.

## 1. 이번에 결정할 공간 구성

**기본 발표 화면은 전체 폭의 두 파형과 하단 방법 목록을 쓴다. 상세 설명을 요청할 때만 오른쪽 패널을 연다.** 기본 시선은 잡음 입력 → 선택 방법 출력으로 향한다. 같은 Reference가 두 행에 회색으로 겹쳐지고, 시간축·mV 범위가 같다. method 이름을 읽기 위해 파형을 작게 만들지 않는다.

W1–W10은 열 개의 독립 메뉴가 아니다. 발표 화면의 상태·펼침·기기별 배치다. 상위 진입점은 기존 분석 앱과 `발표 화면 열기`이며, 발표 화면 안에서 재생/정밀 비교/근거로 깊어진다. 발표 종료 시 원래 선택·시각·고정 구간·메모로 돌아온다. 브라우저 전체화면 API는 선택 기능이며 큰 보기의 필수 조건이 아니다.

## 3. 화면별 역할과 동작

### W1 — 재생 보기

화면 질문: “같은 잡음 입력을 이 방법으로 처리하면 어떻게 다른가?” 첫 시선은 입력과 출력의 형태다. Reference는 중립 회색으로 두 행에 같은 opacity를 적용한다. 범례에 `Reference: 전처리된 기준 신호`와 정의로 가는 링크를 둔다. 실제 clean 측정값과 무잡음 정답이라는 강한 주장을 자동으로 붙이지 않는다.

상단 조건 요약은 **현재 표시 중인 장면**을 가리킨다. SNR은 자료가 있는 discrete 값만 선택한다. noise 친화 문구는 실제 catalog의 noise code와 매핑하며, 없는 NSTDB 조건을 합성 잡음으로 대체하거나 같은 이름으로 표시하지 않는다. 현재 98조건은 두 axis × 기존 7 noise presets × 7 SNR이며, 모든 물리적 noise 부분집합 조합을 새로 정의했다는 뜻은 아니다.

하단 rail은 대표 5개 내외 + 전체 방법 + Pin이다. 정확한 대표 ID는 모든 축에서 자료가 준비된 비교군을 확인해 정한다. 이름/family/비교 목적의 일관성을 우선하며 “최고 방법” 자동 선택은 하지 않는다.

### W2 — 정밀 비교·Reference

`현재 구간 고정`은 현재 관찰 구간을 연속 시간축으로 펼치고 시계를 멈춘다. 단순 Pause는 Sweep의 이전/현재 주기 공간 배치를 그대로 멈춘다. 두 동작을 같은 버튼이나 동일 상태로 취급하지 않는다. 고정 시작·끝은 source sample index로 보존한다.

Reference 강도 35/55/75%는 표시만 바꾼다. 방법 변경에도 구간·진폭 범위를 유지한다. 현재 Reference가 없으면 이유를 표시하고 overlay 및 Difference를 비활성화한다. 그 상태에서 clean을 추정해 넣지 않는다.

오른쪽 패널은 선택 방법 이름/family → 프로젝트 비교 목적과 짧은 원리 → 한계/파라미터/출처 순이다. 긴 설명은 이 패널 내부에서만 스크롤한다. 현재 작업에서는 기법 해설 자체의 확대 집필을 진행하지 않는다.

### W3 — Reference와 차이

Difference Lens는 **Output − Reference**이며, 원래의 제거 성분 **Input − Output**과 다르다. 복구 코드의 residual을 이름만 바꿔 재사용하지 않는다. zero line·mV 단위·display gain ×1/×3/×5를 항상 읽을 수 있어야 한다. 실제 오차값과 metric 계산은 확대하지 않는다.

W2의 두 파형 높이는 280px로 유지한다. 차이 strip은 y=844–924에 추가하고 timeline/transport를 아래로 옮긴다. 방법 선택은 오른쪽에서 계속 가능하다. 차이의 gain/범례는 오른쪽에 두어 64px 내부 plot을 텍스트가 차지하지 않게 한다.

Pin과 Difference를 동시에 켠 경우 1080p 안에 전부 축소해 넣지 않는다. Pin을 보존한 채 expert 영역을 아래로 펼치고 명시적으로 스크롤하며, 전체를 한 번에 보기 원하면 사용자가 Pin을 해제한다. 자동 Pin 해제는 금지한다.

### W4 — 지속 A/B 비교

`현재 방법 고정` 시 선택 방법을 pinned 슬롯에 복사하고 세 번째 행을 만든다. 이후 클릭은 selected만 변경한다. selected와 pinned가 같으면 중복 데이터임을 표시하고 “다른 방법을 선택해 비교”를 안내한다. pinned가 몰래 바뀌어 비교 대상이 사라져서는 안 된다.

hover/focus는 selected 행에 후보 점선을 임시로 겹친다. selected metric·행 제목·pinned 행을 후보로 바꾸지 않는다. 범례에는 `미리보기: 후보명`을 별도로 둔다. 이탈/Escape로 preview만 제거한다. 자료가 없으면 미리보기를 그리지 않는다. 대형 창과 기본 창 모두 같은 규칙과 시각을 사용한다.

1080p는 내부 200px씩 확보한다. compact 3행은 내부 180px 이상을 보존하고 파형 영역의 세로 스크롤을 허용하는 검토안이다. 기본 발표는 2행 A/B 전환이며, 3행을 강제로 보여주는 선택은 발표자에게 남긴다. 3행+Difference의 동시 가독성은 실제 기기에서 별도 검수한다.

### W5 — Attract

대표 장면을 8–12초 반복한다. `REPLAY · 전시용 구간 반복`을 표시하여 600초 연속 자료 재생과 구분한다. 이 반복을 10분 데이터 확보 근거로 사용하지 않는다. hover만으로 인계하지 않고 의미 있는 클릭·터치·키 입력에 반응한다.

인계 시 record/noise/SNR/method/source index를 유지하고 관람객 CTA를 noise 선택 하나로 바꾼다. 아직 준비된 대표 장면이 없으면 Attract를 켜지 않는다. idle reset은 별도 opt-in(기존 180초 + 10초 취소 유예 설계), 발표 중 억제, 미저장 메모 보존, Escape/의미 있는 입력으로 취소한다. idle 복귀로 LIVE를 켜거나 데이터를 지우지 않는다.

### W6 — 시연 장면·북마크

상시 `시연 장면` 버튼 하나를 제공한다. 열면 현재 재생을 멈추고 A/B/C의 목적을 고른다. 취소는 같은 장면·시각으로 돌아가며 진입 전 재생 중이었다면 그때만 재개한다. 실제 조건/구간이 검증되기 전의 시작 버튼은 비활성이다.

A는 강한 잡음에서 전후 차이 설명, B는 고전/DL 비교, C는 약한 잡음에서 보존/과처리 가능성 설명이다. **B에서 DSP가 반드시 이기고 C에서 과처리가 반드시 발생하도록 구간을 고르지 않는다.** 출력과 무관한 입력·Reference 규칙으로 선택하고, 설명 목적이 실제 결과와 맞지 않으면 그 사실과 선정 규칙 수정 여부를 기록한다. 개인 북마크와 공식 시연 장면은 분리하고 provenance를 보존한다.

### W7 — 로딩·누락·실패

보드는 pending/error/missing의 세 장으로 분리했다. 상태 모델은 `displayedScene`과 `requestedScene`을 구분한다. 새 선택을 눌렀다고 현재 행 제목을 먼저 바꾸지 않는다.

1. 마지막 유효 시각에서 Pause. 기존 파형·Reference·범례·선택 표시·metric을 그대로 둔다.
2. 하단 예약 영역에 “새 조건 준비 중: …”만 표시한다. 변경된 선택지에는 `요청 중` 상태를 별도로 둔다.
3. 요청 ID, source/condition/method, chunk 범위와 hash를 확인한다. 오래된 요청 응답은 폐기한다.
4. 준비 완료 시 현재 sample range의 모든 필수 trace·metadata·metric을 한 번에 교체한다. 다른 길이 자료로의 seek가 필요하면 새 범위를 명시한다.
5. 실패/누락이면 이전 유효 장면 유지. Retry/요청 취소/다른 방법 선택을 제공한다. 취소는 이전 장면으로 확정하며 자동 다른 방법 대체는 하지 않는다.

자동 재개는 사용자 요청 직전 재생 중이었고 그 사이 사용자가 Pause/Inspect를 선택하지 않은 경우에 한한다. 요청 대기 중 발생한 추가 사용자 의도가 우선한다. 아직 **첫 유효 장면이 한 번도 없을 때**는 파형 없는 초기 loading/error 화면과 작동하는 재시도 경로를 쓴다. 없는 “이전 파형”을 만드는 예외는 허용하지 않는다.

### W8 — Compact

조건·방법을 44px 높이 선택기로 접고 실제 plot 내부 204px를 확보한다. 타임라인의 선은 40px 슬롯에 들어가지만 포인터 hit area는 transport와 겹치지 않도록 최소 44px를 확보한다. sidebar를 열어 폭을 과도하게 줄이지 않고 필요할 때 전문 정보 sheet를 연다. sheet가 파형을 가리는 동안 시계는 Pause한다.

최소 테스트 조합은 실제 콘텐츠 크기 1366×768, 1920×1080 및 OS/browser 배율로 높이가 더 줄어든 경우다. 폭뿐 아니라 유효 높이를 기준으로 compact 또는 스크롤 배치를 고른다. 창이 작으면 전체를 축소해 작은 글자로 만드는 방식은 쓰지 않는다.

### W9 — Hover 없는 체험

기본 CTA는 “어떤 잡음을 넣어볼까요?”다. 3–4개의 noise chip과 전체 선택을 제공한다. SNR·method가 사라지는 것은 아니며 보조 펼침에서 접근 가능하다. 기술 관람객 시연에서는 CTA를 방법 선택으로 바꾸고 noise chip rail을 방법 rail로 교체한다. 두 선택을 동시에 주요 과제로 요구하지 않는다.

터치는 탭 즉시 선택, Pin 탭 지속 비교다. “한 번 탭 미리보기, 두 번 탭 선택”은 사용하지 않는다. 키보드 focus도 preview 접근을 제공하지만 Enter/Space 전에는 selected를 변경하지 않는다. 툴팁은 필수 정보의 유일한 경로가 아니다.

### W10 — 근거·질의 응답

오른쪽 근거 패널 616px를 열고 현재 파형·구간을 보존한다. scope 탭은 설명문과 population을 함께 바꾼다.

| Scope | 범위 | 표시 조건 |
|---|---|---|
| Local | 지금 고정한 연속 sample interval | 구간을 명시; 재생 중 실시간 숫자 경쟁처럼 흔들지 않음 |
| Session | 현재 record/조건의 완전한 600초 | 자료·유효 구간·결측 처리 검증 후 표시 |
| Experiment | 별도 전체 평가의 records/조건/집계 방식 | 현재 장면과 source/version이 다르면 명시 |

첫 펼침의 큰 수치는 검증된 Session ΔSNR 후보 하나다. 없으면 `검증된 Session 지표 없음`과 이유를 표시한다. Local/Session/Experiment 값을 비어 있다는 이유로 서로 복사하지 않는다. strict/scaled 정의, Reference 정의, model/config/source 해시, 처리의 offline/causal 특성은 provenance에서 확인한다. 실제 AFE bridge가 검증되지 않은 상태에 LIVE 배지를 표시하지 않는다.

## 4. 모션 및 전환 계약

| 동작 | 전달할 의미 | 제안값 | 중단/대안 |
|---|---|---|---|
| Hover/focus preview | 클릭 전 비교 후보 | intent 120ms; 점선 표시 | 이탈/Escape 취소; 터치는 선택/Pin |
| 클릭 피드백 | 요청 접수 | 80–120ms | 자료 완료와 구분; 선택 라벨 조기 교체 금지 |
| Sweep 지우기 경계 | 이전 주기 샘플 제거 | blank 0.12s + fade 0.08s | reduced motion에서 feather 제거; 샘플 위치 동일 |
| 상세 펼침 | 비교→설명 관계 | 180–220ms, 1회 | 즉시 취소/0ms 대안; 매 프레임 추론 결과 morph 금지 |
| 조건 교체 | 새 유효 자료 도착 | atomic swap | 이전/새 파형 crossfade 금지 |
| 정밀 비교 | 연속 시간 구간 확보 | Pause 후 정렬 | 원 source index 보존; 과거/현재 Sweep 접점 연결 금지 |

Sweep의 fade는 **기존 주기 선의 지우기 경계에만** 적용한다. 전체 파형 투명도나 긴 잔상으로 바꾸지 않는다. 새 샘플은 timestamp 위치에 즉시 나타나고 끝에서 왼쪽으로 돌아온다. Scroll은 최신 샘플이 오른쪽에 오고 과거가 왼쪽으로 이동한다. 확대 창도 하나의 playback clock을 사용한다. 화면 전환으로 별도 시계가 생기지 않는다.
