## 0. 개념 — "기록 보관소의 한 기록"

이 전시가 보여 주는 것은 **저장된 기록**(실시간 장치 아님, 데이터 계약)이다. 그래서 무대를 **심전도 기록 서고**로 둔다: 천장까지 닿는 서가에 기록 상자·바인더·말린 심전도 용지가 빽빽하고, 그 사이 사다리에 한 사람이 걸터앉아 있다. 높은 창 블라인드 틈으로 든 햇빛이 쪼개져 서가와 사람을 가로지른다. 관람자는 "보관된 수많은 기록 중 하나 — S038"을 꺼내 보는 셈이다. 공간 은유가 데이터 정직성(저장값)과 같은 말을 한다 `[추론]`.

## 2. 빛

- 주광: 해(따뜻한 노랑, 원반 1.2°) — 블라인드 살 사이 → 서가 틈 → 통로·사다리·사람. 해 깊이 지도로 레이마칭(다락방 spike 방식) → **갈래 빛줄기 + 먼지**가 실제 창살·서가 모양을 따름.
- 고리 몸: 해 깊이 지도를 읽어 **빛 갈래에 든 고리 조각만 따뜻하게 밝음**(IDEA-R1-INTRO §10.5). 심장은 스스로 박동.
- 굽기: 서가·책·바닥·벽·소품 직접+간접광(다락방 방식, 조명 이미지 + 고밀도 소품은 정점 색).
- 그늘: 매달린 등 2개의 약한 따뜻한 빛, 나머지는 깊은 그늘(대비).

## 4. Story 시나리오 (같은 서고, 장면마다 카메라 서명 — IDEA-R1-NOISE §7–8 갱신)

공통: 원인 막 → 이분할(왼쪽 사람·원인, 오른쪽 파형 무대) → 처리 막(모니터 "박동마다 한 겹") → 다음. 현재 잡음원만 색, 나머지는 채도 낮춤(E1 잠정 — 사용자 선택 전).

### 전원 간섭 — 추적 + 크레인
| s | 카메라 | 보이는 것 |
|---|---|---|
| 0–.1 | 심장에서 뒤로 빠짐 | 사다리 위 사람 중경 |
| .1–.2 | 사다리를 돌아 왼쪽으로 60° 궤도 | 사다리 아래 책상 위 브라운관 모니터·컴퓨터가 시차로 드러남(원래 있던 것을 "발견") |
| .2–.3 | 모니터 뒤 전선을 따라 바닥으로 낮게 추적 | 전선이 통로 바닥을 지나 서가 L1 굽도리 콘센트로 |
| .3–.38 | 콘센트 극근경 | 말풍선 + 교류 사인(사용자 안), 사인 빛이 전선을 거슬러 오름 |

| .5–.55 | 세 번째 물결이 가슴에 닿는 박동에 휩 줌 | 사람 상반신이 왼쪽 45 % |

### 끝 — 요약
서가 꼭대기로 크레인 업 → 통로 전체가 내려다보이는 원경(세 원인 자리가 각자 은은히 켜짐) → 책상 모니터로 밀고 들어가 Lab 화면이 되는 match cut.

자세 근거: S1(사다리 걸터앉기)에서 "주먹"은 **사다리 옆대를 쥐는 손**으로 자연스럽게 바뀐다 — 근육에 힘을 주면 잡음이 생긴다는 메시지가 동작으로 읽힘 `[추론]`.

## 6. 데이터 계약

방·빛·소품은 장식. 모니터·심전도 기계 화면과 용지에는 **파형을 그리지 않는다**(가짜 신호 금지) — 빈 격자 용지만. 모니터는 Story에서 "박동마다 한 겹" 진행만 표시.
