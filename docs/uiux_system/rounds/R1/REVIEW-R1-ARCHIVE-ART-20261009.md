# R1 서고 — 다락방 레퍼런스(REF-002)와의 미술적 차이 분석과 수정 포인트 (검토, 2026-10-09)

상태: **검토 문서 — 확정 수정 방향 아님**(사용자 `[대화]` "이건 검토할 작업이야. 확정 수정 방향은 아니야."). 사용자가 고른 항목만 D 기록 후 구현한다.

입력:
- 사용자 녹화 두 개(2026-10-09): 우리 도입부(Signal Studio, 24.8 s), 레퍼런스 leoparpeix.com 다락방(18.7 s).
- 사용자 정지 이미지 1장(빨간 상자 = 날카로운 빛 경계, 파란 상자 = 반사광으로 경계가 옅어진 책장).
- 비교 시트 `verification/r1-archive-art-review-20261009/ref_vs_ours_tone.jpg`. 레퍼런스 프레임은 분석용이며 에셋이 아니다.

## 0. 사용자가 짚은 것 (요지 `[대화]`)

1. 원본은 사다리를 옆으로 세워 내려오게 해 깊이 차이를 줬다. 정옆이 아니라 몇 도 기울여 가로대 사이가 보이게 했다. 우리는 다가가는 시점이라 이 느낌이 덜하다.
2. 사다리 뒤 배경 책장에 햇빛이 비치지 않는다 → 빛이 배경 책장에 닿도록 공간을 고치자.
3. 원본은 액자·블록 조각을 두고, 책을 기울이거나 눕히거나 비워 둔다. 반복의 지루함을 없애고 빛이 들어올 자리를 다양하게 만든다.
4. 질감이 파스텔톤이라 맑다. 메시는 단순한데 책 깊이가 다양해 그림자가 또렷하다.
5. 빛 처리: 경계가 확실한 곳(천장, 사다리 아래 바닥, 오브제)과, 반사광 때문에 경계가 옅은 곳(오른쪽 책장)이 한 화면에 같이 있다. 이것이 가장 중요할 수 있다.
6. 빛 커튼은 우리가 더 좋다. 다만 반짝임만 키우면 대비만 세지므로, 여러 빛 상호작용 중 하나로 두고 싶다.

## 6. 사용자에게 고를 것
