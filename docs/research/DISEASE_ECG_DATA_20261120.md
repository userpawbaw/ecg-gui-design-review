# 질환 파형 데이터 조사 (2026-11-20)

사용자: 「심장 질환 관련 특이 파형을 보여주는 사이트를 이전에 레퍼런스 조사 때 봤던 것 같은데, 이런 질환 관련 파형 데이터가 있는지 조사 … 질환 파형 + 노이즈를 우리 처리 기법으로 처리해서 보여주는 (+해당 질환 파형의 특징 설명) 기능의 추가를 검토」.
상태: 조사 · 제안(구현 결정 전). 이 저장소의 레퍼런스 기록(REF-001…010, `17_REFERENCE_SOURCE_REGISTRY.md`)에는 질환 파형 사이트가 남아 있지 않다 — 이전에 본 사이트는 `기록 없음`.

## 1. 바로 쓸 수 있는 것 — MIT-BIH 부정맥 DB (이미 원본 저장소의 D1 축)
- 라이선스 ODC-By 1.0(출처 표시), 48기록 × 30분, 360 Hz, 심장 전문의 박동 · 리듬 주석. 원본 저장소가 이미 받아 쓰고(`ecgdn/data/mitdb.py`), 브리지 재생(`replay_signal.py --signal mitdb:NNN`)과 실험실 자료 생성 경로가 있다.
- DL 기법 학습 분할(`ecgdn/data/splits.py`, de Chazal DS1/DS2): 학습 101 106 108 109 112 114 115 116 118 119 122 124 201 203 205 207 209 215 · 검증 208 220 223 230 · **시험 100 103 105 111 113 117 121 123 200 202 210 212 213 214 219 221 222 228 231 232 233 234** · 인공 박동기 102 104 107 217(제외). 전시는 시험 기록만 쓰면 학습 누출이 없다.
- 시험 기록 중 질환 후보(MIT-BIH 기록 설명 기준 `[기억 — 구현 전 .atr 주석으로 재확인]`): 좌각 차단 111 · 214 / 우각 차단 212 · 231 / 심방세동 · 조동 202 · 210 · 219 · 221 · 222 / 심실 조기 수축 · 이단맥 200 · 233 / 2도 방실 차단 231 / 동서맥 · 긴 휴지 232 / 정상 동리듬 100 · 103 · 113 · 117 · 121 · 123.
- 원본 저장소의 기존 근거: EXP-E 안전성 프로브(`docs/07_safety_probe_d1.md`) — PVC 박동 형태 보존(V − N 상관 차이 +0.01…+0.03, 모든 기법이 PVC를 정상 모양으로 「교정」하지 않음), 박동 · 3 s 무수축 구간에 가짜 QRS를 만드는지(M06 · M08 낮음).

주의: 원본 기법(특히 DL)은 MIT-BIH 단일 유도로 학습 — PTB-XL · LUDB 12유도는 분포 밖(OOD)이라 결과를 「성능」으로 표시하면 안 된다(AGENTS: 실제 성능 오표시 금지). ST 분절은 고역 통과(공통 전처리 0.5 Hz)에 민감 — 오히려 전시 메시지가 될 수 있으나 측정 후에만.

## 3. 교육용 사이트(링크 · 참고만, 자산 복사 금지)
LITFL ECG Library(질환별 해설 · 예시), ECG Wave-Maven(Harvard BIDMC, 사례 중심). 설명 문구는 우리가 쓰고 출처를 단다.

## 4. 기능 방향(사용자와 고를 것)
- A. 새 탭 「질환 파형」: 질환 카드(정상 · 심방세동 · PVC · 좌/우각 차단 · 방실 차단 · 서맥 …) → 잡음 · SNR · 기법 선택 → 실험실과 같은 비교 화면 + 특징 설명 + 주석 표시(예: PVC 박동 위 표시, 심방세동은 R–R 불규칙 · P파 없음).
- B. 실험실에 「기록(리듬)」 축 추가: 화면 · 코드 재사용이 가장 크고 탭이 늘지 않는다. 설명은 장면 머리글 + 접는 상자.
- 공통: 특징이 처리 뒤에도 남는지(PVC 형태 상관, QRS 폭, R–R 불규칙도)를 미리 재서 「보존 / 훼손」으로 보여 주면 이 프로젝트의 질문(잡음 제거가 진단 정보를 지우는가)과 이어진다. 심박 카드(D-188)는 심방세동에서 「신호 불안정」이 되는 것이 오히려 맞는 동작 — 설명에 활용.
- 표시 원칙: 「교육용 · 진단 아님」, 주석 출처(MIT-BIH 전문의 주석) 표기.

## 5. 질환별 분류 사이트의 정보틀(2026-11-20 추가 조사, 사용자 「질환별로 분류해놓고 보여주는 사이트 … 목적에 적합한 정보틀」)
조사한 구성: LITFL ECG Library(ECG 진단 목록 → 질환 쪽: 정의 · ECG 특징 · 기전 · 임상 의미 · 예시 여럿), Alan E. Lindsay ECG Learning Center(Utah, 리듬 이상을 상심실성 · 심실성 · 박동기로 묶음, 「측정 → 리듬 → 전도」 순서 판독), Healio ECG Library(질환 아래 예시를 심박 범위별로 묶음), ECGpedia · ECGbook(교과서식 장 구성), SkillStat Six Second ECG(리듬 약 27개를 Ⅱ유도 6초 띠로 돌려 보며 맞히기).

**분류(위계)** — Utah · LITFL 공통 골격을 전시용으로 줄임:
1. 정상과 동리듬 변이(정상 · 동서맥 · 동빈맥)
2. 심방(상심실성) 부정맥(심방 조기 수축 · 심방세동 · 심방 조동)
3. 심실 부정맥(심실 조기 수축 · 이단맥 · 심실 빈맥 · 심실 세동)
4. 전도 차단(방실 차단 1 · 2도 · 좌/우각 차단)
5. 허혈 · 경색(ST 상승 · 하강, T파 변화)
6. 기타(인공 박동기 등 — 전시에서는 선택)

**질환 한 장(카드)의 항목** — LITFL 쪽 구성 + 이 프로젝트에 필요한 것:
| 항목 | 내용 | 출처/근거 |
|---|---|---|
| 이름 · 한 줄 정의 | 「심방이 불규칙하게 떨려 맥이 불규칙해지는 리듬」 | 우리 문장(교과서 확인) |
| 파형 특징 체크리스트 | 판독 순서(Utah): 심박수 · 리듬(R–R 규칙성) · P파 · PR · QRS 폭/모양 · ST/T | 각 항목을 파형 위 주석으로 짚음 |
| 실제 예시 띠 | 6–10 s, 전문의 박동 · 리듬 주석으로 특징 위치 표시(예: V 박동, AFIB 구간) | DB 주석(지어내지 않음) |
| 잡음을 넣으면 | 같은 띠 + 잡음(종류 · SNR) — 특징이 가려지는 모습 | 실험실과 같은 합성 |
| 처리하면 | 기법별 출력, 특징 보존 측정(PVC 형태 상관 · QRS 폭 · R–R 불규칙도 · ST 높이) | 원본 EXP-E 방식 확장 |
| 심박 표시 | D-188 카드가 어떻게 반응하는지(심방세동 → 「신호 불안정」 등) | 실측 |
| 임상 의미(한 줄) | 교육 수준, 진단 아님 | 표기 필수 |
| 데이터 출처 | DB · 기록 번호 · 라이선스 · 학습 분할(시험 기록인지) | 출처 · 규약 대화상자와 같은 방식 |

**질환 → 데이터 대응(초안)**: 1 · 2 · 4 · 3(PVC)은 MIT-BIH 시험 기록, 3(심실 빈맥 · 세동)은 vfdb, 5(ST)는 edb 또는 PTB-XL(12유도 중 Ⅱ유도). 1 · 2 · 4는 단일 유도로 충분, 5는 유도 의존이 커서 「이 유도에서 보이는 것」으로 한정.
