## 동기화 검증 (사용자 요구 U7)

`prototype/v2/browser-tests/intro.spec.ts` — 반복 두 바퀴, R 30개 모두에서:
- sweep 머리의 표본 = 그 R 표본
- 심장 발광이 그 프레임에서 최대(> 1.25), 한 프레임 전에는 없음(< 0.6)
- 수축은 R 프레임에서 시작(그 전 0)

결과: 2 PASS(동기화, 라벨·Lab 진입). 기존 e2e(story·expo) 5 PASS + 1 SKIP(10분 soak — replay 자료 없음, 이전과 같음). v2 단위 테스트 18 PASS / 1 FAIL(600초 chunk 자료 없음, 이전과 같음).

처음 실행에서 동기화 테스트가 실패했다: sweep 머리는 `floor(t·fs + 1e-6)`, 박동은 실수 시간 비교를 써서, R 표본이 그려지는 프레임에 심장이 아직 직전 박동으로 판정될 수 있었다(부동소수 오차). 박동도 같은 정수 표본 기준으로 바꿔 해결했다.
