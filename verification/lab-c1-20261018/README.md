# 실험실 서고 C1 — 경로에서 거꾸로 계산한 천창, 잎 그림자, 램프 제거 (D-077) — 2026-10-18

사용자 요청:
- 경로 셋(C1·C2·C3)을 옵션으로 만들되, 오래 걸리면 C1부터 커밋한다.
- 빛 커튼은 두 번 지난다.
- 선명한 그림자와 반그림자가 적절한 비율이 되게 한다. 서고 조명 세션 결과를 함께 검토해 잎 그림자와 천장 구멍·창을 정한다.
- 오로라는 S1부터 하고, S1+M은 다음 단계로 미룬다.

## 만든 것
- 경로 C1(Blender): (0.15, −3.4, 3.3) → (0.25, −1.2, 2.4) → (0.3, 1.0, 0.95). 시선은 뒷벽 서가다. `?path=c1`(기본) | `c3`(D-074 하강).
- 천창 다섯. 앞 보 칸의 둘은 통과용이고, 상자 모형 광선 검사에서 진행 21–27 %, 56–64 %에 빛 안이다. 나머지 셋은 볕 면적용으로, 오른쪽 책장 끝면과 뒷벽 서가 두 곳을 비춘다(D-077 표).
- 해 크기 1.2° → 0.5°. 서고 조명 세션과 같다.
- 잎 덩이 다섯: 뒤쪽 천창 둘·셋째 칸 천창 위, 왼쪽 벽 창 두 곳 밖. 가지 줄기와 뾰족한 잎이며 `decor` 그룹이라 웹 빛기둥도 같은 잎으로 얼룩진다.
- 통로 램프 둘과 전구를 뺐다(실험실 변형만). 대신 노출을 ×1.8로 올렸다.
- 굽기 509 s, 9.23 MB. `prototype/v2/src/story/intro/assets/archive-sun35/`를 교체했다.
- 오로라 S1: `?aurora=`(0–100, 50 = 설계값). 빛 단면의 잎·줄 무늬가 위치마다 다른 위상으로 흔들린다. `?silk=`는 없앴다.
