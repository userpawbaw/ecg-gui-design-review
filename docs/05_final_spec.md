# ECG Signal Studio · 최종 GUI 구성 명세

버전 1.0 · 2026-09-09 · 대상: `prototype/`. 이는 저장 실험 결과를 사용하는 인터랙티브 프로토타입의 확정 구현 명세다. 실제 AFE 연결·새 모델 추론·임상 형태 보존 검증의 완료를 뜻하지 않는다. 검증 결과와 남은 실행 환경 조건은 [검증 보고서](07_verification.md)에 구분한다.

## 1. 설계 결론과 강조할 프로젝트 가치

사용자가 먼저 답할 질문은 **“같은 입력에서 무엇이 줄고 무엇이 변했는가?”**다. 입력→공통 FE→두 비교 출력의 같은 시간·mV축을 첫 관찰 대상으로 삼는다. 선택 방법을 바꾸면 원리·한계와 실제 저장 출력이 함께 바뀐다. 파형이 매끈해졌다는 인상은 strict/scaled SNR, 최적 배율 α, 구간 확대를 통해 다시 확인한다.

다음 질문인 “다른 기록에서도 성립하는가?”는 전체 근거 화면에서 다룬다. 계측의 질문은 “지금 실제 장치 신호를 받고 있는가?”이므로 별도 작업 공간으로 분리한다. 결과의 범위와 실패 원인이 다른 정보를 같은 대시보드 수치처럼 배열하지 않는다.

| 결정 | 채택 이유 | 사용자가 얻게 되는 것 |
|---|---|---|
| 실험실·전체 근거·계측의 3 작업 공간 | 국소 파형·전체 집계·참조 없는 스트림은 근거 계약과 작업 수명이 다름 | 화면을 바꾸면 질문과 데이터 범위가 함께 바뀐다는 인식 |
| 방법 해설과 구간 확대는 실험실 내부 | 같은 입력에서 동시에 봐야 하는 정보 | 설명을 읽거나 확대해도 비교 문맥 유지 |
| 출처·검토 기록·진단은 다이얼로그 | 잠깐 확인하고 원래 작업으로 돌아오는 보조 과업 | 주요 파형 폭 확보, 명시적인 닫기와 복귀 |
| 발표 보기는 같은 실험실의 표현 모드 | 발표용 데이터나 숨은 최고 성능 사례를 새로 만들 필요 없음 | 현재 조건 그대로 더 넓은 파형 |
| 병리·실험 실행·상세 분포는 연결 조건을 남김 | 필요한 annotation·run·개별 통계가 현재 export에 없음 | 존재하지 않는 증거를 성공 화면으로 오인하지 않음 |

새 화면은 기존 화면의 부족함뿐 아니라 **별도 질문, 다른 근거·시간축, 독립적인 실패·복구 흐름** 때문에 추가할 수 있다. 향후 annotation이 연결되면 병리 검토를 독립 작업 공간으로 추가하는 것이 타당하다. 현재 조건을 바꾸지 않는 residual은 패널로 유지한다.

## 2. 기본값·정보 우선순위·배치

첫 실행은 D1 / mixed / 주입 10 dB / 선택 M08 / 비교 M04 / 3.0–4.2초 / ±2 mV / dual 보기다. 자동 재생하지 않는다. 이 값은 시작점이며 최우수 사례 선정 주장이나 사용성 실험 결과가 아니다.

| 층 | 실제 구성 | 의도 |
|---|---|---|
| 전역 | 로고, 작업 공간 3개, 현재 출처 유형, 검토 기록, 출처·규약 | 위치·근거 확인과 짧은 보조 작업 |
| 과업 설명 | 한 문장 질문, 발표 보기 | 프로젝트 가치를 기능명보다 먼저 설명 |
| 조건 | D0/D1, 7 잡음, SNR 슬라이더+7단계 버튼, 현재 record | 조작 원인과 현재 입력 정체성을 가까이 배치 |
| 핵심 | 어두운 파형 패널, 공통 진폭, 비교 후보, 커서, 범례 | 같은 조건의 변화에 시선 집중 |
| 선택·해설 | 오른쪽 방법 목록과 원리·한계 | hover 탐색과 클릭 고정을 구분 |
| 증거 | 전체 10초 지표, 입력/FE 대비 차이, EXP-G 조건 평균 | 시각적 인상을 수치·집계로 재확인 |
| 세부 | 시간 선택과 두 비교 그래프, 구간 지표 | 전체에서 고른 같은 구간을 검토 |

기준 설계 폭은 1440px이며 최대 콘텐츠 폭은 1640px이다. 전체 문서가 세로 스크롤된다. 950px 이하는 방법 패널을 아래로 재배치하고, 700px 이하는 dual 그래프를 위·아래로 쌓는다. 1190px 이하 일반 분석 보기에서는 구간 해설을 그래프 아래에 배치한다. 1920×1080, 1440×900, 1024×768, Windows 배율·200% 확대의 실제 픽셀 검수는 별도 미완료 항목이다.

배경은 밝은 중성색, 데이터 패널은 짙은 청회색이다. 입력 주황, FE 회청색, 비교 후보 파랑, 고정 선택 청록, 참조 보라 점선이다. 청록은 **선택 출력**을 뜻하며 정상 ECG·성능 합격의 의미가 아니다. 색 외에 행 이름·범례·선 모양·선택 문구를 함께 제공한다. 웹폰트와 아이콘 CDN을 요청하지 않는다.

## 3. 실험실의 구체 동작

### 입력과 비교

현재 데이터는 2축 × 7잡음 × 7 SNR = 98 저장 장면이다. SNR은 −5, 0, 5, 10, 15, 20, 25 dB다. 25 dB는 이 장면 집합에 있으며 EXP-A 주 결과표의 −5…20 dB 범위와 구분한다.

조건 선택은 이미 저장된 배열을 읽는다. 가짜 inference 진행률, 연속 보간된 방법 출력, 결과가 좋아지는 방향으로의 파형 morph를 사용하지 않는다. 같은 축·잡음에서 SNR만 바꾸면 record·segment가 유지되며 잡음 크기만 바뀐 저장 사례로 이동한다. 잡음 종류 또는 축을 바꾸면 record가 바뀔 수 있으므로 출처 줄과 알림에 새 record를 표시한다.

파형은 입력, 공통 FE, 추가 비교 후보, 선택 출력의 최대 4행이다. 후보가 선택 출력이나 FE와 중복되면 중복 행을 줄인다. 선택 M_FE에서도 FE 행을 유지한다. M00은 입력과 같은 값을 내는 identity 기준으로 제공한다. 출력 행에는 같은 참조를 점선으로 겹친다.

### 방법 탐색

기본 목록은 M00, M_FE, M01, M04, M05, M06, M08이다. 추가 목록은 M02, M03, M06L6, M09, B01이다. 총 12개를 선택할 수 있다. M07·M10은 원본 프로젝트에는 있지만 이 장면 export에 출력이 없어 비활성화 사유를 보여준다.

마우스 hover 또는 키보드 focus는 설명과 노란 점선 미리보기만 바꾼다. 고정 선택, 현재 구간, 성능 지표는 바꾸지 않는다. 클릭하면 선택을 고정하고 해설·출력·지표를 함께 갱신한다. hover를 벗어나면 고정 방법의 설명으로 돌아온다.

M05=Sameni EKF/EKS, M06=Residual U-Net, M08=Wavelet-subband U-Net, M09=CNN+Transformer, M10=Dilated ResNet으로 교정했다. M07은 SWT를 먼저 적용한 뒤 U-Net으로 전달하는 순차 구조이며 M08과 다르다. 원본 정본은 [registry](https://github.com/userpawbaw/ECG_denoising_method_comparision/blob/5eb27946087faca3c6e70b3925e2ba132b2ee680/ecgdn/registry.py)와 [종합 보고서](https://github.com/userpawbaw/ECG_denoising_method_comparision/blob/5eb27946087faca3c6e70b3925e2ba132b2ee680/docs/91_report.md)다.

### 구간·진폭·재생

- 파형 클릭은 클릭 시점이 선택 구간 중앙이 되도록 이동한다. 숫자 입력과 ±0.5초 버튼도 제공한다. 길이는 0.6/1.2/3초다. 경계를 넘으면 `[first, lastExclusive)` 표본 구간으로 보정한다.
- dual 보기는 같은 출력에 대해 입력 대비 변화와 참조 대비 차이를 나란히 보여준다. 좁은 화면에서는 위·아래 배치다. 참조 확대와 제거 성분 보기로 전환할 수 있다.
- 제거 성분은 `input − output`이다. 참조와 다른 ECG 성분이나 기준선도 포함될 수 있으므로 전부 제거된 잡음이라고 부르지 않는다.
- 진폭은 모든 행과 상세에 동일하게 적용한다. “범위 맞춤”은 입력·FE·참조·두 후보의 최대값을 보고 공통 범위를 정한다. residual 보기에서는 제거 성분도 포함한다. 행별 자동 정규화와 화면 파형의 α 보정은 하지 않는다.
- 범위 밖 표본은 그릴 때 자르고 개수를 알린다. 이는 **뷰포트 범위 밖**이라는 뜻이며 ADC clipping 실측값이 아니다. 기본 파형의 개수는 중복 표시된 참조까지 포함한 표시 표본 수다.
- 커서는 저장 배열 위를 1× 속도로 10초 동안 한 번 이동한다. 경과 시간은 `performance.now()` 기준이다. 하드웨어 timestamp나 새 샘플 수신을 나타내지 않는다. 중지, 화면 이동, 문서 숨김 시 멈춘다.

### 지표의 범위

참조·입력·출력은 **각각 평균을 제거한 뒤** 계산한다. `r`을 참조, `o`를 출력이라고 할 때 strict SNR은 `10 log10(sum(r²) / sum((r−o)²))`이고 α는 `sum(r·o)/sum(o²)`다. scaled SNR은 오차의 출력을 `αo`로 바꾼다. 파형 자체는 이 배율로 바꾸지 않는다. reference가 상수이거나 자료가 잘못되면 지표를 계산하지 않는다.

| 위치 | 값 | 범위·주의 |
|---|---|---|
| 전체 10초 카드 | 출력 strict/scaled SNR, α, CC | int16 복호화 파형의 국소 재계산. 카드의 SNR은 개선량이 아닌 출력 SNR |
| 기여 문장 | 선택 strict − 입력 SNR; 선택 strict − FE strict | 전체 파이프라인 변화와 FE 이후 추가 차이를 분리 |
| EXP-G 접이식 표 | 현재 `scaled−input SNR`, 저장 조건 평균 | 같은 축·잡음·SNR의 참고 평균. export에 없는 n·CI·분포는 생성하지 않음 |
| 확대 구간 | RMSE(mV), CC | 선택한 부분만, 평균 제거 규칙 동일 |
| 전체 근거 | EXP-A record-level mean/std/median/n | 현재 장면과 다른 실행·집계 범위 |

α는 잔여 잡음에도 영향을 받는 최소제곱 배율이며 R 진폭 오차율이 아니다. CC 또는 scaled SNR 하나로 병리 보존을 합격 처리하지 않는다. D1 참조는 `FE(x_raw)`인 대역 제한 참조이며 완전히 깨끗한 환자 ground truth라고 부르지 않는다.

## 4. 전체 근거

고정된 EXP-A D1 주 실험 L1 결과를 보여준다. TEST 22 records, mixed noise, −5…20 dB의 record 단위 집계다. 방법·변형·oracle 포함 16행에 대해 scaled SNR 개선 평균을 막대와 수치 표로 제공한다. 막대의 공통 길이 범위는 0–20 dB이며 exact 값은 같은 행에 적는다. n은 각 행에 제공한다. 표준편차를 CI로 명명하지 않는다.

M00·M_FE 기준선을 포함하고 B01/B02는 참조를 사용하는 oracle로 표시한다. 실제 장치에 배포할 후보로 추천하지 않는다. 현재 장면과 EXP-A 표의 차이를 그대로 빼거나, EXP-G L6를 EXP-A L1과 짝지어진 동일 실험처럼 묶지 않는다.

오른쪽 해설은 FE 기여, 보정 후 수치의 의미, 형태 지표의 한계를 설명한다. D1 QRS duration floor p95=28.072 ms는 원본 조건의 검출·참조 오차 기준이다. 모든 지표의 보편적 오차막대나 동등성 구간이 아니다. 이 화면에서 우승·임상 적합을 자동 판정하지 않는다.

## 5. 계측과 명시적 Replay

기본 상태는 `NO DEVICE SESSION`이다. 포트·유실 수·지연을 가짜 값으로 채우지 않는다. 상태 선택기는 미연결/워밍업/전극 접촉 해제/표본 유실/FE 변경의 **UI 시연**이다. 네트워크 요청과 실제 SSE 연결을 시작하지 않는다.

“저장 파형 표시”를 눌러야 별도의 Replay 영역이 열린다. 실제 보관 입력과 선택 출력을 사용하며 `REPLAY · 장치 연결 없음`을 파형 옆에 계속 표시한다. 장치 통계는 계속 미측정 상태다.

| 상태 시연 | Replay 표현 | 무엇을 검토하는가 |
|---|---|---|
| 미연결 | 사용자가 연 경우 저장 입력·출력 2행 | 저장 자료와 실제 수신의 구분 |
| 표본 유실·lead-off | 4–5초 구간을 가리고 invalid 시연 문구 | 연결하면 안 되는 구간의 시각 표현. 실제 기록의 유실 사실은 아님 |
| 워밍업·FE 변경 | 저장 입력만 유지, 이전 출력 숨김 | 준비 전 출력을 현재 결과로 표시하지 않는 규칙 |
| 상태 변경·Replay 닫기 | 커서 정지 | 숨은 재생·오래된 상태 방지 |

“진단 상세”는 PORT→FRAME→DECODE→BUFFER→RENDER의 확인 순서와 미확인 상태를 설명한다. source bridge는 존재하지만 이 프로토타입에 연결하지 않았다. `/stream`에 접속된 사실만으로 LIVE를 표시하지 않는다. 구체 어댑터 계약과 필요한 실측은 [팀 가이드](06_team_guide.md)에 있다.

## 6. 상태·상호작용 계약

중앙 상태는 `workspace, axis, noise, snr, method, comparison, start, length, amplitude, view, playing, presentation`이다. 메모는 검토 창의 textarea, 계측 시나리오는 selector 상태에 있다. 새로고침 후 상태 복원은 구현하지 않았으며 내보낸 JSON은 수동 재현용이다.

| 입력 | 유지할 것 | 바뀌는 것·실패 처리 |
|---|---|---|
| 방법 클릭 | 입력·참조·시간·진폭 | 선택 출력·설명·지표; 손상 출력은 대시, 다른 방법 사용 가능 |
| 비교 후보 변경 | 선택 방법·지표·입력·구간 | 추가 비교 행과 EXP-G 표 |
| SNR 변경 | 같은 axis/noise의 record·segment | 해당 저장 입력·출력, 명목값; 커서 정지 |
| 잡음/축 변경 | 방법·구간·진폭 | record 변경 가능, 출처 줄/알림 갱신 |
| 보기 전환 | 입력·방법·시간·진폭 | dual/overlay/residual 렌더와 설명 |
| 작업 공간 이동 | 실험실 문맥 | 다른 근거 범위, 커서 정지; 복귀해도 자동 재생 안 함 |
| 발표 보기 | 조건·비교·선택·지표 | 방법 목록을 숨기고 파형 확장; 분석 보기로 복귀 |
| 입력/참조 파일 오류 | 선택 조건은 재시도에 이용 | 이전 파형·지표·record 비우기, 오류·재시도 표시 |
| 출처/검토 기록 닫기 | 직전 상태 | 트리거 버튼 focus 복귀 핸들러. native 동작은 브라우저 검수 필요 |

버튼의 기본/hover/focus/pressed/selected/disabled, 오류 alert, 짧은 status를 제공한다. 저장 배열 교체에는 별도 loading 상태를 만들지 않는다. 실제 비동기 inference를 연결하면 run별 processing/cancel/stale/partial-failure 상태를 추가해야 한다.

모션은 버튼 색·테두리·그림자와 status opacity의 120ms 전환, 사용자가 시작하는 재생 커서다. 방법 설명·파형 좌표는 즉시 갱신한다. 패널이 미끄러지는 장식적 모션과 파형 사이의 수치 보간은 없다. `prefers-reduced-motion`에서는 CSS 전환을 제거한다. OS 설정과 native focus·Escape 동작은 아직 실기 확인하지 않았다.

## 9. 납품·후속 구현 경계

- 현재 제공: 최종 프로토타입 코드, 독립안 동결본, 비교 문서, 요소별 팀 가이드, 실제 저장 배열, 수치/DOM 검사, 단일 HTML 빌드, 재개 로그.
- 별도 검증 필요: 실제 데스크톱 렌더·키보드·배율·스크린리더, 다운로드 동작, 장시간 성능.
- 별도 구현 필요: 최신 코드로 bank 재생성, annotation/분포·checkpoint·run metadata export, 실제 bridge adapter, source/session 확장, 장치 현장 시험.
- 도입 판단 대기: 자동 attract/idle reset, 실제 sweep/scroll의 ring-buffer 표현, 물리 다이얼, 병리 전용 작업 공간, 비동기 실험 실행. 모두 의미와 근거가 생겼을 때 추가한다.

이 명세의 완료 조건은 화면 수가 아니라 선택·출처·범위·오류 규칙이 구현과 설명서에서 일치하는 것이다.
