## 바뀐 것
- **머리 B2**: A 자신의 머리(안구 포함)를 2 mm 부피로 바꿔 닫기 → 열기(귀 제거) → 흐림(얼굴 앞 더 강하게). 두개골·이마·광대·턱·코의 면은 A 그대로, 눈·입·콧구멍·귀 없음. 계란형 폐기.
- **리그**: Rigify 사람 메타리그(얼굴 뼈 없음)를 A에서 잰 관절·손가락 중심선에 맞춰 생성. 위팔·아래팔 변형 뼈 2개씩. 팔·다리는 IK 손/발 목표 + 극 목표 + 손 방향으로 잡음.
- **자세**(사용자 레퍼런스 2026-10-04):
  - 바닥: 오른 무릎 세움 + 오른 아래팔이 무릎을 가로질러 손이 무릎 너머로 늘어짐, 왼 다리 접어 바닥에, 왼손은 발목, 고개 숙임
  - 사다리: 오른손 위 가로대(6번째), 왼손 가슴 높이(4번째), 왼 무릎 들어 1번째 가로대, 오른발 0번째, 위를 봄. 손가락은 마디마다 가로대 축에서 거리를 맞춰 감음(마디 가운데 ↔ 축 27–31 mm = 봉 반지름 19 + 손가락 반지름)
  - 의자·책상·벽: 이전 의도 그대로 새 리그로
- **의자**: 서고의 의자 메시에 광선을 쏴서 좌면 0.427 m·등받이 방향을 잼 → 엉덩이 최저점을 좌면에 놓음. 이전 "0.44 m, 20° 돌림"은 짐작이었고, 실제 의자는 `place()`의 회전이 적용되지 않아 돌아가 있지 않았음(아래 참고).
- **사다리(r2)**: 가로대를 둥근 봉(반지름 19 mm)으로. 사다리 자세의 0번째 가로대 = 서고의 첫 가로대(0.29 m).
- **구도(두 번째 시안)**: 책상 컷에 멀티탭·전원선이 들어오게 카메라 이동, 근육 장면에 쥔 오른손 + RA 전극 근접 컷 `d7_climb_close` 추가.
