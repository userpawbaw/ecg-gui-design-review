모두 1600 × 900, SwiftShader, 전체 모드(해상도 0.6, 마우스 시점)다. 아래 저전력 모드를 넣기 전에 찍었다. 노트북(GPU)에서 보일 모습에 가깝다.

## 구성
- `prototype/v2/src/labBackdrop.ts`: 서고(도입부 `createArchive`)를 고정 캔버스에 그린다. 빛기둥 후처리 한 패스를 쓰고, 해 그림자 지도는 한 번만 그린다.
- 카메라 경로: 서가 위 내려다봄 → 빛줄기 높이 → 통로 눈높이(s3_aisle) → 차분한 서가(i1_wide).
- 마우스: ±5° + 옆으로 ±0.12 m.
- `main.tsx`: 실험실 맨 위에 한 화면 높이의 하강 구간(`.lab-hero`)을 두었다. 그 구간을 스크롤하는 정도가 하강 진행이다.
- 하강이 끝나 갈수록 어두운 막(`--lab-veil` 0.08 → 0.58)이 덮여 글자·조작부를 읽기 쉽게 한다.
- 어두운 테마. 배경색은 문서 루트에 둔다. body에 두면 z-index −1 캔버스를 덮는다(첫 시도에서 화면이 검게만 나옴).
- `?bg=0`: 배경 끄기. `?bgres=`: 해상도 배율.

## 노트북 예산과 측정
- 카메라가 바뀔 때만 그린다. 초당 30번 이하다.
- 화소 상한 120만, 크기 변경은 150 ms 기다렸다 한 번 그린다.
- 파형 재생 중이거나 크게 비교 창이 덮고 있으면 그리지 않는다.
- 소프트웨어 렌더(SwiftShader·llvmpipe 등)를 감지하면 저전력 모드다. 마우스 시점이 없고, 해상도 0.35배, 스크롤이 멈춘 뒤 한 번 그린다.
- 측정(SwiftShader): 배경 전체 모드에서 실험실 차이 테스트가 45 s 한도를 넘었다. 배경을 끄면 11.6 s였다. 원인은 테스트 클릭마다 일어나는 마우스 시점 애니메이션(프레임당 약 1 s)과 스크롤마다의 다시 그리기였다. 저전력 모드 뒤 14.7 s로 통과했다.
- 초당 30번 상한을 처음 넣을 때 그릴 것이 없어도 다음 프레임을 계속 예약하는 결함이 있었고, 테스트 전에 고쳤다.
