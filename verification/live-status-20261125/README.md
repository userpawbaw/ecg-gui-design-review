# 실시간 탭 상태 줄 한 줄 고정 (2026-11-25)

사용자: 「상태창이 계속 쌓이는게 산만 … 너무 많이 쌓이면 파형창이 위아래로 오르내리니 더 그래. 연결됨, 실시간 처리 한계 초과, 처리 결과 몰림 이 셋 이외는 아이콘으로 놔둬. 무슨 일이 있더라도 상태 표시창이 두 줄과 한줄을 오르내리게 하지 마.」

- 글자 칩: 연결됨 · 실시간 처리 한계 초과 · 처리 결과 몰림(설명은 짧게 「화면 +0.8 s」). 나머지(신호원, 연결 끊김 · 확인 중, 브리지 밀림, 수신 간격 불규칙, 가벼운 계산(누르면 원래대로), 알림 문구)는 오른쪽 아이콘 — 설명은 마우스를 올리면.
- `.live-status`: 줄바꿈 없음 · 높이 38 px 고정 · 넘치면 잘림.
- `status.cjs`: 정상 · CPU 8배 감속 20 s 동안 높이 38 px 하나. `status_worst.cjs`: 글자 칩 3개 + 아이콘 6개를 넣고 폭 1600 · 1100 · 800 px 모두 38 px(`status_all.png` — 위: 정상, 아래 셋: 최악).
