## 통제 조건과 실제 확인

- 씬별 혼합 p=0/.2/.4/.6/.8/1:18장. p=.5,t=.18,배경3모드:9장. B5 시간루프 t=0/.2/.4/.6/.8/1:6장.
- 총33장, 각1280×720. `verification/b-background-20261004/states.json`에 카메라/p/t/통계. 설치된 Edge + agent-browser0.38.2 실제 캡처. 시간루프 표본은 체감 모션 합격과 다르다.
- 새 브라우저 세션 오류0. 장면·배경 선택/정지 UI 확인은 `interaction.json`. p=.5 고정 재생에서 t=.18→50.23s 진행 관찰. 역스크롤이 t를 되감지 않는다.
- edge depthTest=true/불투명 면은 코드·상태 확인. 종이가 뒤 장비/선을 가리는 모습은 캡처 확인. 물리광 차폐/실시간 그림자는 미검증.
- 95–189 draw calls, 약1.7만 triangles는 렌더러 통계이며 FPS/전시PC 합격이 아니다.

초기 빈 화면은 JS 지수식 괄호 오류였다. 수정 후 syntax check와 새 브라우저 확인. sandbox 서버 시간 초과/CLI socket 권한 문제는 정상 권한의 로컬 실행으로 해결했다. 초기 실패와 최종 오류0을 구분한다.

## 실제 결과 판정

| 대상 | 확인된 효과 | 남은 TUNE |
|---|---|---|
| B3 | 전경 margin·인체·카트·접선이 실제 깊이로 분리. p에 따라 가려진 영역 변화 | 종이가 기록물보다 큰 판처럼 보임. 좌우 명암 불균형/카트 부분 가림. 인체610px 목표와 정확 일치하지 않음 |
| B5 | 같은 방에서 왼쪽 인체/오른쪽 기록면, 제목 뒤 암부 | 가슴 확대 목표 대신 전신 clay. 프레임이 아직 인체 뒤와 겹침. 종이가 갈색으로 읽힘 |
| B6 | 작은 접힘 축과 측면 카메라로 뒤 격자 노출, 큰 처리박스 없음 | 이면이 약해 절개처럼 읽힐 위험. 종이 곡률/두께/이면 명암, 처리층→컴퓨터 연결 보완 |
| 혼합 | off보다 접선/프레임/수광으로 거리 단서 증가 | 수광이 평평함/접지 약함. 주연10–20% 밝기 목표는 측정·확정하지 않음 |

**전체 TUNE.** 생성 보드의 통제 문제를 실제 카메라 시험으로 넘겼다. 고급 목업 수준의 재질/빛/인체 완성도가 확보된 결과는 아니다.

## 셰이더·빛 선택

넣음: rough PBR 면, ACES exposure1.05, SRGB, AA, 최대DPR1.5, depthTest 선/불투명 가림면. 구조선 모드에도 검은 가림면 유지. 소품/광원 동일.

뺌: texture/굴절/SSS/AO bake/실시간 shadow/볼륨/dust/bloom/DOF/grain/LUT. 구조 단계 변수를 줄임. 따뜻한 수광은 저명도 plane 근사로 물리광 차폐 구현이 아니다. 실제 receiver/depth light 적용 때 다시 off/on 확인. 전체 노출/반사로 빈 방을 채우지 않는다.
