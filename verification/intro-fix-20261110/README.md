# D-166 도입부 렌더 정리 검증 (2026-11-10)

Chromium(SwiftShader, GPU 없음, 초당 약 1프레임) · 1280×720 · 개발 서버. 사용자 영상(원본 릴리스 `video`)은 내려받지 못해 이 환경 렌더로만 판단했다.

| 파일 | 내용 | 판정 |
|---|---|---|
| 01_aisle_lightmap_before_after | 도입부 `?p=.3`(서고 통로), 빛줄기 끔. 위 = 이전, 아래 = 넓은 양방향 필터 적용 라이트맵. 양쪽 책장 옆면 · 바닥 얼룩이 사라지고 오른쪽 햇빛 띠 가장자리는 남음 | PASS |
| 02_right_panel_before_after | 오른쪽 책장 옆면 확대(왼쪽 이전, 오른쪽 이후) | PASS |
| 03_left_panels_before_after | 왼쪽 책장 옆면 확대 | PASS |
| 04_noise_bw_shaft_06_vs_1 | 잡음 장면(기저선) 오른쪽 절반, 빛줄기 0.6(왼쪽) → 1(오른쪽). 이 시점은 카메라가 빛을 등져 차이가 작다 | 조건부 — 사용자 확인 필요 |
| 05_emg_cut_point_proposal | 근육 잡음 장면: 「중첩 표시」 버튼이 뜨는 시점 = 장면 16.3 s = 기록 6.30 s(표본 1575, 10 s 자료). 같은 waveMode · beatPhase로 60 fps 모의 계산 | 사용자 확인 대기(미수정) |

## 먼지
통로를 걷는 8프레임(`p` 0.300 → 0.3105)을 먼지 있음 · 없음으로 렌더해 빼고 입자를 추적했다.

| | 프레임당 입자 | 새로 나타남 | 사라짐 | 밝기 변화 중앙값(|log|) | 2배 넘는 변화 비율 |
|---|---|---|---|---|---|
| 이전 | 68.7 | 8 | 3 | 0.060 | 3.4 % |
| 이후 | 86.3 | 9 | 1 | 0.066 | 3.0 % |

이 환경의 이동에서는 이전에도 깜빡임이 거의 없어, 사용자가 본 「번쩍번쩍」을 재현하지 못했다. 수정(판정 5점 평균, 1 px 미만 면적 보정, 카메라 1 m 안 사라짐)은 원리상 안전하지만 효과는 **미확인**. 통로 안쪽에 보이는 체크무늬는 빛줄기 레이마칭 디더(프레임마다 바뀜)이며 이번에는 고치지 않았다.
