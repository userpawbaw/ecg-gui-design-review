# 실험실 파형 밝기 — 기법 여럿에서 어두워짐 (D-177, 2026-11-12)

사용자: 패키지 실행 후 「여러 기법을 선택해도 모두 동일해지긴 했지만 수정 전의 입력 신호와 비교해보면 더 어두워졌어」.

## 측정 방법
- `rowlum.cjs <query> <methods> <label>` — 재생 중 실험실 캔버스 픽셀을 직접 읽어, 행마다 선단 뒤 0.4–2.0 s 열의 최고 밝기 · 번짐 높이(max(R,G,B) > 60 픽셀 수) · 빛 양(합 max(R,G,B)−45) 중앙값. `MODE=scroll`, `THROTTLE=n`(CPU 느리게), `SHOT=`(패널 스크린샷).
- `drop.cjs <query> <methods> <throttle>` — 재생 중 0.5 s마다 번짐 단계(`data-fx`)와 프레임 간격.
- `compose.cjs` — 비교 시트(HTML → 스크린샷). `levels.cjs` · `rows_v.cjs` · `canvas_rows.cjs` — 첫 조사(재생 끝난 뒤 찍힌 화면 등 오류 포함, 결론에는 `rowlum.cjs` 값만 씀).
- 수정 전 판은 `git show f2b43e9:prototype/v2/src/Plot.tsx`로 잠시 바꿔 찍고 되돌림(`git diff` 확인).
