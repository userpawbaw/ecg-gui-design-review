# D-168 모서리 · 틈새 번쩍임 (2026-11-10)

사용자 영상 2개(22:48 도입부 사다리 장면, 22:52 기저선 변동 초반)와 「정면 책들의 틈새 … 사다리 오른쪽 가구의 모서리 부분이 번쩍」.

| 파일 | 내용 |
|---|---|
| 01 · 02 | 원본 해상도 연속 6프레임. 종이 두루마리 끝 · 책장 판 가장자리의 밝은 띠, 선반 앞 모서리 · 책 틈의 점이 프레임마다 켜졌다 꺼짐 |
| 04 · 05 | 30프레임 동안 이웃 두 프레임보다 밝은 한 프레임짜리 픽셀(자홍). 정지 기하의 가장자리 · 틈 · 모서리에 몰림 |
| 03 | 수정 전후 같은 장면(`?p=.45`, 이 환경)에서 어두워진 픽셀(자홍): 인물 윤곽 · 오른쪽 판 가장자리 · 틈. 화면 평균 63.63 → 63.55 |

원인: 빛줄기 패스는 픽셀마다 깊이 하나로 광선 길이를 정한다. 픽셀 폭의 틈이나 가장자리는 MSAA 색은 섞이지만 깊이는 뒤쪽 먼 값 하나라, 그 픽셀만 빛 든 공기를 최대 9 m 통과해 밝아진다. 카메라가 움직이면 깜빡이고 블룸이 퍼뜨린다.
조치: 픽셀과 상하좌우 4개 중 가장 가까운 깊이로 광선을 멈춤.
한계: 이 환경(SwiftShader)에서는 깜빡임 자체가 같은 정도로 재현되지 않아(연속 프레임 깜빡임 수 전후 비슷) **사용자 PC 확인 필요**.
