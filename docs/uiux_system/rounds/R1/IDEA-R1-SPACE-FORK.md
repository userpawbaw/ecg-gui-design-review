## 1. 포크 방식의 원칙 — 이음새가 품질 보호막

| 문제 | 해법 |
|---|---|
| 원본 조명은 텍스처에 구워져 있어(`scene_v9.glb` Draco 142 KB + KTX2 4096 px 약 8장, EFX-002-01) 새 에셋과 불일치하고 다시 비출 수 없다 | **연결점(책 포털)에서 세계를 교체**한다. 책 안쪽은 우리 파이프라인. 원본 방에 얹는 에셋은 원본 광원 방향·색에 맞춰 따로 굽는다(다락방 spike의 Cycles 굽기) |
| 낮/밤을 돌리려면 조명을 분리해야 하는데 beauty 베이크는 분리 불가 | **1단계**: 야간 등급(색조·노출 곡선) + 램프 풀(가산광) + 낮 햇빛 얼룩을 **달빛 갈래로 재해석**(어둡고 차갑게, 모양 재사용). **2단계(선택)**: 우리가 다시 굽는 낮/밤 한 쌍 — 원본 대체이므로 품질 비교 후 결정 |
| 원본 에셋 반입 | 로컬 전용 `prototype/practice/attic-fork/public/_original/`(gitignore). 커밋·배포 금지. AGENTS.md "레퍼런스 에셋 복사 금지"와 충돌하지 않게 **저장소 밖 취급**. D-047 |
| 카메라 | 원본 3단 계층(modelCamera → mouseMoveCamera → camera)과 스크롤 매핑(EFX-002-02·03)을 그대로 쓴다 |

## 2. 병렬 시험 — Ha / Hb (같은 장면에서 `?beat=a|b|ab`로 전환 비교)

공통 계약: 박동 시각 = **저장 R 피크 목록**(0프레임 오차 e2e `browser-tests/intro.spec.ts` 방식 재사용). 연출 세기는 R 간격을 바꾸지 않는다. 방·책·종이는 장식, 파형은 저장값.

| | Ha 방이 뛴다 | Hb 팝업북 심장 |
|---|---|---|
| 보는 것 | R마다 램프·달빛 갈래가 한 번 맥동하고 빛 속 먼지가 떠오름. 방 전체가 심장 | 펼친 책 왼쪽 페이지에서 종이 해부 심장이 접힌 채 일어서고, R마다 수축. 책갈피 리본이 튕김 |
| 만드는 법 | 맥동 함수 `p(t)=Σ exp(−(t−t_R)/τ)`를 램프 강도·달빛 갈래 알파·먼지 속도에 곱함(τ 약 0.3 s, 램프 +15–20 %부터 조정). 원본 먼지 파티클 2,000개 재활용 | 기존 HRA 심장(`story/intro/assets/heart.glb`, CC BY)을 종이 질감(면 분할 + 종이 섬유 노멀 + 접힘선)으로. V자 접힘 힌지가 일어서는 키프레임 + 수축은 기존 박동 변형 재사용 |
| 수용 기준 | R 동기 0프레임. 평상시 눈에 띄되 산만하지 않음(맥동 진폭을 단계별 3종 캡처) | 3/4 각도에서 심장으로 읽힘. 책을 가려 파형을 막지 않음 |
| 위험 | 너무 약하면 안 보이고 너무 강하면 "깜빡이는 방" | 종이 오브제 디자인 품질이 승부 |
| 합치기 | `ab`: 방이 약하게, 심장이 강하게 — 둘이 같은 R에 반응 | |

## 3. moto-card 흡수 (질감·테마 변형)
