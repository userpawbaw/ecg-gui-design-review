## 권장 방법
1. 그림마다 주어(청록 #5fd6c2 심전도 파형)를 넣는다. 「무엇이」 그 상태인지가 보여야 한다.
2. 상태는 실물 실루엣(플러그 · 보드 · 계기 · 그래프 축, 회청 #8fa9a2)과 상태색 한 점(호박 · 산호 · 모래)으로.
3. 가로 80 × 32(2.5 : 1), 왼쪽 → 오른쪽으로 신호가 어디까지 왔고 어디서 막혔는지 읽히게.
4. 획은 `vector-effect: non-scaling-stroke`로 화면 픽셀 고정(칩 1.6 px, 큰 패널 2.4 px). 채움 판 없이 선으로. 양감은 큰 패널의 파형 번짐만.
5. 그림 옆에는 상태 명사구(「브리지 연결 없음」)와 필요하면 짧은 설명 한 줄(「자동 재시도 중」).

## 도달한 품질
D-157 원래 그림 · 1차 · 2차를 같은 크기로 나란히 놓고 「무엇이 끊겼는지 바로 읽히나」를 사용자가 판단해 2차를 받아들였다.

## 가지 말 길
- **일반 아이콘 규칙(정사각 격자 · 듀오톤 판)만으로 상징을 그리기** — 형식은 깔끔하지만 주어가 없어 뜻이 약하고, 작은 칩에서 판이 뭉갠다(J-006 T1). 범용 버튼 아이콘에는 다시 쓸 수 있다.

## 틀린 길이라는 신호
- 그림을 보고 「이게 뭐가 끊긴 거지?」라는 질문이 나온다(J-006 T1).
- 22 px 칩에서 그림이 덩어리로 보인다(J-006 T1).

## 적용 범위와 재검토 조건
- 범위: 이 앱의 상태 · 출처 표시(머리글 배지, 빈 화면, 실시간 측정 상태 · 경고).
- 다시 열 조건: 평가자 시연에서 칩 뜻을 묻는 일이 반복되면 설명 줄을 늘린다(D-160).
