# J-003. 서고 그림자 — 광량 조정에서 가림 거리·아랫면 재질을 분리한 선택까지

| | |
|---|---|
| 기간 | 2026-10-16 ~ 2026-10-19 |
| 도착 | P-006, P-007 |
| 기록 | D-084, D-085, D-141, F-046, F-047, `verification/r1-archive-b3-selected-20261018/README.md` |

## 출발점

광량을 조정한 r8에도 사다리의 선명한 그림자와 먼 가림의 자유로운 흐린 그림자가 함께 부족했다. 선반 아랫면도 밝았다. 이 여정은 B0 이후의 기록을 연결하며 r7/r8·V1 카메라 전체의 최종 채택을 대신하지 않는다.

## 흐름 한눈에

T1 가림 거리·점토 시험대 → T2 같은 해 + 천창·잎 → T3 16개 변형과 아랫면 비교 → T4 사용자 선택을 분리 프리셋으로 기록.

## T5. 공급처 교체 대신 원본·맵 규약·가공을 분리한 재질 시험

| | |
|---|---|
| 날짜 | 2026-10-18 |
| 종류 | 비교 |
| 계기 | 사용자가 저품질 텍스처 원인·대체 조달처의 실제 검토를 요청하고 외부 접속을 개방·재게시함 |
| 가설 | 깨끗한 단색 기준과 실제 2K 후보를 같은 시험대에 두면 원본 얼룩과 가공 손실을 구분할 수 있음 |
| 판정 | 부분 채택 |
| 다음 | T6 |
| 기록 | D-142, F-107, `verification/r1-archive-material-review-20261018/README.md` |

### 선택지와 기준
공급처 전체 교체와 항목별 검수, 사이트 미리보기와 실제 원본, 기존 서고 교체와 독립 벤치를 비교했다. 사용자 승인된 자체 키트 주력·낮은 대비 표면 목표가 기준이다.

### 한 것
CC0 8팩을 받고 자체 베벨 시험대에서 최종 22장을 렌더했다. PH .15 혼합과 자체 재질을 포함하고 맵 해상도/압축을 따로 측정했다. CGBookcase의 DirectX normal 누락 두 장은 G 반전 후 재렌더했다.

### 결과
PH 도장 벽과 ambientCG 석고의 얼룩은 2K 원본에도 있었다. PH ash의 미세 결은 균일해 PH 전체 저품질 판정은 기각했다. 실제 서고 적용·웹·B3 조합 렌더는 확인 안 함이다. 사용자 미감 확인 전 권장 카드는 잠정으로 둔다(F-107, `verification/r1-archive-material-review-20261018/README.md`).

사용자 후속 `[대화]`: PH ash **원본**이 가장 괜찮고 자체 paint도 나쁘지 않다고 평가했다. 원래 기기 품질은 별도 출처 감사로 확인했다(F-108, `verification/r1-original-branch-assets-20261018/README.md`). 실제 장면 적용 승인은 아직 없다.

### 왜 여기까지
자체 도장면과 약한 목재 결이 현재 목표의 우선 후보다. 최종 화면에서의 타일 크기·빛·베이크 확인이 남아 독립 벤치를 최종 채택으로 바꾸지 않는다.

### 왜 다음으로

실제 재질 비교는 별도 벤치였고, 사용자가 이미 고른 B3 조합의 전체 그림자·아랫면 실제 렌더가 여전히 필요했다. 원본 접근이 복구되어 같은 camera와 재질 조건에서 재현하기로 했다.

## T6. 선택 조합 렌더와 아랫면 전후 수치

| | |
|---|---|
| 날짜 | 2026-10-18 |
| 종류 | 비교 |
| 계기 | T4에서 고른 (b)·L2·30°·×0.35는 실제 같은 조합의 새 렌더를 기다렸음 |
| 가설 | 같은 B3 EXR/카메라에서 underside 계수만 바꾸면 윗면·광원 경계는 유지하면서 아랫면 휘도를 낮출 수 있음 |
| 판정 | 부분 채택 — 수치 목표 달성, 디자인 최종 확인은 대기 |
| 다음 | T7 |
| 기록 | D-141, D-144, F-108, `verification/r1-archive-b3-rerender-20261018/README.md` |

### 선택지와 기준

같은 (b)·L2·30°·두 카메라에서 underside 1.0과 0.35만 바꾼다. 광원·해 방향·수집 거리·표면을 고정한다.

### 한 것

16종 PH 원본의 API 파일 MD5를 확인하고 2.8m/2.0m 카메라에서 64 samples로 계수 0.35와 1.0을 각각 새 렌더했다. 같은 2.0m 표본 분류에서 그늘 아랫면 0.0935→0.0375 (−59.9%), 윗면 0.2675→0.2649 (−1.0%). 사다리 penumbra 1.8–2.3 px, 먼 잎 13.2 px였다.

### 결과

선택 계수가 윗면을 거의 유지하고 아랫면만 어둡게 하는 효과는 확인했다. 재게시한 vintage drawer 파일은 registry SHA와 다르다. 카메라 안에 든 자체 PC/CRT/ECG 여섯 부분은 상자 기하·베벨 없음으로 새 Q2 검사에서 FAIL. 사람의 L2 해치 동선, 웹 bake, 목표 PC, 사용자 최종 미감은 확인 안 함이다. key 0.35/0.25 혼합은 D-144 후보이며 기본값 변경이 아니다.

### 왜 다음으로

사다리/잎 그림자 결과는 유지되지만 key 채움이 햇빛 무늬를 얼마나 눌러 보이게 하는지 후보 믹스 비교가 남았다. 여기서는 기본값을 변경하지 않는다(D-144).

## 도착점

P-006은 거리·재질·광원 믹스 비교 절차를 정리한다. 상태는 잠정이다. T6에서 아랫면 비율을 새 조합으로 검증했고 T7에서 key 0.35를 다음 화면 후보로 좁혔다. 최종 색감 선택·L2 연출·웹 굽기는 확인 대기다.

후속 P-007은 T8의 독립 실시간 볼륨 구현과 검증을 정리한다. 원본 B3 빛/미감의 최종 승인은 이 기록으로 대체하지 않는다.
