## 2. 라운드 1 선택지

★ = AI 추천(한 줄 이유). 모든 안의 공통 계약: 파형 꼭짓점은 저장값, 시간·진폭 눈금은 파형과 같은 층, 파형은 기울이거나 늘리지 않음.

### B-G 격자 (W4)

| ID | 보는 것 | 만드는 법 | 위험 |
|---|---|---|---|
| G1 | **심전도 용지 격자** — 작은 칸 0.04 s × 0.1 mV, 큰 칸 0.2 s × 0.5 mV. 어두운 화면에 아주 옅은 청록 선(작은 칸 4 %, 큰 칸 9 % 밝기). 관람객이 "심전도"임을 한눈에 앎 | 캔버스 한 장에 미리 그려 두고(정적) 파형 아래 층 | 촘촘하면 네온이 묻힘 — 파형 뒤 영역만 조금 밝게 |
| G2 | **HUD 최소 축** — 기준선 하나 + 1 s마다 짧은 눈금 + 왼쪽 mV 눈금 3개, 고정폭 작은 숫자(REF-009) | DOM/캔버스 | 여전히 비어 보일 수 있음 |
| G3 ★ | **G1 + 화면 끝까지 번지는 격자** — 격자가 파형 상자 밖으로도 이어지되 가장자리로 갈수록 사라짐(심장 뒤까지 옅게). 파형 상자 부분만 격자가 또렷 → 상자 테두리 없이 "측정 창"이 생김. sweep 머리가 지나가는 칸의 격자가 잠깐 밝아짐(격자에도 잔광) | 격자 캔버스 + 방사형 마스크, 머리 위치 세로 띠만 밝기 +α | 격자 잔광은 장식 — 파형 잔광보다 약하게 |
| G4 | 격자 대신 **시간 흐름 띠** — 2.5 s 창을 0.5 s 간격 세로 띠로 나누고 지나간 띠는 옅어짐 | 캔버스 | 의료 느낌 약함 |

★ G3: 심전도 용지라는 가장 빠른 의미 전달(G1)에 REF-008의 "차트가 페이지와 한 몸" 문법을 더한다. 격자는 번져도 **파형은 상자 안 실제 구간만**.

### B-T 잡음 → 깨끗 전환의 임팩트 (W5)

| ID | 보는 것 | 만드는 법 | 위험 |
|---|---|---|---|
| T1 | **박동이 한 칸씩 걷어낸다** — 스크롤은 목표만 정하고, 실제 교차는 **R 피크마다 한 단계씩** 진행(예: 4박에 걸쳐 25 %씩). 박동 순간 심장 발광과 함께 파형 전체가 짧게 번쩍이며 잡음이 한 겹 벗겨짐 | 교차 비율 = 스크롤 목표를 박동 시각에만 따라잡는 계단 함수 + 각 계단 0.12 s 이징. 같은 시계(D-041) | 스크롤 반응이 늦게 느껴질 수 있음 — 스크롤 중 미리보기로 초점만 조금 움직이게 |
| T2 ★ | **T1 + 라벨 인계 + 저장 수치 확정** — 라벨 두 줄("잡음 섞인 입력" / "잡음 제거 출력")을 쌓아 두고 현재 쪽만 채운 글자·금색(또는 청록) 세로선(REF-007). 마지막 박동에 강조가 아래 줄로 넘어가며 옆 작은 고정폭 수치가 뒤섞였다가 저장값으로 멈춤: `SNR 0 dB → 12.44 dB · cc 0.971`(REF-009) | T1 + DOM 라벨 + 뒤섞임 0.3 s(중간값은 문자만 섞고 숫자 값을 지어내지 않음 — 끝 값만 저장값) | 수치 노출은 D-040(기법 이야기 제외)과 충돌하지 않음 — 방법 이름 없이 결과 수치만. 사용자 확인 필요 |
| T3 | **초점 렌즈** — 마우스가 파형 위에 오면 원형 렌즈 안만 깨끗한 신호(밖은 잡음). 스크롤을 내리면 렌즈가 커져 창 전체가 깨끗해짐. "직접 걷어내 보는" 참여형 wow | 두 파형을 원형 마스크로 합성(렌즈 안 = 출력 층), 렌즈 반지름 = f(스크롤) | 전시장에서 마우스를 안 쓰면 자동 렌즈(심장 박동마다 이동)가 필요 |
| T4 | **걷어낸 성분이 떠오름** — 교차하는 순간 입력 − 출력(제거된 성분, 저장값의 차)이 옅은 선으로 분리돼 위로 떠오르며 흩어짐 | 차이 곡선을 별도 층으로 그려 위로 이동·페이드 | 떠오르는 선은 위치가 바뀐 **장식** — 데이터처럼 읽히면 안 됨. 계약 위험 중 |

★ T2: 전환이 심장 리듬에 묶여 도입부 전체의 "같은 시계" 주제와 이어지고, 마지막 순간 라벨·수치가 확정되며 "결과"라는 매듭이 생긴다. T3는 과감한 대안(참여형)으로 따로 올린다.

### B-L 라벨 배치·글자 (W6)

| ID | 보는 것 | 만드는 법 | 위험 |
|---|---|---|---|
| L1 ★ | **두 층 라벨 블록** — 큰 한국어 단어(파형 높이의 약 1/4, 굵게, 자간 −0.03em) + 작은 고정폭 보조 줄(`INPUT · WHITE NOISE 0 dB` / `OUTPUT · STORED`), 크기 비 약 8 : 1(REF-010). 두 줄을 쌓고 현재 쪽만 채움, 다른 쪽은 외곽선(REF-007) | DOM, 한글 굵은 글꼴 + 고정폭(IBM Plex Mono, OFL) | 한글 외곽선(text-stroke)이 굵은 글꼴에서 뭉개질 수 있음 → 외곽선 대신 투명도 25 %로 대체 가능 |
| L2 | **데이터에 붙는 주석** — 파형 안 첫 R 피크 위에 점선 + "R 피크 · 심장이 수축하는 순간", 잡음 구간 옆 "백색 잡음 0 dB"(REF-008). 주석은 파형과 같은 층 | 캔버스/DOM 좌표를 파형 시각에 고정 | 주석 위치가 sweep에 따라 움직여야 함(표본 시각에 고정) |
| L3 | **HUD 모서리 괄호** — 파형 상자 네 모서리에 짧은 괄호선, 왼쪽 위 고정폭 `CH 01 · 250 Hz · 2.5 s`, 라벨은 뒤섞임 등장(REF-009) | DOM | 과하면 게임 UI처럼 보임 |
| L4 | **읽는 만큼 켜지는 한 줄** — 파형 위 한 문장("같은 심장, 같은 기록 — 잡음을 걷어내기 전과 후.")이 교차 진행률만큼 단어 단위로 켜짐(REF-007 EFX-007-03) | DOM, p = 교차 비율 | 문장이 길면 산만 |

★ L1 + L2의 첫 R 주석 1개: 위계(큰 단어)와 데이터 연결(주석)을 둘 다 얻는다. L3의 고정폭 보조 정보는 L1의 작은 줄에 녹인다.

| ID | 보는 것 | 만드는 법 | 위험 |
|---|---|---|---|
| P1 ★ | **문구 먼저, 파형이 추월** — 가슴 확대 끝(p ≈ 0.72) 이후 스크롤 구간에서 라벨 블록(중간 속도 0.85)이 먼저 올라와 자리 잡고, 파형 무대(1.45)는 한 화면 아래에서 출발해 늦게 들어오지만 빨리 올라와 제자리에 선다. 심장(느린 층 0.63)은 거의 제자리 | 도입부 진행률에 층별 계수(REF-003 EFX-003-06). 파형 무대가 제자리에 선 뒤에는 고정 | 파형이 움직이는 동안은 W4 빛 고리(첫 R 착지)를 기다림 — 착지는 파형이 멈춘 뒤 |
