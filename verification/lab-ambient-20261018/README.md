# 실험실 배경 상시 움직임 + 해 각도 다시 굽기 (D-075, F-050) — 2026-10-18

사용자 요청:
- 마우스를 멈춰도 배경이 살아 있게. 빛 커튼(실크·오로라), 구름에 가리는 빛, 바람 먼지. A+B+C를 하나의 구름 시간축으로, C·B부터("진행해줘").
- 해가 책장 면을 비껴가지 않고 비스듬히(면과 30°) 닿게, 다시 굽기("가)로 한번 해보자", "비스듬한 쪽").

## 만든 것
- `archive.ts`(세기 기본 0, 도입부·이야기 장면 그대로):
  - 구름: 해의 빛 공간에서 흐르는 256 px 무늬를 매 프레임 그린다. 빛기둥, 해를 받는 표면(구운 볕 자국), 먼지를 함께 어둡게 한다.
  - 실크: 빛기둥 밀도 무늬를 빛 방향으로 늘리고 가로로 접어 천천히 흘린다.
  - 바람: 먼지가 빛이 들어오는 방향으로 흐르고, 돌풍 때 소용돌이친다. 돌풍은 구름 속도도 올린다.
- `labBackdrop.ts`:
  - 서고 화면(색·깊이)은 카메라가 움직일 때만 다시 그린다. 매 프레임에는 빛기둥과 먼지만 그 위에 더한다.
  - 초당 24장(가만히), 12장(파형 재생 중, 카메라는 고정), 30장 이하(카메라 이동).
  - 저전력(소프트웨어 렌더)과 움직임 줄이기 설정에서는 끈다.
  - 주소창: `?amb=0` 끔(`?amb=1`은 저전력에서도 강제로 켬), `?wind=` `?silk=` `?cloud=` `?shaft=`(0–100, 10 % 단위, 50 = 설계값), `?sun=0` 기존 해.
- 해 변형:
  - `scripts/assets/archive-sun-variant.py`가 `build_archive.py`를 고치지 않고 r1 해 한 줄만 메모리에서 바꿔 실행한다. 그 파일은 서고 조명 세션 점유다.
  - 해 (0.649, 0.5, −0.574)(Blender, 책장 면과 30°, 고도 35°). `--intro2 --bake … --size 2048 --bsamples 128`, 629 s.
  - `package-archive.py`, `denoise-archive-lightmap.py <dir>`. 결과는 `prototype/v2/src/story/intro/assets/archive-sun35/`(10.36 MB)이다.

## 그림

- `02_web_sun_old_vs_35.jpg`: 웹(커튼 0, UI 0), 왼쪽 기존 해, 오른쪽 35°. 스크롤 0 · 0.5 · 1.
- `03_shafts_old_vs_35.jpg`: 빛기둥 세기 ×2(`?shaft=100`). 기존 해는 통로를 가로지르는 빛 커튼이 크고, 35°는 거의 없다(F-050).
- `04_ambient_old_sun_diff.jpg`: 기존 해에서 상시 움직임 7.5 s 동안의 변화(오른쪽, ×8). 빛기둥, 먼지, 볕 자국이 움직인다.

## 확인하지 못한 것
- GPU 화면의 실제 움직임과 노트북 프레임 비용. 이 환경은 소프트웨어 렌더라 상시 움직임이 기본으로 꺼지고, 캡처는 `?amb=1`로 강제했다.
- 실크 무늬가 빛 커튼으로 읽히는지는 기존 해(`?sun=0`)에서 사용자가 봐야 한다.
