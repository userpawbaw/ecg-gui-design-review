## S1 — 에셋 조사 (24 단계)

`explore.mjs`로 모델(book)·재질(fabric, paper)을 조사하고 **미리보기를 직접 보고** 골랐다. 전부 CC0, 레지스트리 등록 + sha256 고정(`fetch.mjs --pin`).

| 레지스트리 id | 쓰임 |
|---|---|
| `model-ph-decorative-book-set-01-fbx-1k` | **품질 기준 레퍼런스만.** 열어 보니 책 한 권이 보드·책등·페이지 블록이 붙은 닫힌 단일 셸(6,432 삼각형)이라 표지를 열고 페이지를 넘길 수 없어 쓰지 않음 |
| `tex-ph-book-hardcover-01-diff-2k`, `…-nor-gl-2k` | 페이지 마구리(옆면 줄무늬) + 면지(크래프트) 텍스처를 잘라 사용 |
| `mat-ambientcg-leather026-1k` | 표지 가죽 질감(Color/NormalGL/Roughness), 색은 청록 틴트 |
| `mat-ambientcg-paper003-1k` | 종이 미세 노멀 |

## 라운드 1 — 책 모델 + PBR 조명 리그 + 파형 이식

구현: `book2.ts`(보드 RoundedBox 오버행, 둥근 책등 반원통, 조인트 띠, 헤드/테일밴드, 면지, 리본, 금박 얼굴·책등, 시트 스택·휘는 시트), `rig.ts`(주광 슬릿 스포트+쿠키, 램프 필, 림, 환경맵, 책 아래 간접광, 블룸·비네트·그레인), `trace.ts` v2(이전 도입부 파형 디자인), `beatmix.ts`.

### 자기 비평 (캡처 R1a–R1c, R1g0)

| 코드 | 점수 | 무엇이 왜 부족한가 |
|---|---|---|
| M1 형태 | 2 | 보드 오버행·둥근 책등이 보임. 정면이라 두께감은 약함 |
| M2 재질 | 1 | 금박이 어두운 환경을 비춰 거의 안 보임, 천이 검정에 가까워 청록으로 읽히지 않음(R1d) |
| L1 키 라이트 | 2 | 슬릿 띠는 나오나 방 전체가 램프 풀 때문에 주황으로 떠 있음(R1a) |
| L2 대비 | 1 | 같은 이유: 방이 밝아 책이 주인공이 아니고 합성처럼 뜸 |
| L3 접촉·그림자 | 1 | ShadowMaterial 캐처가 스포트 원뿔 밖에서 어두운 사각형으로 드러남(R1a) |
| D1 데이터 충실 | 1 | 파형이 하얗게 보임. 호박/민트가 안 보이고 밀집 노이즈에서 additive가 쌓여 하얀 띠(R1g0) |
| D2 이해 | 2 | 펼침면에서 책등 아치가 가운데 서 있어 구조가 틀림(R1b) |
| F1 성능 | 3 | 1.0–1.5 ms @1280×720 |

### 원인 → 수정 → 효과

| # | 원인 가설 | 수정 | 효과 |
|---|---|---|---|
| 1 | 램프 풀 additive가 서가 전체를 덮음 | 책이 당겨 나오는 동안 방 램프를 93%까지 줄임(광선 속 책만 남김) | ✔ 방이 어두워지고 광선 띠 대비가 살아남(R1d) |
| 2 | ShadowMaterial은 스포트 원뿔 밖을 그림자로 취급 | 캐처 제거, 키 광선 방향으로 투영한 부드러운 그림자 블롭 + 선반 위 접촉 블롭 | ✔ 어두운 사각형 사라짐. 블롭 그림자 효과는 정지 프레임에서 약해 **미확인** |
| 3 | 금속 박은 거칠기가 낮을수록 어두운 환경만 비춤 | 박 metalness .92 / roughness .42 / env 4.5, 천 색 밝게 + sheen | ✔ 금박 프레임·엠블럼·책등 밴드가 보임(R1f) |
| 4 | 펼침 상태에서 책등 아치가 앞쪽에 남음 | 열릴 때 책등 그룹을 −90° 회전해 페이지 뒤로 | ✔ 가운데 서 있는 아치 사라짐 |
| 5 | 책 아래 점광이 페이지에 너무 가까움(R1c 백열 폭발) | 광원을 책 아래 바깥으로 이동, 세기를 1/10로 | ✔ 폭발 없음. 라운드 3에서 한 번 더 낮춤 |
| 6 | `new Color(r,g,b)`는 선형 값이라 sRGB 값을 그대로 넣어 색이 옅음 | `setRGB(…, SRGBColorSpace)` | ✔ 호박/민트 복원 (**F-035**) |
| 7 | 밀집 노이즈 위 additive가 흰색으로 포화 | 코어·이너 레이어를 MAX 블렌딩, 글로우만 additive, 게인 하향 | ✔ 호박 코어 + 백열 헤드(R1h) |
| 8 | 정면 구도라 포스터처럼 납작함 | 스크롤 후반에 카메라가 내려다보고(≈22°) 책이 41° 눕는 연속 이동(같은 장면) | ✔ 두께·판형이 보이고 팝업이 읽힘(R1g) |

**효과 없던 시도(남김):** ① ShadowMaterial 캐처 → 위 #2로 폐기. ② 종이 오려 붙이기 심장을 책 위에 세우기(R1e: 카메라가 팝업 평면의 옆을 보아 층 단면만 보임, 고기 슬라이스처럼 읽힘) → 구도 변경으로 가시성은 해결했으나 형태 문제는 라운드 2에서 메시로 교체.

## 라운드 2 — 심장 메시 + 페이지 넘김 확인 + 맥동 FX

구현: `heartmesh.ts`(HRA 점 구름 → 복셀 → 외곽 플러드필 → 솔리드 → marching cubes, 클리어코트), `pulsefx.ts`(파면 링 + 연속 입자 변위).

### 자기 비평 (R2a–R2f)

| 코드 | 점수 | 비평 |
|---|---|---|
| M3 디테일 | 1→2 | 첫 메시(R2a)는 과하게 블러해 콩팥 같은 덩어리. 해부 특징 소실 |
| A2 2차 운동 | 2 | 시트가 곡선으로 휘며 지연되어 넘어감(R2d). **정지 프레임으로만 확인, 영상 미확인** |
| F2 연속성 | — | 심장 팝업이 시트가 눕기 전에 종이를 뚫고 올라옴(R2e) → 타이밍 오류 |
| D2 이해 | 2 | 심장→파형 연결을 보이는 요소가 없음 |

### 수정 → 효과

| # | 수정 | 효과 |
|---|---|---|
| 1 | 복셀 해상도 88→112, 블러 반경 2→1, 쉘 임계값 하향 | ✔ 심방·대동맥 줄기·표면 굴곡이 살아남(R2b) |
| 2 | 팝업 시작을 시트가 다 눕는 p=2.84로 지연 | ✔ 뚫고 올라오는 현상 제거 |
| 3 | 파면 링(호박→민트, 크림 종이에서도 보이게 어두운 보조 링) + 입자 240개가 파면에 밀려났다 되돌아옴 | ✔ 링과 입자 확인(R2f, R3a). **움직임은 정지 프레임으로만 확인** |
| 4 | 책 아래 간접광을 스프라이트+점광으로 키움 | ✔ 하단 따뜻한 맥광이 보임(R2f) |

## 남은 부족함 (정직한 목록)

1. 페이지 곡면(책등으로 빨려 들어가는 곡선)과 스택 윗면 곡면이 없다. 두 페이지가 평면이라 "책"보다 "태블릿"에 가까운 순간이 있다.
2. 피사계 심도 없음. 배경 서가·사다리가 여전히 선명하다.
3. 천 직조 노멀·박 엠보싱 노멀 없음. 클로즈업에서 천이 가죽처럼 보인다.
4. 파형 플레이트가 페이지에 비해 작다(가독 거리 D-044 점검 필요).
5. 심장 해부 정밀도는 점 구름 해상도에 묶여 있다(대혈관·관상동맥 없음). 박동 변형은 균일 스케일 + 약간의 압축뿐.
6. D-048(별도 페이지 월드 폐기)은 사용자 승인 전에 **기본 경로에서 임시로** 통합했다(`?pw=1`로 구 경로 복원 가능). 승인이 없으면 되돌릴 수 있다.
7. 사용자 로컬 확인 필요: 실제 휠 체감, 박동 동기 시각, 1080p 이상 fps.
