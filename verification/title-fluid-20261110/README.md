# 도입부 제목 포인터 유체 왜곡 (D-164, 2026-11-10)

leoparpeix 사이트에 2026-11-10 직접 접속해 번들(`index-djk_Apyr.js`)과 화면으로 확인한 효과를 같은 방정식 · 수치로 새로 구현했다(사이트 코드 · 셰이더 · 캡처는 저장소에 넣지 않음, 수치는 REF-002 2026-11-10 절).

| 파일 | 내용 |
|---|---|
| 01_pointer_sweep_sequence | `?p=0` 제목 위를 포인터로 왼쪽 → 오른쪽 한 번 지난 뒤: 위부터 지나기 전 · 직후 · 0.9 s · 3.6 s · 9 s. 지나간 자리(「잡음 제거」)가 일렁이며 거칠게 번지고(hash blur) 가라앉는다 |
| 02_webgl_vs_dom_same_font | 위 = WebGL로 다시 그린 제목, 가운데 = DOM 제목, 아래 = 차이 ×4. 글자 자리 · 모양은 겹치고 굵기만 다르다(이 환경은 제목 글꼴 Malgun Gothic이 없고 가변 글꼴 굵기가 DOM에 적용되지 않아 DOM이 얇게 그려짐 — CSS 값 700은 WebGL 쪽과 같다. 시험용으로 두 쪽 다 Pretendard로 바꿔 비교) |
| 03_title_shrink_p006_p030 | 제목이 줄어드는 중(`p=0.06`)과 왼쪽 위 표지가 된 뒤(`p=0.3`)에도 오버레이가 따라감 |

주의: 이 환경은 GPU 없이 SwiftShader라 도입부가 초당 1 프레임 안팎이다. 시뮬레이션은 사이트처럼 프레임 dt를 1/15 s로 자르므로, 여기서는 가라앉는 데 실제보다 오래 걸린다. 사용자 PC(60 fps)에서는 사이트처럼 1 ~ 2 s에 가라앉는다고 본다(미확인).
