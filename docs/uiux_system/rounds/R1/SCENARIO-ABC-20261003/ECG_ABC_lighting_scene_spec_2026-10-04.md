# A B C 장면별 빛과 모델링 수정 명세

2026-10-04 KST · A/B TUNE 후속 설계 · C 보완 · 목업 생성 전

기존 [A·B 수정 목록](ECG_AB_TUNE_items_2026-10-03.md), [B 상세판](ECG_B_scene_spec_v3_2026-10-03.md), [C 상세판](ECG_C_signal_chamber_2026-10-03.md)에 덧붙이는 **씬별 수정 명세**다. 첨부 문서의 공통 원칙과 기술 보완은 [검토 보고서](ECG_light_modeling_review_2026-10-04.md)에 분리했다. 여기의 새로운 프레임/효과는 설계 제안이며 결과물 KEEP 판정이 아니다.

## 1. 공통 프레임 규칙

기준1920×1080. 빛은 **배경을 채우는 것 / 다음 목적지를 알리는 것 / 주연을 강조하는 것 / 디지털 처리를 표현하는 것** 중 해당 역할을 명시한다. 한 프레임에서 모든 역할을 최대 밝기로 보여 주지 않는다. 인체·전극·신호의 색은 기존 승인 방향을 유지하고, 환경광의 색과 의미를 구분한다.

각 씬은 source/aperture/blocker/receiver를 하나의 모델로 만드는 것이 아니라, 그 관계를 맞춰 만든다. `APR_ / BLK_ / RCV_ / NEG_ / VOL_ / SET_` 이름, world 단위, 카메라 경로, beauty와 light-depth 포함 여부를 export 계약에 남긴다. 숨은 BLK는 기본 beauty에 보이지 않아도 깊이 패스에 명시적으로 포함한다.

**자체 발광 예외:** 심장·ECG 헤드·C 입자는 수광만으로 읽히는 대상이 아니다. 자연광 규칙을 적용해 추가 구조를 새로 파는 대신, 외곽/조형과 국소 glow로 드러낸다. 자체 발광이 주변 조명을 자동 생성한다고 가정하지 않는다.

### A3–A5 구름과 서고의 빛

**A3/A4 보완 프레임:** 구름을 지나자 중앙(960,460)에 고창, 그 아래 좌우로 지붕 보의 두께가 보인다. 카메라가 내려오며 가까운 보가 x0–600을 빠르게 가리고, 그 뒤에서는 고창이 천천히 커진다. 보를 통과한 뒤 서고의 따뜻한 빛 두 갈래가 **서가 앞턱→사다리 옆대** 순으로 같은 화면 안에 이어진다. 창에서 뻗는 공기 구간과 두 receiver의 밝은 패치가 보여야 한다. 보를 검은 fullscreen cut 카드처럼 쓰지 않고 실제 전경 물체로 사용한다.

**A5 주연 프레임:** 현재 기본 인체 자리 기준은 중심(1030,580), 높이760이다. 왼쪽 서가가 화면18%를 가리고, 뒤 고창은 직접 보이지 않아도 광선 방향을 추적할 수 있다. 햇빛은 가슴 정면을 밝히지 않고 **어깨 가장자리/사다리 옆대**를 스쳐 아래 서가 턱이나 바닥으로 간다. 가슴의 심장이 인체 영역의 가장 강한 의미 있는 빛이며, 환경 하이라이트가 이를 압도하지 않는다. H5 고리 사이를 흰 면으로 메우지 않는다.

모델링은 hero 창의 depth와 보의 두께, 서가 앞턱, 사다리 단면에 집중한다. 모든 책을 같은 높이·폭으로 만드는 대신 광선을 받는 구역만 리듬이 읽히게 한다. 작은 상자/말린 기록지가 중간 breakup을 만들 수 있지만 인체 뒤에 의미 없는 밝은 막대를 추가하지 않는다.

**최신 자리 아이디어와의 연결:** 저장소 IDEA §13의 바닥 첫 등장(F3), 측정 의자, 전원 책상, 호흡 창가, 근육 사다리는 아직 후보 검토 상태다. A 전체를 ‘사다리에서 측정’으로 영구 고정하지 않는다. 현재 기본과 **A5-ALT 바닥→의자**를 다음처럼 별도 제안한다.

- 첫 등장: 사람 중심(1040,740), 높이460, 사다리 세로축은(1270,460) 높이850. 발치의 낮은 좁은 빛이 무릎/어깨 옆과 바닥을 잇는다. 아직 측정 전이면 전극/케이블 등장 시점도 그 서사에 맞게 바꿔야 함.
- 측정 자리: 서가 끝면이 전경을 지나 가리는 동안 의자 쪽으로 카메라 이동, 사람 중심(1030,580) 높이700. 카트→전극 연결 후 심장/파형으로. ‘새 사람’처럼 두 실루엣이 동시에 보이지 않게 한다.
- 이 대안의 자세·자리·전극 등장 타이밍은 **사용자 검토 대상**이다. 빛의 착지점도 자리 선택 후 고정한다. 채택되면 A5를 수정하며 공통 규칙이나 B/C를 동시에 바꾸지 않는다.

### B4–B7 기록의 내부에서 처리층까지

**B4:** 인체 높이760, 심장과 세 전극이 작은 밝은 요소다. 따뜻한 종이 반사광은 외곽 어깨/내부 바닥에만 낮게 남긴다. 가슴 안을 노랗게 채워 심장을 묻지 않는다. 반투명 면의 정렬/깊이 문제가 빛 문제처럼 보이면 재질 패스부터 분리한다.

**B5:** 심장(420,550)높이380, ECG리본 x820–1830. 글자 면은 왼쪽/오른쪽의 읽기 위치로 안정적으로 도착한다. 종이의 느린 조명 패턴과 리본 헤드의 빠른 잔광을 분리한다. 초점/DOF는 리본과 제목을 흐리지 않게, 전경 종이만 깊이 단서로 사용한다.

**B6 보완 프레임:** 오른쪽 종이 면의 골이 벌어지며 뒤의 표본 배열이 드러난다. x1180 부근 접힘 edge는 얇은 따뜻한 선, 배열 중앙(1400,560)은 차가운 작은 청록 점들의 면, 아래 골은 짙은 어둠이다. 앰버 조각은 종이 위에서 이 틈으로 향하고, 통과한 청록 조각이 앞으로 나오며 출력 리본을 만든다. 종이 전체가 디지털 필터라는 인상을 피하기 위해 컴퓨터의 보라 연결선을 배열 뒤에 남긴다.

조명은 골에서 마법처럼 생기는 강한 전역 shaft보다 **뒤에 존재하던 처리 공간을 가림이 걷히며 발견하는 방식**이다. 단어 `디지털 처리` 60–68px를 별도 앞쪽 면에 놓아 차가운 빛과 함께 도착시키되 입자가 글자를 먹지 않게 한다.

**B7:** 청록 출력이 도착하면 배열 발광은 잔잔한 수준으로 줄고, 국소 sweep 잔광이 리본의 주연으로 돌아온다. 종이 key는 유지하되 신호 뒤의 질감 대비는 낮아진다. 출력 전환의 임팩트를 위해 리본 형태 변형/입자화는 허용한다.

### B8–B9와 세 잡음 장

- **B8 원경 복귀:** 사람과 장치는 같은 내부 무대에 남고 종이 접힘3면이 다시 공간 경계가 된다. 종이 틈빛은 사라지는 리본을 쫓지 않고 world의 해당 공간에 머문다.
- **B9 전원 장:** 앞의 접힌 탭이 전경을 지나며 컴퓨터/플러그 구도를 공개. 화면 전체 warm→blue 색보정을 갑자기 바꾸지 않고 같은 내부 조명을 유지한다.
- **BP 전원:** 플러그 edge/코드가 기존 내부광을 받는 구도. AC 보드가 떠오를 때 보드 자체의 작은 밝은 면만 추가. 소나/물결은 붉은 설명광이지 종이의 자연광 그림자 주파수가 아님.
- **BB 호흡:** 측면 흉곽과 느리게 움직이는 기준면. 부드러운 상부광은 같은 위치, 호흡에 따른 면 방향/가림 변화가 몸의 움직임을 드러냄.
- **BM 근육:** 손·전완·RA가 한 화면에 오게 key가 손가락 사이/옆대 접촉을 읽게 한다. 접촉 음영과 붉은 잡음 투사를 분리. 마지막 비교 패널은 새 정확 renderer이며 종이 lighting 픽셀을 데이터로 재사용하지 않음.

**B 구현 단위:** hinge/양면/틈 → 내부 인체/빛 → B6 디지털층 → 제목 면 → BP/BB/BM. 각각 자기 씬에서 피드백을 받는다.

### C4의 개선된 와우 프레임

카메라가 배열 입구의 왼쪽 기둥을 가까이 지나면 그 기둥의 어두운 앞면이 화면 왼쪽3분의1을 빠르게 가린다. 바로 뒤 오른쪽에서는 얇은 청록 edge가 드러나고, 앰버 표본 조각이 이 edge 앞을 통과할 때 반사 한 번을 남긴다. 카메라가 중앙을 바라보는 중간 프레임에는 **가까운 어두운 기둥→밝은 샘플 행→뒤의 청록 출력**이 세 층으로 보인다. 카메라가 더 전진하면 가까운 기둥은 나가고 출력 리본이 크게 도착한다.

이 연출은 단순 ‘노이즈 파형을 입자로 폭발’보다 디지털 배열을 통과해 바뀌는 방향을 구체화한다. 입자 전체가 실제 알고리즘의 내부 샘플 흐름이라는 주장은 하지 않는다. 조형·카메라·빛으로 처리 사건을 보여 주는 독자 확장이다.

### CP CB CM 조명 변화

- **CP0/1:** 플러그와 전원선 edge, 실제 장치의 소규모 상태면. PLI 물결은 원인쪽 붉은 설명효과, 환경key는 안정적. 모니터 표본 배열과 청록출력은 같은 처리 문법.
- **CB0/1:** 큰 리본아래 곡면의 위/옆면이 다른 방향빛을 받아 느린 기저변동의 깊이가 읽힘. 숨루프가 광원자체를 펄럭이는 대신 흉곽/기준면의 방향과 위치를 바꿈.
- **CM0/1:** 손·RA·burst덩어리만 국소 강조. 쥠의 시작/종료는 기존 F-030, 파형헤드와 같은t. 주변공기를 번쩍이지 않고 붉은표본층이 켜짐.
- **CM3:** 발광입자·리본두께·연출광을 종료하고 정확비교로. 단순정면회전으로 복원했다고 판단하지 않음.

## 7. 설계 자체 검토

- **구도:** 각 기존 좌표와 빛의 착지/어둠/전경가림 위치를 연결했다. 새빛이 주연과 무관한 빈공간만채우지않게 함.
- **개연성:** A는 장소추적, B는접힘뒤공간발견, C는입력–배열–출력방향. 각안의빛이어떤전환을돕는지명시.
- **물성:** A서가·B얇은종이·C유광리본의구조와재질을구분. 종이와심장에recess/bevel을일괄강제하지않음.
- **상태:** p정지/t재생, 역방향/빠른스크롤, 움직이는차광체, 정확비교경계를명세에포함.
- **미검증:** 실제종이transmission/입자반사/지구역광/소품receiver품질, 카메라전체경로, 웹–Blender색일치, 목표PC성능. 문서명세로품질KEEP을대신하지않음.

사용자가 수락한 과거 피드백 분석/대조는 종료 상태를 유지한다. 이 검토는 **이번 빛 설계 보완의 구체성**에 대한 것이다.
