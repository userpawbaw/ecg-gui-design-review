# A-P2 사용자 피드백과 빛·후처리 보완 계획

2026-10-06 · F-040 / D-070 · 피드백 정리 완료, 구현은 다음 작업

## 1. 이번 판정

사용자: “보완 항목으로 짚은 부분에 동의하고, 지금은 아예 조명이 없는 느낌이라 빛/후처리 부분도 이후 작업에서 신경써야 할 것 같아.”

- **TUNE 확정:** 앞선 자체 검토의 태양 flare, 얼음 지형 입체감, 구름 해상도·질감 GAP. 여기에 광원 방향과 빛의 존재감 부족을 추가한다.
- **KEEP 유지:** D-068의 서고 전체 빛 렌더와 내부 소품 충실도. 이번 지적을 서고 전체 재제작으로 확대하지 않는다.
- 지구→궤도→구름→같은 서고의 흐름은 현행 제작 기준으로 유지한다. 이번 발언은 모든 전이 구도·속도에 대한 최종 승인이 아니다.
- A-P2 기술 QA PASS와 시각 품질 TUNE를 구별한다. 이번 작업은 문서/계획 갱신이며 새로운 렌더 개선이나 성능 검증을 주장하지 않는다.

## 2. 원인 해석과 수정 대상

[코드] arrival.ts에는 차가운 directional light(0xc9ddff, 3.3), ambient, PBR 지형, cloud shell, 대기 rim이 이미 있다. 따라서 광원 부재가 아니라 **빛이 화면에서 읽히지 않는 상태**로 해석한다. 차가운 광색, 거의 균일한 표면 roughness(.78), 구름 그림자 부재, 태양 원반/flare 부재가 후보 원인이다. 각 요소의 실제 기여는 다음 on/off 비교에서 확인하며 현재 확정 원인으로 주장하지 않는다.

| 파트 | 목표 화면 | 제작할 보완 | 확인할 실패 |
|---|---|---|---|
| 큰 지구 | 어두운 지구의 한쪽 경계에 따뜻한 태양, 밝은 얼음 능선과 깊은 음영이 함께 보임 | 태양 방향/구도부터 조절하고 낮·밤 경계와 지형 shading 확보. 바다/육지/얼음 roughness 구분 및 필요 시 지형 source 보완 | 전체 노출만 올려 평면적으로 밝아짐, 야간 발광이 낮 면까지 덮음, 얼음 변위 seam |
| 궤도·역광 | 태양이 지구 가장자리로 가려지며 얇은 rim과 짧은 flare가 나타남 | 가림에 반응하는 태양 원반/halo, 제한된 bloom과 flare. 지구 회전·카메라와 동일 진행률에서 제어 | flare가 지구 앞을 관통, bloom이 대륙/얼음을 지움, 이동 중 깜빡임 |
| 구름 진입 | 가까운 구름 가장자리는 빛을 받고 내부는 어두워 깊이가 읽힘 | 광원 방향에 맞춘 밀도/산란, 필요한 sample·noise 디테일 비교. 지구 cloud layer와 가림용 cloud field의 톤 연결 | 하얀 평면 안개, 계단/노이즈 shimmer, 단순 해상도 증가로 비용만 커짐 |
| 구름→고창 | 밝은 구름 틈의 방향이 실제 고창의 빛 방향으로 이어짐 | 가림 전중후의 광색·광원 위치·밝기 변화 조절. 완전 가림 컷과 동일 고창 좌표 유지 | 컷 순간 밝기/색 튐, 서고 전체 노출 변경으로 기존 KEEP 손상 |

## 3. 실제 제작 순서와 피드백 단위

1. **P2-L1 광원·재질:** 고정 p=0/.12/.23에서 태양 방향, 낮·밤 경계, 얼음/바다 shading을 먼저 완성한다. flare/bloom-off에서도 입체감이 남아야 한다.
2. **P2-L2 역광·후처리:** 태양 가림에 연동한 halo/flare와 제한된 bloom을 추가한다. 더 밝게 하는 안, 표면 광응답을 고치는 안, 후처리만 강화하는 안을 비교하되 **표면 광응답→후처리** 순서를 기본으로 한다.
3. **P2-L3 구름·접합:** 구름 산란과 고창 match cut을 조정한다. p=.25/.314/.32/.336/.40/.44/.46/.49와 전중후 이동 영상을 대조한다. 기존 서고 내부 bake/소품은 유지한다.
4. **내부 검증:** 동일 p/t/카메라에서 기본·bloom-off·flare-off·cloud-off 비교, 정방향/역방향 영상, MSAA/shimmer·GPU 시간·브라우저 오류 검사. mockup과는 광원 방향/입체감/밀도를 대조한다. 다른 구도 이미지의 평균 밝기를 품질 합격 기준으로 쓰지 않는다.
5. **사용자 피드백:** 지구·역광·구름·고창이 모두 빛/후처리까지 갖춰진 연속 결과를 보여준다. 부분 제작물마다 완성도 판정을 요청하지 않는다. KEEP/TUNE를 파트별로 기록하고 필요한 국소 수정 후 **A-P3 처리/출력·의자 인계**로 진행한다.

새 target-PC 성능 검증은 별도이며 로컬 QA로 대신하지 않는다. 이번 계획의 구체 수치는 구현 비교 후 정한다. B/C는 후속 보류 상태다.

## 4. 이후 단계에 넘길 내용

A-P3에서는 처리막이 파형을 받아 표본으로 분리하고 깨끗한 신호로 재구성하는 순간에 빛의 역할도 amber→cyan으로 인계하는 아이디어를 검토한다. 이는 **제안**이며 이번 피드백으로 자동 채택된 효과가 아니다. 파형/전환 아이디어는 해당 단계 제작과 함께 발전시키고 전체 제작 끝으로 미루지 않는다.

A-P4는 각 노이즈원에 빛의 의미를 맞춘다: 전원 장비의 간섭 영역, 호흡의 움직임, 주먹 쥠의 긴장 부위를 강조한다. 기존 박동 배경 스캔은 여전히 별도 보류다. 세 단계의 피드백과 구현 기록을 섞지 않는다.
