## 6. 효과 카드

### EFX-010-01 줄 단위로 끊은 헤드라인 + 한 글꼴 극단 크기 대비

**선정 이유**: 사용자 요청(글자 크기·배치 연구) `[대화]`, 과학 내용 사이트의 글자 체계.
**지각**: 미확인 — 녹화 없음. 코드상 헤드라인이 줄마다 별도 요소라 줄 단위 등장이 가능하다 `[추론]`.
**입력 모델**: 문턱 발동(추정 — 미확인).
**판별 근거**: HTML에 `<h1 class="text">`가 한 문장의 줄마다 따로 있음, 크기 토큰 9단계, 글꼴 하나 `[코드]`.
**구현 메커니즘**:
```
한 문장 = 줄 요소 여러 개(줄바꿈 위치를 디자이너가 고정)
크기: 설계 px ÷ 기준 폭 × 비율 — 모든 크기가 화면 폭에 비례(레이아웃 비율 유지)
큰 제목은 자간을 좁혀(−0.03em) 덩어리로, 작은 라벨은 기본 자간
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 크기 단계 | 100 / 80 / 70 / 49 / 20 / 16 / 12 | `[코드]` |
| 자간 | −0.04 ~ −0.01em | `[코드]` |
**타임라인**: 미확인 — 녹화 없음.
**에셋**: 글꼴 Jeko(상용).
**성능 기법**: 미확인 — JS 동작 미분석.
**접근성·폴백**: 한 문장을 여러 h1로 나눠 제목 구조가 중복됨(스크린 리더에 불리) `[코드]` — 우리 구현은 한 요소 안에서 줄을 나눈다.
**근거**: `[코드]`, `[추론]`.
**재현 요구사항**: 줄 분할 + 크기 토큰. 난이도 하.
**수용 기준**: 제목·라벨 크기 비가 6 : 1 이상, 한 화면에 글꼴 한 가지(+ 고정폭 보조).
**ECG 번안**: 파형 라벨을 "작은 본문 글자 한 줄"이 아니라 **큰 한국어 단어 + 작은 고정폭 영문·수치** 두 층으로 — 예: 큰 "잡음" / 작은 `INPUT · WHITE NOISE 0 dB`. 크기 대비로 위계를 만든다.
**재현 상태**: `none`
