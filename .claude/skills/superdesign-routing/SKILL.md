Read `docs/uiux_system/14_SUPERDESIGN_GENERATION_LAYER.md`. For automatic or Dual requests, first use `16_DUAL_CREATIVE_DIRECTOR.md` and the task router. This wrapper defines project roles; the installed official Superdesign skill defines CLI/auth/init/resume syntax.

- NATIVE_DIRECTOR: shared baseline/goal/constraints only; no A references, shortlist, preferred direction or drafts. Use a clean session and uncontaminated vendor state. Search the native inspiration system; record actual queries/sources. Produce 4–6 cards before generating; prefilter within B and render only 1–2 valid directions. No mandatory A/reference-mining prerequisite.
- CONCRETIZER: receive selected A/B/Hybrid IDs, intent and relevant sources. Generate only the requested/authorized shortlist (normally 2–4 for comparison, one selected idea or Hybrid is valid). Do not claim independent discovery. Refine with replace; branch only for requested alternatives.

Use existing `prototype/v2` baseline; preserve waveform/time/unit/Reference/Difference/metric contracts. Resolve undecided data-story grammar before composition. Pass minimum UI source, never bulk archive/replay/secrets. Check shell, actual vendor availability/auth and clean context before execution. In standard Chat, return a mode-specific handoff; Native handoff excludes A output. Failure/fallback must not be reported as native success.

Return actual canvas/preview URLs, IDs, queries/inputs, model/CLI provenance and budget/status; do not fabricate missing tool results. Stop at user alignment + independent validator KEEP/TUNE/REJECT. Follow 16 for cross-review/optional Hybrid and 10 for recording. No automatic production implementation.
