# J-006. 상태 그림 — 듀오톤 정사각 아이콘에서 「파형 + 실물」 가로 그림까지

| | |
|---|---|
| 기간 | 2026-11-07 ~ 2026-11-08 |
| 도착 | P-009 |
| 기록 | D-157, D-160(+ 보완), `docs/40_ui_copy_review.md` §2, `verification/ui-copy-20261107/` |

## 출발점

사용자 `[대화]`: "실시간 처리 화면에서 … 불친절한 정보들을 간결하게 SVG 형태의 신호가 끊겼다는 그림과 함께 신호 끊김이라는 상태 표현 + 짧은 설명 글귀로 대체했던 경우 있지? 이런 방향으로 그림을 함께 이용해서 정보를 압축하는 것을 더 선호". 선례는 D-157 `LiveOffline` 그림(파형 → 끊김 → 플러그 → 전선).

## 흐름 한눈에

```
T1 Lucide 규칙 + 듀오톤 판(정사각 32 격자) 11종 ──(사용자: 이전 아이콘이 더 직관적)──▶
T2 D-157 그림과 나란히 비교 → 「파형 + 실물 + 상태색 한 점」 가로 80 × 32 ── 끝(사용자: 아이콘 좋아)
```

## T1. 듀오톤 정사각 아이콘 11종

| | |
|---|---|
| 날짜 | 2026-11-07 |
| 종류 | 시도 |
| 계기 | 위 사용자 선호, 「트렌디하게 — 투명도 · 색 조합 · 부분 양감」 |
| 가설 | Lucide 설계 규칙(격자 · 획 · 간격)과 듀오톤(몸체에 방사 그라데이션 판)이면 세련되고 일관된다 |
| 판정 | 기각 |
| 다음 | T2 |
| 기록 | D-160, `verification/ui-copy-20261107/04_glyph_set.png` |

### 한 것
상태마다 상징 하나(플러그 둘 · 계기 · 막대)를 32 격자에 그리고 몸체에 같은 색 그라데이션을 깔았다.

### 결과
사용자 `[대화]`: "브릿지 끊김 아이콘을 봤을 때 이전 버젼의 아이콘이 좀 더 퀄리티가 높아(직관적)보였는데".

### 왜 다음으로
무엇이 그 상태인지(주어)가 그림에 없었다. 일반 아이콘 규칙은 지켰지만 이 화면의 뜻을 싣지 못했다.

## T2. 「파형 + 실물 + 상태색 한 점」, 가로 흐름

| | |
|---|---|
| 날짜 | 2026-11-08 |
| 종류 | 비교 |
| 계기 | T1 피드백 |
| 가설 | D-157 그림이 나은 이유(주어 · 실물 실루엣 · 색 역할 · 좌 → 우 · 채움 판 없음)를 규칙으로 만들어 11종에 적용하면 같은 품질이 된다 |
| 판정 | 채택 |
| 다음 | 끝 |
| 기록 | D-160 보완, `verification/ui-copy-20261107/10_bridge_icon_d157_v1_v2.png`, `09_glyph_set_v2.png` |

### 한 것
11종을 80 × 32로 다시 그렸다. 「브리지 연결 없음」은 D-157 구도를 그대로 잇고, 파형에만 은은한 번짐을 줬다.

### 선택지와 기준
D-157 그림 · T1 · T2를 같은 패널 크기로 나란히 놓고 「무엇이 끊겼는지 바로 읽히나」로 봤다.

### 결과
사용자 `[대화]`: "아이콘 좋아."

## 도착점

`prototype/v2/src/Glyph.tsx` 11종, `StateChip` · `StatePanel`.

## 여정에서 얻은 것

- 상태 그림은 상징보다 「무엇이 · 어디서 · 어떻게」의 짧은 장면이다. 이 화면의 주어(심전도 신호)를 매번 넣는다.
- 외부 아이콘 규칙은 획 · 간격 같은 형식만 빌린다. 뜻은 이 화면의 선례에서 가져온다.
