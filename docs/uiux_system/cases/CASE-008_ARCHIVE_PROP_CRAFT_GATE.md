# CASE-008. 자체 제작 기기 품질 문제를 제작·검수 관문으로 바꾸다

연결: F-108, D-143, 서고 리뷰 §5·§7, `verification/r1-original-branch-assets-20261018/README.md`, `verification/r1-prop-craft-gate-20261018/README.md`.

## 배경

초기 `r1-autopilot-recommended`의 컴퓨터·CRT·ECG 기기는 자체 `box()` 구성이 중심이었다. 이후 사용자는 Poly Haven 에셋의 얼룩덜룩한 질감 문제를 지적했고, 재질 벤치에서는 원본 PH ash와 자체 paint가 깔끔하게 보였다. 따라서 외부 재질 품질만으로 초기 장비의 낮은 형태 품질을 설명할 수 없었다(F-108).

사용자 `[대화]` 2026-10-18: “기기 형태는 외부 에셋이 아니라 직접 만든 형태가 제대로 검수되지 않아 저품질로 나온 결과였나보네. 이 문제가 다시 생기지 않게 하기 위해, 직접 제작 시 참고할 제작 절차 및 기술을 담은 스킬과 검수 기준이 필요해 보이네. 탐색해서 제작해줘. 완료되면, 실제 서고 빛 렌더 재설계로 들어간다.”

## 논의 흐름

AI는 기존 서고 리뷰의 베벨·단차·화면 투영 수치를 확인하고 Blender Manual의 Bevel, Weighted Normal, UV, Baking 문서 URL에 접근했다. 첫 대응은 형태·베벨·재질·화면 크기 검수를 별도 스킬로 묶고, 초기 장비는 실패 사례로 점검하겠다는 것이었다 `[대화]`. 사용자 반론은 이 요청 이후 아직 없다. 미완료된 사용자 검토를 완료로 꾸미지 않는다.

재질만 높이는 경로는 박스형 실루엣을 그대로 남긴다. 외부 모델 일괄 교체는 자체 키트 주력 결정과 Story 소유 범위를 해친다. 그래서 형상 → clay → 엣지·법선 → 재질·UV → 최종 카메라 → 장면·성능 순서의 Q0–Q5 관문을 선택했다(D-143).

## 구축된 시스템

- `.claude/skills/self-authored-3d-props/SKILL.md`: 트리거, 제작 절차, mm 단위 출발 범위와 예외, Q0–Q5, 증거 작성법.
- `references/sources.md`: 프로젝트 근거와 공식 Blender 기술 문서 URL. 문서 접근 HTTP 200은 내용 전수 감사나 제품 결과 검증이 아니다.
- `docs/uiux_system/11_CHECKLISTS.md` §12.1, `05_TOOL_SKILL_ROUTING.md`: 서고 소품 제작 시 찾는 경로.
- 실제 새 소품 제작·렌더 합격은 아직 확인 안 함. 최초 B3 빛 렌더에 남아 있는 예전 장비는 조명 진단에는 쓸 수 있어도 소품 품질 PASS가 아니다.

사용자는 결함 가설과 재발 방지 스킬/검수의 필요성을 제시했다. AI는 원인 근거를 분리하고 절차·관문·기술 자료로 구체화했다. 이 스킬이 실제 제작 시간과 반려율을 줄이는지는 차기 자체 소품 제작에서 측정해야 한다.

## 핵심 대화 근거

- 사용자 `[대화]` 2026-10-18: “기기 형태는 외부 에셋이 아니라 직접 만든 형태가 제대로 검수되지 않아 저품질로 나온 결과였나보네.”
- 사용자 `[대화]` 2026-10-18: “이 문제가 다시 생기지 않게 하기 위해, 직접 제작 시 참고할 제작 절차 및 기술을 담은 스킬과 검수 기준이 필요해 보이네.”
- 이 요청 이후 품질에 관한 추가 사용자 판정은 기록 없음.

## 재사용 가능한 AI 사용 패턴

1. 재질과 형상 결함을 별개 원인으로 조사하고, 둘 다 같은 카메라의 근거로 검증한다.
2. 기술 문서의 기능 설명과 프로젝트의 미적 목표 수치를 혼동하지 않는다.
3. 스킬의 존재를 결과물의 합격으로 치지 않고, 소품마다 관문 증거를 남긴다.

## 사용자가 기여한 것

- 초기 장비의 자체 제작 형상 검수 부족이라는 가설과 재발 방지 요구를 제시했다.
- 스킬을 마친 뒤 실제 빛 재설계로 이어가라는 순서를 정했다.

## AI가 기여한 것

- 초기 빌더/서고 리뷰/재질 벤치를 대조하고 Blender Manual의 기술 범위를 확인했다.
- Q0–Q5 관문과 스킬, 기록 라우팅을 구성했다.

## 한계

새 기기 제작·화면 렌더·사용자 미감 확인 전이라 관문의 효용은 확인 안 함. 수치 범위는 기존 서고 리뷰의 시안값이며 실제 장비 치수에 맞춰 검토해야 한다.
