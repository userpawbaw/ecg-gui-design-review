## 2. 병렬 시험 — Ha / Hb (같은 장면에서 `?beat=a|b|ab`로 전환 비교)

공통 계약: 박동 시각 = **저장 R 피크 목록**(0프레임 오차 e2e `browser-tests/intro.spec.ts` 방식 재사용). 연출 세기는 R 간격을 바꾸지 않는다. 방·책·종이는 장식, 파형은 저장값.

| | Ha 방이 뛴다 | Hb 팝업북 심장 |
|---|---|---|
| 보는 것 | R마다 램프·달빛 갈래가 한 번 맥동하고 빛 속 먼지가 떠오름. 방 전체가 심장 | 펼친 책 왼쪽 페이지에서 종이 해부 심장이 접힌 채 일어서고, R마다 수축. 책갈피 리본이 튕김 |
| 만드는 법 | 맥동 함수 `p(t)=Σ exp(−(t−t_R)/τ)`를 램프 강도·달빛 갈래 알파·먼지 속도에 곱함(τ 약 0.3 s, 램프 +15–20 %부터 조정). 원본 먼지 파티클 2,000개 재활용 | 기존 HRA 심장(`story/intro/assets/heart.glb`, CC BY)을 종이 질감(면 분할 + 종이 섬유 노멀 + 접힘선)으로. V자 접힘 힌지가 일어서는 키프레임 + 수축은 기존 박동 변형 재사용 |
| 수용 기준 | R 동기 0프레임. 평상시 눈에 띄되 산만하지 않음(맥동 진폭을 단계별 3종 캡처) | 3/4 각도에서 심장으로 읽힘. 책을 가려 파형을 막지 않음 |
| 위험 | 너무 약하면 안 보이고 너무 강하면 "깜빡이는 방" | 종이 오브제 디자인 품질이 승부 |
| 합치기 | `ab`: 방이 약하게, 심장이 강하게 — 둘이 같은 R에 반응 | |

### 5.1 직접 확인한 결과와 "볼 만한 지점" 후보 (2026-10-02, 내장 브라우저)

사용자가 Persepolis 링크(https://persepolis.getty.edu/)를 줬고 직접 확인을 요청했다.

**Persepolis Reimagined (L2).** 구성: 어둑한 안개 낀 들판의 도입 문구 5개 → "Getty presents" → 제목 + ENTER → 지면에서 상공으로 올라 성채 전체를 훑고 → 계단·성벽 접사(돌 질감이 화면을 채움) → 정면 대칭 구도의 "Gate of All Nations"(챕터 점 4개, About this Project). 안개 전환 영상 2개(`fogTransitionIn/Out1080p.mp4`)를 로드하고 캔버스는 1개 `[런타임]`.

## 6.3 업계 관점 피드백 (AI 자체, 2026-10-03)

1. **카메라 연속성.** 열린 책(세워서 정면)에서 페이지 월드(탁자 위, 위에서 내려다봄)로 **시점이 다른 두 장면을 크로스페이드**하는 것은 웹 스토리텔링 사이트의 흔한 약점이다. 한 번의 촬영(single take) 또는 프레이밍이 일치하는 매치 컷이어야 하고, 두 렌더러를 동시에 돌리는 구조는 성능에도 불리하다 → **페이지 월드 폐기, 같은 장면의 열린 책을 무대로**(P-A).
2. **빛이 이야기를 한다.** 조명 없는 베이직 머티리얼 책은 합성 사진처럼 뜬다. 한 점의 **의도된 주광**(새벽 빛이 블라인드 틈으로 책 일부만 가름)이 부피를 만들고, 나머지는 램프 난색 보조광과 그늘로 남겨 **키아로스쿠로 대비**를 만든다. 접촉 그림자·AO가 없으면 "붙어 있는" 느낌이 안 난다.
3. **모션의 문법.** 책 꺼내기에는 예비 동작(살짝 밀림)과 안착, 표지 열기에는 무게(ease-in-out + 작은 오버슈트), 페이지 넘김에는 2차 운동(펄럭임·시차)이 있어야 한다. 지금은 선형에 가까운 보간이라 "애니메이션처럼" 읽힌다. 키 순간마다 **머무름 구간**(Persepolis의 고정 문구처럼)을 둔다.
4. **종이의 물성.** 섬유 노멀, 가장자리·책등쪽 AO와 누렇게 바램, 얇은 종이의 **투과광**(빛이 비치는 가장자리), 인쇄 잉크의 미세한 엠보싱. 두께는 시트 스택(오른쪽 더미가 줄고 왼쪽 더미가 늘어남)으로 만든다.
5. **후처리 스택.** 블룸(램프·맥광), 비네트, 필름 그레인, 책이 주인공일 때 배경 서가에 얕은 피사계 심도, 일관된 컬러 그레이딩. 원본 사이트도 해시 블러·안개·그레인으로 정리한다.
6. **타이포.** 페이지 제목이 작다. 숫자(0 dB)를 크게 쓰는 위계, R 피크 주석, 가독 거리에서 읽히는 크기(D-044). 활판 느낌의 잉크 번짐은 장식으로만.
7. **성능은 기능이다.** 매 프레임 캔버스 재그리기 같은 CPU 경로를 금지하고, 프레임 예산표(메인 ≤ 6 ms, 후처리 ≤ 3 ms @1080p)를 둔다. 전시 PC가 확정되기 전까지 `__bench`로 회귀를 막는다.
8. **심장.** 층층이 쌓인 종이 오려 붙이기는 층 수를 늘려도 "공예품"이지 해부도가 아니다. 사용자 판단(너무 데포르메)이 맞다. 점 구름을 **등가면 메시(marching cubes)**로 복원해 매끈한 해부 심장을 만들고, 젖은 듯한 클리어코트 + 박동 변형(수축)을 준다.
9. **맥동의 시각 언어.** 지금은 "한 번 튀고 사라짐"이다. 박동은 **파면(wavefront)**으로 퍼져야 한다: 심장에서 페이지를 가로질러 파형까지 가는 링 파동이 지나가며 입자가 유영하고 파형이 순간 밝아져, 심장 → 파형 연결(앞선 K2안)이 읽히게.

## 6.5 다음 단계 제안 (사용자 승인 대기, D-048)

| 단계 | 내용 |
|---|---|
| P-A | **페이지 월드 폐기 → 열린 책을 무대로.** 같은 장면·같은 렌더러, 카메라는 스크롤 + 제한 호버. 팝업 심장은 책에서 카메라 쪽으로 일어남. 효과: 컨텍스트 하나, 교차 제거 |
| P-B | **실사 양장본**: 보드 + 둥근 책등(조인트 홈) + 헤드/테일밴드 + 면지 + 리본 + 금박 엠보싱 + 천 직조 노멀 + 책 블록 페이지 라인 노멀, PBR + 작은 환경맵 |
| P-C | **페이지 넘김**: 곡선으로 휘는 시트 N장, 시트 스택 두께, 표지 열림 후 몇 장이 시차로 넘어가 심전도 용지에 안착 |
| P-D | **조명**: 해(블라인드 쿠키) 주광이 책 일부를 가르고, 램프 보조광, 림, 접촉 그림자, 종이 굴곡에 따른 음영, 블룸·비네트·그레인, 배경 DOF |
| P-E | **심장 메시**: 점 구름 → SDF → marching cubes → 부드러운 메시(오프라인 스크립트로 glb 생성), 클리어코트, 박동 변형 |
| P-F | **맥동 FX**: 파면 링이 심장 → 파형으로 퍼지고 입자가 파도치듯 유영, 책 아래 간접 맥광(엔벨로프 연속) |

사용자 결정이 필요한 것: (1) P-A(별도 페이지 월드 폐기)에 동의하는가, (2) 심장은 **사실적 해부 메시(권장)**와 종이 공예 유지 중 무엇인가, (3) 순서 P-A → P-B/C/D(책) → P-E/F(심장·FX)로 가도 되는가.
