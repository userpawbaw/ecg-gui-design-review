# 서고 B3 선택 조합 실제 재렌더 — 2026-10-18

판정: **정지 조명 시안 조건부 PASS**. D-141의 (b) 조각 유지, L2, 기존 30°, 선반 아랫면 ×0.35를 보호된 빌더 기본값과 분리해 렌더했다. 비교 기준은 같은 장면의 아랫면 1.0이다. 이 문서의 이미지는 우리 장면에서 새로 생성했으며 레퍼런스 사이트 에셋/이미지를 저장소에 넣지 않았다. 기기·사람·웹의 최종 승인과는 별개다.

## 출처와 재현 조건

- Python 3.11.17, bpy 4.5.3, Cycles CPU 4스레드, 1280×720, 64 samples, 두 카메라 높이 2.8m/2.0m, 수직 FOV 32°. 각 카메라 목표는 (0, 4.7, 같은 높이), 위치는 (0, −0.8, 같은 높이).
- 혼합은 key 0.5 / sun 0.6 / sky 4 / rest 1 / exposure 0.3, AgX Punchy. `scripts/blender/archive-light-b3.py`의 opt-in 레시피. 장면/EXR은 ignored `dist/archive-light-b3-{selected,baseline}-20261018/`에 보존했다.
- Poly Haven 원본 16종, 총 84 파일의 API MD5 84/84 통과; 저장소 registry GLTF SHA-256과 15/16 일치. 전 파일별 기대/실제 해시는 [source-hashes.json](source-hashes.json). `vintage_wooden_drawer_01`은 공급처 재게시로 원래 SHA `d39f4172d6fcbb285272168d585f4929c3ed27f05e7101d4fe1c4580408fb8e1`, 수신 SHA `4080ecdac2228759dd41a5d5705b984f993bbf6b0f66570824a9dcbbeaa49e51`가 다르다. 조용히 registry 값을 바꾸지 않았다. 구 버전과 완전 byte-identical 재현은 아니다.
- 선택값 두 프레임의 외관: [2.8m](selected-p2-z28.png), [2.0m](selected-p3-z20.png). 기준값은 같은 조건 별도 렌더다.

## 그림자·형태 진단

- 2.0m 시점 `shadow-sharpness-map.py` 160×90 raycast를 720p 화소폭으로 환산: 태양 아래 사다리 가로대 경계 중앙값 **2.3px**(가림 거리 1.15m), 기둥 **1.8px**(0.88m), 먼 잎 **13.2px**(6.7m). 선명/흐림의 거리 층은 재현됐다. [기하 그림자 진단](selected-shadow.json)과 map PNG는 조명 가림 거리 추정이며 실제 화면의 모든 경계 육안 품질을 대신하지 않는다.
- 2.0m 두 조건 `underside-light-sources.py` 160×90 raycast와 EXR 선형 휘도: 같은 678개 그늘 아랫면 표본의 중앙값 **0.0935→0.0375 (−59.9%)**. 같은 417개 윗면 표본은 **0.2675→0.2649 (−1.0%)**. 선택값의 그늘진 아랫면 광원 분율은 key 80.5%·sun 13.1%·sky 3.7%·rest 2.8%다.
- 2.0m 이미지는 L2 사다리 그림자가 서랍장에 선명하게 드리우지만, 사람의 해치 접근 동선은 L2로 인해 이어지지 않는다. 사람·해치 소품은 변경하지 않았다. 장면 빌더의 `figure collisions ... OK` 출력은 사람의 접촉/동선 연출 검수를 대체하지 않는다.
- 이 렌더에 담긴 옛 PC/CRT/ECG 물체 6개는 각각 정점 8·면 6·modifier 없음으로 Q2 FAIL(`verification/r1-prop-craft-gate-20261018/legacy-box-audit.json`). 현재 카메라는 기기 클로즈업이 아니므로 Q1/Q4는 확인 안 함.

## 판정과 후속

- 빛 차폐 층위와 아랫면 전후 차이는 수치/이미지에서 보인다. B3 정지 시안은 **측정상 조건부 통과**: 선반 상판은 거의 유지되고 아랫면은 약 60% 어두워졌다. 화면에서는 계단형 밝기와 사다리의 선명한 선이 유지된다.
- 새 디자인으로 채택됐다는 사용자 확인은 없으며 r8/D-084 기본값이나 제품 장면에 반영하지 않았다. 이 결과는 선택 프리셋 검증이며 전체 빛/미술 재설계 최종본은 아니다.

## 확인 안 함

- key 0.50 선택은 이 정지 이미지 세트에 대한 시각 선호다. 실제 씬 광원 재설정·애니메이션·웹 굽기·Story 통합의 승인으로 확대하지 않았다.

- 사용자 시각 확인, 기기 새 모델의 Q0–Q5 합격, Story 사람/해치 접촉·4방향 자세/실제 이동, B4 자체 소품 키트, 웹 굽기·움직임·목표 PC: **확인 안 함**.
- PH 재게시 서랍 원본의 과거 SHA와 픽셀 동일성: **확인 안 함**. 파일별 MD5 통과는 현재 공급처 파일 무결성만 입증한다.
- 이번 결과를 r8/D-084나 Story 기본값에 반영하지 않았다.

다음 제작 단계: B4 자체 키트의 범위·Story 소유를 먼저 조율하고, 새 PC/CRT/ECG는 `self-authored-3d-props` Q0–Q5를 통과시킨다. 빛은 이 B3 비교를 바탕으로 화면 정리·해치 접근 충돌을 분리해 후속 D를 정한다.
