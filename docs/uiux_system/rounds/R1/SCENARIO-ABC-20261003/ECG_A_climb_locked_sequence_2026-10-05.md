# A 도입부 확정 경로 — 사다리에서 Story 의자로
2026-10-05 · D-063 · UX/MOTION 설계 · 현재 승인: 도입부 오르기 자세와 카메라 경로
이 문서는 D-062의 두 포즈 후보 중 오르기 경로를 현행으로 확정한다. 바닥 앉기 목업은 보류 대안으로 보존한다.
A/B/C 전체 중 최종 제작안 선정과 실제 구현 품질 판정은 별도 단계다.

## 1. 고정한 요소
- 도입부: 같은 서고의 사다리에 두 손/두 발이 닿은 오르기 자세. 실제로 여러 단을 올라가는 동작은 추가하지 않고 정지 자세+미세 idle부터 제작한다.
- 카메라: 하강하며 사다리 발견 → 등 뒤 → 열린 측면 → 가슴/혼합 입력 → 처리/출력.
- Story: 같은 서고의 인접 의자 구역으로 편집 전환. 원인·유입·파형의 한 화면 구도 유지.
- 몸: 불투명한 검은 형태, 얼굴 특징 없는 머리. 심장: 가슴에서만 심실 분리형 amber 형상. 몸 전체 혈관/골격/링 발광 제외.
- 환경 기준: 기존 서고 우측 높은 서가/ECG 기록물, 좌측 고창, 사다리 rail, 우측 카트. 하나의 공통 environment를 사용.
- 승인된 목업의 무드·빛 방향을 시각 목표로 사용한다. 목업의 그림자/후처리 자체를 실제 구현 검증으로 간주하지 않는다.

## 2. 연속 장면 명세
아래 좌표는 1920×1080 설계 프레임 기준이며 실제 asset 바운딩 박스를 확인하기 전의 카메라 조정 목표다. p는 도입부 스크롤 정규화 진행률, t는 계속 재생하는 시간이다. p 구간은 구현 초안이며 시간 지연/스크롤 차단 조건이 아니다.

| 단계 / p | 화면·카메라 | 빛·글자·전이 | 정지할 때 |
|---|---|---|---|
| A0 지구 / 0–.12 | 우하단 지구 중심(1290,850), 남극 relief·구름층·대기 rim. 왼쪽 제목 | 심전도 잡음 제거가 먼저 읽힘. 단일 기록 목적지 locator | 느린 지구/구름 idle; 표적 난점멸 없음 |
| A1 궤도 / .12–.23 | 지평선을 대각으로 돌리며 locator를(1000,520)에 정렬 | 역광에도 지형 유지, 제목은 물러남 | 카메라는 p에 정착, 대기층 idle |
| A2 구름 / .23–.32 | 구름 근경이 좌측을 가림. 뒤 목적지는 고정된 내부 고창과 대응하는 지붕 | 구름 가림 안에서 거리 압축. 외부 건축은 내부 구조로부터 설계 | 구름만 미세 이동, 장소 추가 변경 없음 |
| A3 서고 하강 / .32–.44 | 내려오며 사다리 rail/rung이 먼저 드러남. 고창→서가→사다리 순서. 가까운 보가 화면을 지나감 | 좌측 고창의 broken shaft가 사다리와 바닥에 수광. 서가 깊이 확인 | 환경 완성 룩 유지, 인체는 가림 뒤 |
| A4 등 뒤 / .44–.56 | L04 기준. 사다리 x760, 인체 중심(1010,570). 손·발 접촉과 한쪽 굽힌 무릎, 뒤쪽 카트 | 뒤에서 심장을 투시하지 않음. 등 실루엣과 손/발의 닿는 점이 먼저 읽힘 | 오르기 pose 유지; 큰 climbing 반복 없음 |
| A5 측면·가슴 / .56–.70 | 사다리 열린 쪽으로 약75° orbit, 머리/어깨를 관통하지 않음. 심장이(480,510) 부근으로 이동 | 고창·shaft·서가 수광을 함께 낮춤. 사다리 edge/서가 column은 약하게 남김. 심장 영역이 드러남 | heart 재생은 t에 따름, 카메라 p 정착 |
| A6 혼합 입력 / .70–.82 | L05 기준. 좌측 인체/심장35%, 우측 얕은 격자 x900–1840,y360–790. 큰 제목은 y200 | 제목 잡음이 섞인 심전도→격자/입력의 순차 등장. 입력 amber 과명도 방지. 격자는 파형 뒤 | 약2.5초 표시창 sweep과 심장/R 이벤트 동일 clock. 0dB 실제 신호는 이후 데이터 확인 |
| A7 처리·출력 / .82–1 | 같은 graph 자리, 얇은 표본막 이동. amber 표본→셀→cyan 출력, 작은 제거 성분 아래로 | 전체 투명도 교차만으로 끝내지 않고 처리 사건이 읽힘. 막은 최종 오른쪽 밖, 잡음 제거 결과 제목 | clean sweep 지속, 생성 head 짧은 잔광/소거 끝 국소fade. 실제 타이밍 검증 필요 |

카메라75°는 후보값이다. 심장이 팔/사다리에 가려지면 실제 모델 기준으로 orbit과 pitch를 조정하되 등→측면→가슴의 흐름을 유지한다.
혼합 입력은 시연 연출이며 climbing 자체가 잡음원으로 검증된 것처럼 표현하지 않는다. 각 원인 설명은 Story에서 시작한다.

## 3. 의자 구역으로 연결
1. clean 출력의 sweep가 계속 재생되는 상태에서 카메라가 인접 서가 끝면을 향한다.
2. 가까운 서가 기둥이 화면을 충분히 가리는 지점에서 컷한다. 아래의 좌표 배치는 구현용 제안이며 사용자에게 새로운 구조 변경으로 숨겨 적용하지 않는다.
3. 컷 뒤는 **같은 서고의 인접 의자 bay**. 사람 좌(580,590), 컴퓨터/모니터 우(1390,600), 벽/바닥 콘센트(1710,890). 기존 S01의 원인/유입/파형 구도를 유지한다.
4. 환경광을 회복하고 전원 간섭 상태표시가 등장한다. 전선→AC 근접→장비 물결→가슴/PLI 입력으로 연결한다.
5. 긴 내려오기/걸어가기/앉기 동작은 현재 범위에 추가하지 않는다. 장면 전환은 편집으로 이해되도록 하며 물리적인 실시간 원테이크를 주장하지 않는다.

의자는 별도 방이 아니다. 서가 column/고창 방향/바닥 재질을 공통으로 유지한다. Story 기존 생성 이미지의 건축 차이는 이 공간 기준으로 수정해야 한다.
PLI/BW/EMG 각각 원인→입력→처리→출력 유지. 호흡/쥠은 설명 연출이며 실제 기록자의 동작 증거가 아니다.

## 4. 해당 단계에서 새로 검토할 아이디어
- **빛의 역할 인계:** 심장 강조 전 사다리 수광이 먼저 낮아지고, 심장 박동에 맞춘 작은 밝기 변화가 graph head로 인계된다. 방 전체를 박동마다 강하게 켜지 않는다.
- **표본막의 깊이:** 막 통과 직전 작은 구간만 앞으로 돌출했다가 cyan 출력 면으로 정렬된다. 원인 없는 전체 폭발보다 디지털 처리 사건을 읽히게 하는 A 확장.
두 항목은 제안 상태다. 대표 표본막의 기본 동작부터 검증하고 실제 결과 부족에 따라 선택한다.

## 5. 첫 실제 제작 묶음 — 준비 계획
첫 묶음: **A4→A5→A6**, 사다리 등장/등→측면/heart·mixed waveform.
- 자산: 공통 서고/고창 차광체/사다리 rail·rung/오르기 body pose/심실형 heart/3전극·lead/카트.
- 재질: black body+절제된 rim, 종이/목재 거칠기, 제한된 발광 heart/ECG.
- 빛: 광원→고창 차광→공기 산란→사다리/바닥 수광. 암전에서는 창/shaft/환경을 함께 낮춤.
- 모션: p 카메라와 t 심장·sweep 분리, 포인터 미세추종은 rung접촉/가슴가시성 훼손하지 않는 범위.
- 품질 피드백 준비: 이 묶음의 보이는 환경·hero·support asset/빛/후처리를 갖춘 상태를 제시. clay/geometry 검사는 내부용.
- 검증: 전중후 6–12프레임, shadow/volume/bloom on-off, 등/옆면에서 hand·foot 접촉, 정지p에서 heartbeat/R sync, frame시간·오류. 목표PC 체감 품질은 별도.

## 6. 상태와 다음 순서
완료: 오르기 선택 및 연속 경로 문서 고정.
다음: 보완된 A와 기존 B/C를 같은 기준으로 비교해 제작 순서 결정 → 첫 제작 묶음의 실제 자산/조명 명세와 구현 → 내부검증 → 완성도 피드백.
B 프리비즈 후속 보류는 유지한다. 바닥앉기 L02/L03은 보류 대안이며 오르기 경로가 실제 가시성/접촉을 해결하지 못할 때 비교 근거로 재사용한다.
