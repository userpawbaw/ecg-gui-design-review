## 렉 후보(`prof.cjs`, 640 × 400, 소프트웨어 렌더 SwiftShader, 20 s 동안 그려진 프레임 수 = fps)

- 마우스를 움직이는 동안(`prof_first_move.txt`)도 비율은 같다. 유체는 700 px 미만 창에서 꺼지므로 따로 강제로 켜 쟀다(`prof_fluid.cjs`): 켬 1.51 · 끔 1.58(5 %). 실제 GPU에서는 화면을 2D 캔버스로 다시 그리는 비용(3D 캔버스 읽기)이 더 클 수 있어 **노트북 확인 필요**.
