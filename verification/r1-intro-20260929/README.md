# R1 도입부 검증 (2026-09-29, D-041)

대상: `prototype/v2/src/story/intro/*` — 역광 지구 → 사람 윤곽 → 심장 → 네온 sweep, 잡음 입력 → 저장 출력.
환경: 컨테이너 헤드리스 Chromium(SwiftShader, GPU 없음) `L3`. 전시 PC·실제 GPU `L4`는 아님.

## 다시 만드는 법

```
npm run story                      (사용자 PC — 브라우저로 직접 보기)
node scripts/serve-v2.cjs          (컨테이너 — 빌드본 :4173, 캡처용)
verification/r1-intro-20260929/run-seq.sh      (구간별 12장 × 5)
```

캡처는 `?p=`(스크롤 진행률)·`?t=`(재생 시계)를 고정하고 `window.__intro`로 같은 코드 경로를 한 프레임씩 그린다(`capture.mjs`). 시간을 걸어가는 단계는 상태만 계산하고(`renderOnce(false)`), 마지막 한 프레임만 그린다(O-006).

## 동기화 검증 (사용자 요구 U7)

`prototype/v2/browser-tests/intro.spec.ts` — 반복 두 바퀴, R 30개 모두에서:
- sweep 머리의 표본 = 그 R 표본
- 심장 발광이 그 프레임에서 최대(> 1.25), 한 프레임 전에는 없음(< 0.6)
- 수축은 R 프레임에서 시작(그 전 0)

결과: 2 PASS(동기화, 라벨·Lab 진입). 기존 e2e(story·expo) 5 PASS + 1 SKIP(10분 soak — replay 자료 없음, 이전과 같음). v2 단위 테스트 18 PASS / 1 FAIL(600초 chunk 자료 없음, 이전과 같음).

처음 실행에서 동기화 테스트가 실패했다: sweep 머리는 `floor(t·fs + 1e-6)`, 박동은 실수 시간 비교를 써서, R 표본이 그려지는 프레임에 심장이 아직 직전 박동으로 판정될 수 있었다(부동소수 오차). 박동도 같은 정수 표본 기준으로 바꿔 해결했다.
