# 레버 카탈로그 — 후보를 넓히는 체크리스트

6단계에서 레버를 하나씩 대보며 "여유 지도의 어느 칸에 걸 수 있나"를 묻는다. 각 레버는 **무엇을 잃는지**와 **그 손해가 보통 어디서 무료가 되는지**를 같이 적었다. 프로젝트 안 실제 사례는 괄호 안 기록 번호.

| 레버 | 하는 일 | 잃는 것 | 보통 무료가 되는 곳 |
|---|---|---|---|
| **L1 안 보이면 안 함** | 가려진 곳·화면 밖·숨은 탭·꺼진 상태는 계산하지 않음(가시성 컬링, scissor/stencil, 탭 숨김 정지) | 가림 경계의 정확도, 덮개가 움직일 때 드러나는 빈칸 | 불투명도 높은 패널 아래, 탭이 안 보일 때 |
| **L2 덜 자주** | 바뀔 때만 다시 계산, 낮은 갱신률, 여러 프레임에 나눠 계산 | 반응 지연, 움직임 부드러움 | 정적이거나 천천히 바뀌는 것, 배경 (실험실 배경 = 카메라가 움직일 때만 그림, D-153) |
| **L3 더 작게** | 해상도·정밀도·샘플 수 낮추고 올려 쓰기(양방향 업샘플, 블러) | 세부·가장자리 | 블러·안개·커튼 아래, 저주파 신호 (빛줄기 반 해상도 + 깊이 인식 블러, D-169) |
| **L4 중요한 곳만 정밀** | 중요도 지도(빛 받는 곳, 시선, 데이터 주변)에서만 원래 품질, 나머지는 L3 | 중요도 판정이 틀린 곳의 품질 | 사용자가 "배경은 뭉개도 된다"고 한 곳 |
| **L5 미리 계산(굽기)** | 오프라인·로딩 시·처음 쓸 때 한 번 계산해 저장(라이트맵, 임포스터, 실행 중 굽기) | 변화 가능성(동적 요소), 저장 공간, 처음 계산 시간 | 정적 조명, 고정 경로, 고정 시점 (서고 라이트맵) |
| **L6 재사용** | 이전 프레임·결과 재투영, 메모이즈, 증분 갱신 | 움직임이 클 때 잔상 | 작은 시점 변화, 반복 계산 |
| **L7 근사 모델** | 정확한 계산을 값싼 모델로(레이마칭 → 빛 카드 메시, 해석식, 표 조회) | 물리 정확도, 특수 경우 | 인상만 필요한 장식 효과 |
| **L8 표현 바꾸기** | 3D → 이미지/영상, 영상 → 3D, DOM → 캔버스, 자료 구조 교체 | 상호작용 폭(시차, 자유 시점), 제작 파이프라인 | 시점 변화가 회전뿐일 때(이미지 원근 변환이 정확, F-019) |
| **L9 경쟁 피하기** | 무거운 작업과 겹칠 때 양보(재생 중 정지, 우선순위, 프레임 시간 보고 품질 자동 조절) | 겹치는 동안의 품질·반응 | 사용자 시선이 데이터에 가 있는 동안 (실험실 재생 중 배경 정지) |
| **L10 플랫폼 활용** | GPU 디코드, 워커, WASM, 하드웨어 기능 | 이식성, 디버깅 난이도 | 대상 PC가 확정된 경우 |
| **L11 범위 줄이기** | 실제로 쓰이는 입력 범위만 지원(회전 ±3°, 스크롤 0) | 나중에 범위를 넓힐 때 재작업 | 범위가 사용자 결정으로 고정된 경우 |
| **L12 요구 재정의** | 기능 자체를 빼거나 바꾸자고 제안 | 기능 | **사용자 승인으로만** — 질문으로 제시 |

## 코드·데이터 쪽 대응
| 그래픽스 레버 | 코드·데이터에서 같은 레버 |
|---|---|
| L1 | 안 쓰는 경로 지연 로딩, 화면 밖 컴포넌트 렌더 생략 |
| L2 | 디바운스·스로틀, 변경 감지 후 재계산 |
| L3 | 다운샘플(표시 해상도보다 촘촘한 데이터는 그리지 않음), 정밀도 축소 |
| L5 | 빌드 시 사전 계산(정적 JSON, 인덱스), 캐시 |
| L6 | 메모이즈, 증분 계산, 링 버퍼 |
| L7 | 근사 알고리즘, 표본 추출 |
| L9 | 우선순위 큐, requestIdleCallback, 백프레셔 |
| L10 | 웹 워커, SIMD |

## 조합 규칙
- 필수 기능이 사는 영역은 레버를 걸지 않거나 L4로 보호한다.
- L5(굽기)와 L2(덜 자주)는 겹치면 효과가 곱해진다: 한 번 굽고, 다시 구울 때만 비용.
- 같은 요소를 굽기와 실시간 양쪽에 두지 않는다(F-020: 멈춘 먼지 + 움직이는 먼지).
- L8로 표현을 바꿀 때는 그 표현으로 정확히 되는 물리(회전)와 안 되는 물리(이동 시차)를 먼저 가른다(F-019).
