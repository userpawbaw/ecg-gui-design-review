# J-004. 이야기 장면 책상 구석 — 웹 램프 빛에서 구운 소품 세트(A안) 채택까지, 새로 지은 공간(C안) 기각

| | |
|---|---|
| 기간 | 2026-10-15 ~ 2026-10-17 |
| 도착 | P-007 |
| 기록 | D-067, D-070, D-071, F-043, R-024, REF-002, `verification/r1-story-feedback-20261011/README.md` |

## 출발점

이야기(전원 간섭) 장면의 책상 구석에 웹에서 덧붙인 컴퓨터·프린터·램프가 있었다. 사용자는 이를 "장난감 수준"이라고 봤다. 원하는 것은 leoparpeix 다락방처럼 두 가지였다.
- 빛: 선명한 접촉 그림자와, 화면 밖 물체가 드리우는 흐린 그림자.
- 에셋: 베벨이 있어 질감이 뭉개지지 않는 소품.

## 흐름 한눈에

```
T1 웹 램프 + 화면 빛(D-067) ──(사용자 "내가 원하는 불빛이 아니야")──▶ T2 leoparpeix 재해부 → A안: 서고 안에 구운 소품 세트
   ──(흰 면 번짐)──▶ T3 반사율·인코딩 상한 수정 ──(사용자 "C안도 별개로")──▶ T4 C안: 공간을 새로 지어 통째로 굽기
   ──(사용자 "A안이 훨씬 낫네")── 끝: A 채택, C 기각 + 자체 진단(F-043)
```

## T1. 웹 램프와 화면 빛을 구운 서고 위에 더하기

| | |
|---|---|
| 날짜 | 2026-10-15 ~ 2026-10-16 |
| 종류 | 시도 |
| 계기 | 사용자 `[대화]`: "명암의 대비가 선명한 그림자와 아닌 부분, 반사광 등이 표현되었다고 보기는 어려워 보여" |
| 가설 | 웹에서 램프 스폿·화면 발광·램프 그림자 지도를 구운 방 위에 더하면 책상 구석에 빛의 볼거리가 생긴다 |
| 판정 | 기각 |
| 다음 | T2 |
| 기록 | D-067, `verification/r1-story-feedback-20261011/36_desk_light_L1_vs_L2.jpg` |

### 한 것
L1(램프 웅덩이 + 화면 빛), L2(램프 그림자 지도, 빛 원뿔, 갓 빛)를 만들었다. 책상 높이 차단선이 상판보다 높아 빛이 책상에 닿지 않던 결함도 고쳤다.

### 결과
사용자 `[대화]`: "전등도 내가 원하는 불빛이 아니야. 내가 원하는건 이전의 leoparpeix 다락방처럼 제대로 선명한 그림자가 나타나는 부분 … 흐릿한 그림자가 자유분방하게 드리워지는 부분". 기본값은 꺼짐(L0)으로 돌렸다.

### 왜 다음으로
원하는 그림자 두 종류(접촉 경화·화면 밖 고보)는 레퍼런스에서 굽기로 만들어진 것이었다. 웹의 국소 빛으로는 간접광과 흐린 그림자가 나오지 않았다.

## T2. A안 — 서고는 두고 책상 구석만 소품 세트로 다시 만들어 굽기

| | |
|---|---|
| 날짜 | 2026-10-16 |
| 종류 | 비교 |
| 계기 | T1 기각, 사용자 `[대화]` "A안으로 진행해줘. 컴퓨터는 빼고 소품으로 바꿔줘" |
| 가설 | 해 하나 + 화면 밖 창살·잎으로 구운 베벨 소품을 서고 안에 놓으면, 서고의 밀도·주제는 유지한 채 빛의 볼거리가 생긴다 |
| 판정 | 채택 |
| 다음 | T3 |
| 기록 | D-070, REF-002 §11, `scripts/assets/desk-corner-set.py` |

### 한 것
leoparpeix 홈 장면을 다시 해부했다(해 하나, 여러 구멍, 화면 밖 식물, 그룹별 색×빛 굽기). 책상·카드 서랍장·깊은 칸 책장·액자·다면체·러그를 Blender에서 구웠고, 구운 서고의 옛 책상 부분은 부피로 잘라냈다.

### 선택지와 기준
- A: 책상 구석만 굽기.
- B: 웹 실시간 고보.
- C: 공간 재설계.

기준은 접촉 경화 그림자와 흐린 그림자가 함께 나오는지, 그리고 서고 빛 세션 파일을 건드리지 않는지였다.

### 결과
러그 위의 의자·책상 다리 그림자가 선명하고, 책상 위에 잎 얼룩이 생겼다. 깊은 칸은 안쪽으로 갈수록 어두워졌다 `[캡처]`(시트 37).

### 왜 다음으로
두 구멍 굽기 뒤 웹에서 종이·흰 도형이 하얗게 타서 번졌다.

## T4. C안 — 이야기 장면 공간을 다락방으로 새로 지어 통째로 굽기

| | |
|---|---|
| 날짜 | 2026-10-17 |
| 종류 | 시도 |
| 계기 | T3 뒤 사용자 지시 |
| 가설 | 공간 구조(경사 천장·천창·아치 창·사다리)를 leoparpeix처럼 새로 지으면 빛과 공간이 레퍼런스에 더 가까워진다 |
| 판정 | 기각 |
| 다음 | T5 |
| 기록 | D-071, F-043, R-024, `scripts/assets/desk-room-c.py`, `verification/r1-story-feedback-20261011/38_route_a_vs_c_pli.jpg` |

### 한 것
세 장면 카메라 경로를 뽑아 모든 시점을 감싸는 다락방을 지었다. 볕이 떨어질 자리(책상·멀티탭)에서 해 방향으로 거슬러 천창 두 개와 창을 배치했다. 미리보기 9회 끝에 본굽기를 하고 웹에 연결했다(`?set=C`).

### 결과
사용자 `[대화]`: "A안이 훨씬 낫네." 측정으로도 주 장면에서 C안이 낮았다(F-043 표) `[런타임]`.
- 깊은 어둠: 28 % → 15 %.
- 볕 면적: 5.3 → 2.7 %.
- 결정적 경계: 10.6 → 5.5 ‰.
- 질감 밀도: 약 −40 %.

원인은 다섯 가지였다.
- 주제 물체가 빠졌다.
- 빛을 화면이 아니라 바닥 좌표로 설계했다.
- 어둠을 하늘빛으로 메웠다.
- 큰 민무늬 면이 화면을 차지했다.
- A안과 같은 톤·측정기로 비교하지 않고 진행했다.

### 왜 다음으로
사용자 `[대화]`: "다음 번에 C안보다 A안처럼 꽉 차게 나오려면 어떤 데이터와 사전 설계 검토 시스템이 필요할까?" 이어서 "좋아. 만들고 실제 진행 테스트 해보자."

## T5. 프레임 예산 검사기를 만들고, C안을 그 순서로 다시 고쳐 보기(C2)

| | |
|---|---|
| 날짜 | 2026-10-17 |
| 종류 | 시도 |
| 계기 | T4의 자체 진단(F-043)과 사용자 지시 |
| 가설 | 채택안에서 뽑은 프레임 예산으로 빠른 굽기를 라운드마다 판정하면, 새 안이 본굽기 전에 채택안 수준으로 수렴하거나 수렴하지 못함이 일찍 드러난다 |
| 판정 | 부분 채택 |
| 다음 | 끝 |
| 기록 | `scripts/qa/frame-budget.py`, `scripts/qa/frame-capture.cjs`, `verification/r1-story-feedback-20261011/README.md` §14, R-024 |

### 한 것
검사기를 만들어 A 재캡처(49/49)와 C1(14/49)로 먼저 검증했다. 이어서 C2를 3라운드 고쳤다(서가·기록 상자, 하늘빛 앞창 제거, 천창 추가·확대, 바닥 변경, 노출).

### 결과
- 판별 도구로는 동작했다. 라운드당 약 6분에 판정이 나왔다 `[런타임]`.
- 1라운드에서 검사기 결함을 찾아 고쳤다. 하한만 둔 어둠·볕 면적이 새카만 화면과 볕 42 % 화면을 통과시켰다.
- C2는 24 → 22 → 21/49로 수렴하지 않았다. 어둠은 A 범위로 들어왔지만 결정적 경계·질감 밀도·흐린 그림자는 A의 약 60 %에 머물렀다. 3라운드 한도에서 멈췄다.

## 도착점

A안(구운 서고 + 구운 소품 세트)을 채택했다. C안 자산은 비교용으로 남긴다. 공간·세트를 새로 지을 때의 사전 설계 검토 순서를 P-007로 묶고, 검사기(`scripts/qa/frame-budget.py`)로 판별력을 확인했다. 그 순서로 새 안을 채택안 수준까지 끌어올리는 것은 아직 확인하지 못했다(T5).

## 여정에서 얻은 것

1. 레퍼런스의 빛은 "어디에 볕이 떨어지나"가 아니라 "각 프레임에서 밝은 면과 어두운 면이 몇 %씩, 어떤 경계로 나뉘나"로 옮겨야 한다(T4).
2. 기존 공간이 가진 주제·밀도는 새로 짓는 순간 0에서 다시 시작한다. 새로 짓는 안은 그 밀도를 대체할 계획이 먼저 있어야 한다(T2 대 T4).
3. 어둠이 지나칠 때 전체 밝기를 올리면 층위가 사라진다. 빛이 닿는 면을 바꾼다(T4).
4. 검사기는 실제 후보에 돌려 봐야 결함이 드러난다. 한쪽 경계만 둔 지표는 반대쪽 극단을 통과시킨다(T5).
