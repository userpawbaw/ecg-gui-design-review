# 자체 소품 검수 기록 양식

소품명 / 버전 / 적용 브랜치·커밋 / 소유 범위:
목적·관찰 카메라(위치, FOV, 해상도) / Blender 버전:
참고 사진·제조사 치수 링크(복제 파일 저장 금지), 실제 치수와 가정:
선택 제작 경로(mid-poly / high→low / subdivision), 선택 이유:
검수용 이미지(클로즈업 clay: 정면·측면·3/4, 최종 화면 clay·재질, 필요하면 역광/matcap):

| 관문 | 값·방법·증거 | PASS / CONDITIONAL / FAIL / 확인 안 함 | 실패 수정 또는 예외 이유 |
|---|---|---|---|
| Q0 소유·출처 | | | |
| Q1 치수·실루엣 (실제 3특징) | mm/m; 정면·측면·3/4 | | |
| Q2 엣지·단차·법선·기하 | 베벨/인셋 mm; 비균일 scale; zero-area/nonmanifold/겹침; 클로즈업 | | |
| Q3 재질·UV·베이크 | 원본/적용/압축 비교, 맵 크기·UV 텍셀 | | |
| Q4 실제 화면 | 카메라·출력 크기, 주요 형태와 엣지의 실측 px | | |
| Q5 장면·성능 | 접촉·충돌·가림, tris/재질/텍스처/파일 크기 | | |

성능 예산이 정해지지 않았으면 `확인 안 함`이라고 적고 측정값만 남긴다. 서로 다른 카메라·해상도 또는 다른 장면 버전을 비교하면 해당 차이를 명시한다. Q1/Q2 FAIL은 재질로 덮지 말고 형상 단계로 돌아간다. 자동 검사 결과와 사람이 본 이미지 판정을 분리한다.
