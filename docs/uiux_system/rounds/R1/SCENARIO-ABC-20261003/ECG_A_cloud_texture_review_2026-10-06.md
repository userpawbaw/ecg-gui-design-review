# A 구름 질감 수정 검토 — 2026-10-06

연결: D-078, F-049, CASE-007. 원본 첫5종 검토는 ECG_A_cloud_mockup_review_2026-10-06.md.

## 피드백과 진단

[대화] 사용자는 구도와 양감에 만족하지만 질감이 이상하며 레퍼런스를 참고한 수정을 요청했다.
[추론] 기존 J5v3에서 작은 알갱이가 면 전체에 반복되고 외곽의 긴 섬유가 연결되어 폼·거미줄 같은 느낌을 준다고 판단했다. 이 진단은 사용자의 직접 발언이 아니다.

## 참고 범위

- [NASA Bubbles In The Sky](https://svs.gsfc.nasa.gov/10896): 실제 적운 사진과 대류 설명을 제공하는 1차 자료. ISS016-E-27426 사진 링크 접근; 다른 STS 고해상도 링크는403. 사진을 생성 입력으로 제공하거나 정확한 측면 재현을 증명한 것은 아니다.
- [Nubis, Evolved](https://www.guerrilla-games.com/read/nubis-evolved): 제작자가 근접/통과 가능한 볼륨 구름의 모델링·렌더링 접근을 설명한다. 이번에는 발표 소개를 확인했으며 새로운 shader 구현이나 발표 전체 분석을 수행하지 않았다.
- 적용한 디자인 판단 [추론]: 큰 융기와 중간 덩어리는 남기되 미세 변화는 불균일하게; 불투명 core와 낮은 밀도의 경계 구분; 얇은 경계를 긴 연결 섬유로 표현하지 않는다. 실제 구름도 작은 덩어리를 가질 수 있으므로 모든 요철을 없애는 규칙으로 확대하지 않는다.

## 제작과 자체 검토

| 버전 | 입력 | 관찰 | 상태 |
|---|---|---|---|
| J5v3 | 기존 anchor | 구도·양감 만족, 반복 알갱이/연결 섬유 진단 | 구도·양감 KEEP / 질감 수정 대상 |
| J5v4 | J5v3 | 알갱이·음영 대비가 완화됐으나 아래 섬유 남음 | 중간 후보 보존 |
| J5v5 | J5v4 | 아래 연결 섬유가 더 줄고 면의 음영이 연속적으로 보임 | 질감 TUNE / 사용자 평가 전 |

정밀 픽셀 불변을 주장하지 않는다. 큰 군집 위치·높은 타워·중앙 틈·카메라와 빛 방향은 시각적으로 대체로 유지됐다. 큰 덩어리 사이 작은 결절 반복과 일부 외곽 장식 패턴은 남아 있다. 완전히 실제 구름과 같은 질감으로 완료했다고 주장하지 않는다.

이번은 새 사용자 피드백 라운드 initial1+자체수정1(총2회). 이전 D077 initial5+자체수정3과 별도다.
모든 output은 원본 보존한 native PNG; 정확 prompt/parent/hash/size는 manifest.json. 사진은 문헌 참고이며 이미지 입력은 기존 생성 PNG뿐이다.
