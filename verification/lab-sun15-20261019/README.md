# 실험실 서고 15° 판 (D-078, F-053) — 2026-10-19

사용자 요청: "너무 어둡네... 빛 각도를 15%로 바꾼 버전도", 빛 커튼을 더 많이, 큰 웅덩이 하나, 선명·반그림자·다양한 각도의 빛, 어둡고 차가운 원인 확인(반사 횟수인지 해 고도인지).

## 원인 진단 (F-053)
같은 카메라·장면에서 한 조건씩 바꿨다(`verification/lab-c1-20261018/06_dark_warm_diagnosis.jpg`). 반사 4 → 12회와 해 고도·방향은 평균 밝기를 ±10 % 안에서만 바꿨다. 통로 램프의 따뜻한 전구 두 개를 다시 넣으면 2배(0.046 → 0.091)가 되고 R/B는 1.73 → 3.76이다. 푸른 하늘빛은 그늘을 차갑게 한다.

## "15°" 해석과 선택
- 첫 미리보기(면과 15°, 고도 35°, 천창 하나): 밝고 따뜻하지만 큰 웅덩이가 거의 안 보인다(`02_first_preview_f15e35.jpg`). 면과 15°면 면이 받는 빛이 약 26 %다.
- 같은 카메라 비교(`01_angle_variants_c1_mid.jpg`): **면과 15° · 고도 15°**가 볕이 가장 크고 밝다(95 백분위 0.41, 밝은 화소 10.8 %).

## 만든 것 (`?sun=15`)
- 해 (0.933, 0.259, −0.259)(Blender): 면과 15°, 고도 15°, 크기 0.5°. 천창 없음. 창 둘(y −3.8, −2.2)이 진행 약 5–11 %, 42–48 %에서 카메라를 지난다(계산).
- 뒤쪽 창(y 3.95) 1.0 → 1.3 m, 블라인드 없음: 큰 웅덩이 하나. 가운데 문살이 선을 긋는다.
- 통로 램프 메시는 빼고 전구 빛은 남김. 하늘색 #7d96c4 → #b4aa9c.
- 잎: y 2.6, 1.0 창 밖.
