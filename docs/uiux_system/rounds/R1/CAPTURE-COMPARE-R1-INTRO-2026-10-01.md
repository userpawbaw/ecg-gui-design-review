# 레퍼런스 5곳 ↔ R1 도입부 — 캡처 비교 (2026-10-01, 로컬 캡처 도구)

대상: RM-01 Oryzo · RM-02 Igloo · RM-03 ATMOS · RM-08 Superpower · RM-12 Spline heart, 그리고 우리 R1 도입부(story).
방법: `tools/reference-capture` 빠른 모드(D-046) — **위치 조사(survey)** 와 **호버(hover)**. Windows + headed Edge 154 + RTX 3070(D3D11), 1920×1080, 화면 주사율 약 58 Hz. 증거 태그 `[런타임]`.
원본 프레임·시트는 저장소 밖(`%USERPROFILE%\ecg-captures\S-*`, `H-*`)에 있다. 이 문서는 수치와 해석만 담는다(레퍼런스 픽셀 비커밋 규칙).
이 문서는 비교와 근거 정리이며 **구현 선택이 아니다** — 아래 시사점은 D-039에 따라 사용자 반응을 받은 뒤 구체화한다.

## 1. 측정 방식과 읽는 법

- **위치 조사**: 휠 100칸을 50 ms 간격으로 일정 거리(0.5–4 화면, 페이지 길이에 맞춤)만큼 보내고 2 s 가만히 둔 뒤 정지 화면(1920×1080)을 저장 → 끝까지(또는 36곳) 내려간 뒤 **같은 스크롤 위치로 돌아오며** 다시 저장. 정지 지점마다 이동 중 평균 변화 에너지, 정착 시간(입력이 끝난 뒤 변화가 평소 수준으로 돌아오는 시간), 평소 움직임(마지막 0.6 s 변화), 왕복 정지 화면 차이를 얻는다. 왕복 차이가 작으면 화면이 스크롤 위치의 함수(scrub), 크면 이력 의존(한 번 발동·방향 의존)이다.
- **호버**: 포인터를 화면 가로·세로로 훑은 뒤, 화면 안의 상호작용 후보(링크·버튼·`cursor:pointer`)에 접근 → 1.2 s 머무름 → 이탈. **클릭은 하지 않았다**(사용자 결정). 반응은 대상 상자 안/밖 변화 에너지로 판정하고, 화면 전체가 변하는지(`global`) 상자만 변하는지(`local`)를 가른다.
- 변화 에너지 = 인접 프레임 화소당 평균 절대 RGB 차이(0–255). **어두운 장면은 값이 작게 나오는 편향이 있어** 사이트 간 절대 비교보다 같은 사이트 안의 분포와 정성 판단을 우선한다.
- 빠른 모드는 실시간 실행이라 프레임 정확도가 주사율·PC 성능에 묶인다. 전환 곡선·시차를 인용하려면 해당 구간을 A층(가상 시계)으로 다시 찍는다(Oryzo 코르크 전환은 T4/T6에서 이미 A층으로 찍음).

해석:
- 우리와 같은 **scrub 구조**(화면 = 스크롤 위치의 함수)는 Oryzo·Superpower와 같다. 구조 자체는 레퍼런스급이다.
- **가만히 있을 때 우리는 완전히 멈춘다**(앰비언트 0.03). Igloo는 입자·안개 때문에 정지 지점 대부분이 계속 움직이고(35/73), Oryzo도 10곳이 움직인다. "살아 있는" 느낌의 차이는 여기서 온다 `[추론]`.
- 우리 장면은 변화가 **한 곳(파형 무대 진입)에 집중**되고, Oryzo·Superpower는 전 구간에서 크게 바뀐다. 다만 에너지 편향(어두운 장면)이 있어 정성 확인이 필요하다 — 우리 지점 d01–d14의 정지 화면을 보면 지구→사람 윤곽→심장이 한 물체 연속으로 이어져 **match cut 연속성은 좋다**.
- Igloo의 정지 화면 36장은 하나의 세계(이글루 → 얼음 결정 → 고리 → 펭귄 → 이글루)를 18,000 px 이상 끊김 없이 지나간다. 우리 도입부는 지구 → 사람 → 심장 → 파형 무대로 구도가 바뀌지만 그림체가 5종이라는 F-030 진단과 일치한다.
- 우리 스크롤의 정착은 지점에 따라 길다(진행 0.34·0.57·0.62·0.68 지점에서 1.6–2.0 s). `Lenis duration 1.6 s`와 `damp 0.33` 설정의 결과다 `[코드]` — Oryzo 633 ms, Igloo 783 ms보다 늦다.

## 4. 사이트별 한 줄과 도입부 시사점 (선택지, 구현 아님)

- **Oryzo**: 같은 물체가 크기·위치를 바꿔 3D 무대에서 UI 칸으로 이어지는 전환(T4/T6 A층 캡처로 확인), 호버 시 장면 전체 감광. → 심장이 마지막에 파형 무대의 기준 요소로 줄어드는 전환(REFMINE RM-01 번역), 링크·버튼 호버 시 도입부 전체 감광/복귀.
- **Igloo**: 하나의 세계를 끊김 없이 지나가고 정지해도 입자가 흐른다. → 지구·사람·심장을 같은 입자 집합으로 잇고(RM-02), 정지 구간에 느린 입자/먼지 앰비언트(속도 반응은 장식층 한정).
- **Superpower**: 사진 한 장 구도(역광 원반 + 옆얼굴)로 3초 안에 전달, 화면 구성이 단순. 팝업 모달이 스크롤을 잠그는 UX는 따라 하지 않는다.
- **ATMOS**: 입장 버튼 뒤 콘텐츠 — 이번 조사로는 장면 수집 못 함(§5). 색 대본(우주 남색 → 역광 주황 → 몸 안 적색 → 용지 청록)은 문서 근거만 있음(L1).
- **Spline heart**: 해부학적 굴곡(혈관·표면 요철)이 있는 단색 매트 메시 + 부드러운 음영(`[캡처]`, 정지 화면). 우리 심장은 가장자리 림 라이트 한 겹에 내부가 검정 — F-030(재질 층 부족)과 같은 진단을 눈으로 확인했다.

## 5. 한계와 미수집

- **ATMOS 본 콘텐츠**: 입장 버튼 클릭이 필요해 수집하지 못했다(클릭 제외 결정). 입장 버튼만 예외로 허용할지 사용자 판단이 필요하다.
- **Igloo 호버·왕복**: 상호작용 요소가 DOM에 없어 호버 대상 자동 탐색이 실패했고, 가상 스크롤이라 진행률을 못 읽어 왕복 위치가 어긋났다(왕복 차이 25.7은 비교 불가로 취급).
- **Spline heart**: 3D 장면 안 조작(드래그 회전·재질 패널)은 클릭/드래그가 필요해 못 했다. 재질 패널 구성은 여전히 L1.
- **Superpower**: 8 s경 프로모션 모달이 호버·스크롤을 방해한다. Esc로 닫는 방식은 모달 종류에 따라 안 먹힐 수 있다. 호버 첫 대상은 모달과 시간이 겹쳐 신뢰하지 않는다.
- 빠른 모드는 프레임 정확도가 화면 주사율(약 58 Hz)에 묶인다. 변화 에너지는 어두운 장면에서 작게 나온다. 전시 PC 성능은 여전히 모른다.
- 레퍼런스 코드·에셋은 확보·저장하지 않았다(수치·구조·짧은 관찰만).
