# IDEA-R1-DISEASE-TOUR — 질환 특징 설명을 파형 창 안의 「멈춤 · 초점 · 해제」 투어로 (D-192 설계안)

시점 2026-11-24 `[대화]` · 대상: 심질환 파형 탭, 첫 질환 심실 조기 수축(PVC) · 이전 안: D-191(위쪽 별도 카드)

## 1. 사용자 요청(원문 요지)
- 특징 설명을 **기존 파형 창으로 통합**. 초기 행은 **입력(질환) 파형 + 정상 파형 2개**. 기법은 실험실처럼 추가 가능.
- 오버레이는 공간감이 없다 → **그림자 · 투명도로 앞에 은은하게**.
- 왼쪽은 **짧은 제목만**(간결한 학술체, 한자어 + 무엇이 일찍 오는지 명시. 예: 「예상보다 일찍 온다」→「R파 조기 출현」). 2줄 설명 삭제.
- 설명은 **재생 버튼으로 시작**. 사용자 제안 흐름: 재생 → 특징이 화면에 다 들어올 때 **정지** → 화면 어두워지고 **핵심 부위만 밝게(비네팅)** + 문구 · 오버레이 페이드 인 → **약 4 s 유지** → 페이드 아웃 · 밝기 복귀 → **약 2 s 재생**(다음 특징을 잘 보이는 위치까지, 길이 가변) → 다음 특징.
- 특징은 6개 → **대조가 확실한 대표 3개**.

## 5. 한 특징의 시간표(기본값)
감속 0.5 s → 초점 · 어둡게 0.6 s(카드는 0.2 s 늦게 0.5 s 페이드 인, 캘리퍼 0.5 s) → 유지 4 s → 카드 · 유령 페이드 아웃 0.5 s, 밝기 복귀 0.6 s → 가속 0.4 s → 다음 정지점까지 재생(가변).
멈춤 위치: 특징 끝 + 여유 0.4 s가 화면 오른쪽 약 65 % 자리에 오도록 재생 시작점을 미리 계산(프리롤). 투어 동안은 **스크롤 표시**(최신이 오른쪽)로 두고 끝나면 원래 표시 방식으로 돌림 — 스윕은 커서가 특징을 가로지를 수 있다.

## 6. 정상 행 자료 — 결정 필요
- N1(권장) **같은 기록의 정상 박동 평균을 정상 R–R로 배치한 기준 행**: 질환 행의 정상 박동에 맞춰 놓이고, 이상 박동 자리에는 「정상이면 왔을 자리」에 놓임 → 조기 · 휴지가 위아래 정렬로 바로 보임. 단점: 실제 측정 파형이 아님 → 행 이름에 「정상 기준(합성 · 같은 기록 평균 박동)」 명시.
- N2 **실제 정상 기록(100번) 파형**: 실측 그대로. 단점: 다른 사람 · 다른 박자라 위아래가 맞지 않아 「일찍 / 늦게」 대조가 안 됨.
- N3 **같은 기록의 실제 정상 구간**: 같은 사람 실측. 단점: 첫 R만 맞고 이후는 어긋남.
