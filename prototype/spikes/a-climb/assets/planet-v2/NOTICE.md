# A-P2 planet trial sources

- NASA Earth Observatory / Jesse Allen, Blue Marble July 2004 and GEBCO relief: see `../earth/manifest.json`. Original imagery retained; artistic ocean/ice material interpretation is separate.
- Reference Elevation Model of Antarctica (REMA), Polar Geospatial Center / Howat et al., mosaic v2.0 1km. [Dataset and CC BY 4.0](https://registry.opendata.aws/pgc-rema/). [Source mosaic](https://data.pgc.umn.edu/elev/dem/setsm/REMA/mosaic/v2.0/1km/). Acknowledge PGC support and the REMA collaborators described on the dataset page. Local EPSG3031 resampling, latitude -60 to -90; source hash in manifest. Source measured metres are distinct from 5x display displacement and polar no-data display infill.
- Shota Matsuda / Takram, `@takram/three-atmosphere` 0.19.1, Bruneton atmospheric model. [Repository](https://github.com/takram-design-engineering/three-geospatial). LUT files pinned to eac103980f20c0956f2d3215833e73514be08462; MIT notice in `../atmosphere/LICENSE-MIT.txt`. Blue radiance balance is this project's artistic extension.
- `cloud-noise.r8` is synthetic periodic value FBM, generated by `scripts/assets/prepare-planet-v2.py`; released as CC0 data. NASA coverage does not make the synthetic density an observed weather volume.

`antarctic-height.f32.bin` contains gzip-compressed little-endian float32, 2048×512. The neutral suffix prevents HTTP servers from implicitly decompressing it before the explicit browser decoder. Regenerate with the preparation script after obtaining the pinned REMA tar. The atmosphere library and composer bridge do not require React UI migration.

ambientCG Snow014 was not acquired (two connect timeouts) and is not used. No micro-ice normal texture or scientific cloud shadow claim is made.
