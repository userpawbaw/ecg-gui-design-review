# D-175 기저선 변동 장면 북카트 번쩍임 (2026-11-11)

사용자: 「기저선 변동 단계의 사다리 옆 북카트를 볼 때 가장 확연」.

## 방법 — 60 fps 프레임 단위 확인
`scripts/qa/step-capture.cjs`: 페이지를 Playwright 가짜 시계로 돌리고, 매 프레임 장면 시계를 정확히 1/60 s 진행(`__noise.set({t})`)한 뒤 찍는다. 소프트웨어 렌더(이 환경)라도 60 fps 화면의 프레임 순서를 그대로 얻는다.
`scripts/qa/frame-metrics.cjs`: 앞뒤 두 프레임보다 24/255 넘게 밝아졌다(어두워졌다) 돌아오는 픽셀 = 한 프레임짜리 번쩍임 수. `flash-map.cjs`: 그 픽셀을 자홍색으로 표시.

## 찾은 것
- 0–5.5 s 전체(330프레임): 카메라가 빠르게 도는 구간의 큰 값은 대부분 움직이는 모서리(한 프레임에 1 px 넘게 이동)다(`03_orbit_frame125_motion_edges.png`).
- 카메라가 멈춘 뒤(4 s 이후)에도 **북카트 오른쪽 세로 막대**에 지름 20–30 px의 둥근 빛이 한 프레임씩 나타났다(`02_hold_frame313_flash_map.png`).
- 이 장면만 카메라가 숨에 맞춰 위아래로 1.5 cm 움직인다(`breathOff`, 기저선 변동 장면 전용). 햇빛 받는 가는 막대가 픽셀 경계를 넘나들며 한 픽셀이 주변보다 훨씬 밝아지는 순간이 생기고, 블룸이 그것을 둥근 빛으로 키운다.
