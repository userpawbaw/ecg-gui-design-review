# A·B TUNE 항목 — 무엇을 왜 고칠 것인가

> 2026-10-04 보완: [첨부 빛/모델링 검토](ECG_light_modeling_review_2026-10-04.md)와 [후보별 조명 씬 명세](ECG_ABC_lighting_scene_spec_2026-10-04.md)를 함께 적용한다. 기존 본문은 보존하며, 새 장면·자세 제안은 실제 렌더 검증 및 사용자 선택 전이다.

2026-10-03 · 사용자 추가 피드백 반영 · **수정 제안이며 제작 순위/전체 구현 확정이 아님**

A의 아이디어 발전과 별도 파형 아이디어를 좋게 평가한 것은 KEEP 요소다. A 전체의 TUNE 판정을 해제한 것은 아니다. B도 공간감을 유지하면서 근거와 구도를 고친다. 아래에서 **반영 확정**은 사용자가 이번에 직접 요구한 문서/규칙 수정, **제안**은 제가 권하는 화면 변경, **제작 후 판정**은 실제 결과가 있어야 결정할 사항이다. 기존 피드백 분석/대조는 수락·종료 상태를 유지한다.

## A안: 우주에서 한 사람의 심전도까지

| ID / 대상 | 현재 고칠 점 | 구체적 수정 제안 | 상태 / 확인할 장면 |
|---|---|---|---|
| **A-T1 / A0–A2 지구** | Moto의 핵심은 구체적인 지형·역광·회전인데, 우리가 종전 구현에서 확보한 수준은 부족했다. 시나리오 수치만으로 품질을 보장할 수 없다 | 남극과 해안선이 읽히는 고해상도 지구·대기·구름을 조달하고, **정면·역광·극 측면 3구도**를 먼저 시험. 대륙을 과장한 요철은 지리적 사실 표현보다 조형 품질 기준으로 취급. 실시간 품질이 모자라면 이 구간만 사전 렌더로 전환 | **제안 / 제작 후 판정.** 원본과 같은 조명 방향·화면 점유율로 나란히 비교. 단순 색보정으로 통과시키지 않음 |
| **A-T2 / A2–A5 장소 연결** | 구름/창을 넣어도 ‘왜 지구를 보여 줬는지’가 저절로 해소되지는 않는다. 궤도→서고는 천문학적 연속 확대가 아님 | 지구에서 고른 한 빛점을 구름 중앙의 빛길, 지붕 고창, 서고의 햇빛으로 계속 추적. 구름 통과 중 숨긴 컷으로 거리를 압축하는 **영화적 접근**이라고 명시. 각 프레임마다 다음 목적지를 미리 노출 | **제안.** A2/A3/A4에 목표점과 목적지의 위치를 겹쳐 검토. 목적지를 글로 설명해야만 찾을 수 있으면 컷/표식 수정 |
| **A-T3 / A0–A7 도입 템포** | 아름다운 지구·구름·방을 오래 보여 주면 ECG가 늦게 나타난다 | 첫 프레임 제목 `심전도 잡음 제거` 유지. A3과 A4는 한 번의 하강으로 묶고, A5에서 전극→기록 장치를 즉시 보여 줌. 보통 스크롤 예비 목표: **지구 3–4초, 하강/장소 4–5초, 사람/심장 3–4초**. 이는 원본 측정값이 아닌 시험용 목표이며 빠른 입력을 강제로 지연시키지 않음 | **제안.** 10–13초 전후에 심장·입력 신호까지 도달하는 경로 영상으로 비교. 천천히 보는 사용자의 박동 재생은 계속 유지 |
| **A-T4 / A5–A6 인체** | 낮은 품질의 플라스틱 마네킹과 불명확한 손은 지구 품질이 좋아져도 전체를 떨어뜨린다 | 저장소의 H5 고리+젖빛 면/얼굴 없는 머리/승인된 원본 메시를 기준으로 유지. 몸속을 플라스틱 덩어리로 채우지 않고 외곽과 가슴의 빛으로 형태를 읽게 함. **3전극**과 오른쪽 허리 리드 묶음, 사다리를 감싼 손을 같은 구도에 배치 | **기존 승인 반영 + 제작 후 판정.** A5를 정면/3⁄4/역광으로 검토. 손가락이 사다리에 닿고 몸·선·심장이 서로 가리지 않아야 함 |
| **A-T5 / A7–A8 파형 전환** | 동일 좌표 투명도 교차만 고정하면 사용자가 원한 스펙터클을 스스로 제한한다 | **추천: 잡음 리본 → 표본 입자 → 디지털 배열 → 출력 리본.** A의 오른쪽 그래프 앞에서 입력 선이 작은 밝은 조각으로 풀리고, 뒤쪽 처리 면으로 정렬됐다가 청록 출력으로 재결합. 원본 모양을 잠시 왜곡해도 됨. 대안은 ① 격자면이 접혀 처리층을 드러냄 ② 파형을 깊이 방향으로 분리한 뒤 잡음층만 밀어냄 | **자유도 변경은 반영 확정, 연출은 제안.** 3개 전환의 전·중·후 프레임으로 선택. 기본 페이드를 자동 확정하지 않음 |
| **A-T6 / A7 글자·그래프** | 2D 제목/격자가 공간 속 심장과 따로 놓일 위험. 의도 없는 라벨로 되돌아갈 수 있다 | `잡음이 섞인 심전도`를 62–74px 2행으로 오른쪽 상단 면에, 보조 INPUT/0dB를 16–18px로 분리. 그래프 면은 뒤에서 비스듬히 들어와 박동 관찰 위치에서 멈춤. 3D 전환에서는 격자가 표본 배열로 이어지게 함 | **제안.** 파형·제목·심장의 크기 위계와 등장 순서를 정지 프레임에서 먼저 확인. 격자 대비는 선을 묻히지 않게 조정 |
| **A-T7 / Story 3장** | 전원/호흡/주먹을 매번 같은 카메라 왕복+페이드로 반복하면 지루하다 | 같은 서고는 유지하되 PLI는 **플러그→전원선→리드 경로**, BW는 **흉곽 옆 곡면→느린 기저면**, EMG는 **손·전완 클로즈업→시간 구간별 붉은 입자**로 원인 연출을 다르게. 출력 도착은 공통 처리 문법을 짧게 재사용 | **제안.** 각 장의 원인과 첫 프레임 실루엣이 글 없이 구별되는지 검토. 기존 저품질 Story는 재사용 기준으로 삼지 않음 |

### A에서 먼저 수정할 순서

1. **문서:** A-T2 장소 경로와 A-T3 템포 → A-T5 전환 선택지. 이 문서가 v2 A의 수정 명세다.
2. **최종 피드백 이후 목업:** A0 지구 / A3–A4 한 하강 / A5 사람 / A8 변환 중간.
3. **제작:** A-T1 지구·A-T4 인체의 별도 품질 시험 → A-T2 연결 영상 → A-T5 전환 → A-T7 Story.

지구를 삭제하는 안을 지금 확정하지 않는다. 연결 실패가 반복되면 A 안에서 도입 길이를 줄이는 수정부터 하고, 지구 없는 다른 안과의 우선순위 판단은 별도 후보 선택 기록으로 남긴다.

## B안: 기록물이 입체 공간을 연다

| ID / 대상 | 현재 고칠 점 | 구체적 수정과 제안 | 상태 / 확인할 장면 |
|---|---|---|---|
| **B-T1 / 레퍼런스 귀속** | Editorial New에서 3D 옆면/틈 진입을 봤다는 근거가 없다 | 원본은 2D 회전·크기·가변 글꼴, **입체 기록물과 카메라 진입은 독자 확장**이라고 정정. Storybook도 종이 팝업이 아닌 같은 3D 공간의 카메라 연속성 근거로 사용 | **반영 확정·완료.** [B 상세판](ECG_B_scene_spec_v3_2026-10-03.md) §1 |
| **B-T2 / B0–B9 프레임** | A와 달리 공유된 실제 시안이 없으므로 짧은 묘사로는 동일 화면을 상상하기 어렵다 | 1920×1080에서 물체 중심·크기·접힘 구조·깊이·빛·타이포·카메라·시작/도착·정지 중 움직임을 명시. 전환의 원인도 각 씬에 기록 | **반영 확정·초안 완료.** 특히 B1/B2/B3/B6 이미지 기준으로 검토 |
| **B-T3 / B1–B3 접힘** | 종이가 얇은 이미지, 두꺼운 플라스틱 책, 장식 문처럼 보일 수 있다 | 아코디언 3면의 종이를 주 무대로 하고, 옆면의 가는 층과 산/골접힘의 그림자를 명확히. 모든 면을 한꺼번에 움직이지 않고 **외곽 회전→가운데 틈 열림→틈 진입** 3단계로 나눔 | **제안.** B1–B3 한 영상으로 종이의 앞/뒤/안쪽이 계속 구별되는지 확인 |

| **B-T7 / Story 장 넘김** | 세 장의 종이 넘김이 매번 공간을 초기화하면 원인과 처리의 연결이 끊긴다 | 전원·호흡·근육은 **같은 내부 무대의 서로 다른 관찰 방향**. 장 이름의 접힌 탭만 전경에 지나가고, 컴퓨터·인체·배선 위치는 유지. 전원 파트는 확대했던 플러그가 다음 원경에도 있어야 함 | **제안.** 왕복/역스크롤에서 소품 위치 보존, 장별 카메라 시작점 지도 확인 |

### B에서 먼저 수정할 순서

1. **문서:** B-T1 근거 정정 → B-T2 프레임 구체화(현재 초안) → 사용자 피드백.
2. **최종 피드백 이후 목업:** B1 옆면 / B2 틈의 인체 / B3 진입 / B6 처리층.
3. **제작:** B-T3·B-T4 종이 물성+스케일 예비 영상 → B-T5 디지털 전환 → B-T6 글자 → B-T7 3장.

## 공통이지만 별도 관리할 TUNE

- **SYS-01:** Intro/Story 변형·입자·3D 허용은 모든 안에 적용. 비교 패널만 정확한 데이터 렌더를 필수로 한다.
- **VAL-01:** 목업만으로 운동 품질 합격을 선언하지 않는다. 제작 영상에서 정지/역방향/빠른 입력/재진입 결함을 새 검증 항목으로 추가한다.
- **I4 신규 아이디어:** 실제 씬 캡처 피드백 뒤, 그 씬의 부족을 해결하는 연출 2–3개를 계속 제안한다. 이미 만족한 파형의 밝기·sweep·잔광은 바꾸기 전 유지 항목으로 기록한다.

**현재 판정:** A=TUNE, B=TUNE, C=신규 검토안. TUNE은 위 수정 목록의 이행과 화면 확인을 요구하는 상태이며, 특정 후보의 기각 또는 전체 구현 승인을 뜻하지 않는다. 세 안의 제작 순위는 다음 사용자 검토에서 정한다.
