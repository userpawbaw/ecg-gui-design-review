# D-172 서고 배경 경량화 — 이전/새 동작 A/B (2026-11-11)

같은 빌드에서 끄기 스위치(`livebg=live&bgmove=full&bgmask=0&bgidle=0` = 이전 동작)와 새 동작을 같은 시나리오로 비교했다.
`node measure.cjs .` (개발 서버 5179, 960 × 540, `?bgprof=1&bgsoft=0`) · `node compare.cjs`.

**환경 주의**: 이 환경은 GPU가 없는 소프트웨어 렌더(SwiftShader)다. 시간은 절대값이 아니라 **같은 기계에서의 상대 비교**로만 읽는다. 시간 = 한 번 그린 뒤 1픽셀 읽기로 GPU 완료를 기다린 누적값.

- 실험실 스크롤 · 포인터 구간의 **총 시간**은 비슷하다. 소프트웨어 렌더에서는 GPU가 늘 포화라 프레임이 가벼워진 만큼 더 자주 그렸기 때문이다(초당 프레임 상승). 사용자 PC에서는 같은 프레임률에서 GPU 여유로 나타난다.
- 스크롤이 끝난 뒤 원래 품질로 다시 그린 횟수: 1회(`full`). 움직이는 동안은 반 해상도(`low`).
- 실험실 맨 위(배경 구간 시작)의 커튼 밝기 0.12 > 문턱 0.02 → 커튼 결 흐름 유지(정상). 아래쪽 어두운 자리의 판정은 사용자 PC 확인 항목.
