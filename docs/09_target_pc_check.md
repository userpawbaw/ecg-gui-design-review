# 목표 PC에서 이어서 확인하기

완료된 GUI를 실제 브라우저에서 검수하는 실행 순서다. 이 안내를 작성한 것이 검사 완료 증거는 아니다. 아래 항목은 현재 모두 **미검증**이며 PC에서 관찰한 뒤 결과를 기록한다.

## 1. 지금 시작하는 지점

원본 분석·독립안 동결·기존안 비교·최종 GUI·팀 설명서·자동 검증은 완료됐다. 진행 바 중단 후에도 최종 44개 파일과 배포 HTML의 해시가 보존됨을 확인했다. 제작 코드를 다시 시작할 필요가 없다.

이어갈 부분은 **실제 화면의 가독성, 포인터/키보드 동작, 다운로드**다. 이 작업 환경에서는 local file/localhost 접근이 막혀 실행하지 못했다. 데이터 재생성과 실제 AFE 연결은 그다음의 별도 단계다.

후속 감사 중 단일 HTML 끝부분 27,329 bytes가 잘린 상태를 발견했다. 원인은 확정하지 못했다. 손상본을 백업하고 온전한 ZIP에서 복원해 원래 hash와 배포 검사 6개를 다시 통과했다. 아래 작업에는 **갱신된 ZIP을 다운로드해 압축을 푼 파일**을 사용한다. GitHub의 원본 코드와 데이터는 손상되지 않았다.

- 검수 파일: `ecg-signal-studio.html`
- 구현 기준 commit: `4a99f30f0b6b108f0e5b61a11c3f6e62b82a67f8`
- HTML SHA-256: `f14296bc03d2c725bc5940df7fcca5e0e856fd376d8124f79a1558ed262ee5a2`
- 이 안내를 추가하면서 GUI 코드는 변경하지 않았다.

## 2. 시작 준비

1. 단일 HTML을 PC에 다운로드한다. ZIP이면 먼저 압축을 푼다.
2. 데스크톱 브라우저에서 파일을 연다. GitHub 소스 페이지는 실행 화면이 아니다. Node 설치는 필요 없다.
3. 브라우저 zoom을 100%로 맞추고 창을 최대화한다. OS, 브라우저 이름·버전, 해상도, Windows 표시 배율을 기록한다.
4. 새로고침하면 시작 조건으로 초기화된다. 검토 메모는 새로고침 전에 JSON으로 내보낸다.

시작 조건: 실험실 / D1 / 혼합 잡음 / 주입10 dB / MIT-BIH111 / 선택 M08 / 비교 M04 / 구간3.00–4.20초 / ±2 mV. 커서는 자동으로 움직이지 않는다.

## 4. 처음 전달할 자료

우선 **기본 화면, 구간 확대, Replay 유실 상태의 3장과 검토 JSON**이면 첫 시각·상태 검토를 시작할 수 있다. 화면을 본 실제 배율을 적는다. 전체 근거·dialog 문제가 있으면 해당 캡처도 추가한다.

캡처는 화면이 보인다는 증거이며 키보드·모션·오프라인 통과를 증명하지는 않는다. 해당 항목은 직접 한 조작과 결과를 별도로 적는다.

## 5. 결과 기록 양식

아래 내용을 복사해 채팅이나 Markdown으로 작성한다. 확인하지 않은 항목은 NV를 유지한다.

```text
검수자 / 날짜:
OS:
브라우저 / 버전:
해상도 / Windows 표시 배율 / 브라우저 zoom:
파일: ecg-signal-studio.html / 기준 4a99f30

Q01 기본 화면: NV
Q02 SNR 왕복: NV
Q03 hover·선택: NV
Q04 구간 확대: NV
Q05 전체 근거·복귀: NV
Q06 계측·Replay: NV
Q07 키보드·dialog: NV
Q08 실제 JSON 저장: NV
Q09 배율·모션: NV
Q10 오프라인: NV

문제 ID / 구성요소:
재현 순서:
기대 동작:
실제 동작:
첨부 캡처·영상·JSON:
```

PASS는 조작과 관찰을 완료했을 때, FAIL은 기대와 다른 결과를 재현했을 때 사용한다. 불분명하거나 실행하지 못했으면 NV다. 실제 장치 검사는 이 양식으로 통과시키지 않는다.

## 6. 자료를 받은 뒤 할 일

출처·상태 오인과 잘못된 수치(P0), 핵심 조작 불능(P1), 가독성·배치(P2) 순서로 문제를 정리한다. 구성요소와 수정 위치는 [팀 가이드](06_team_guide.md)에 연결한다. 필요한 부분을 수정하고 영향받은 검사만 실행한 뒤 같은 PC 조건에서 다시 확인한다.

화면 검수가 끝나면 [검증 보고서](07_verification.md)의 데이터·장치 게이트로 진행한다. 현재 코드로 bank 재생성, annotation metadata, 기존 bridge 연동은 실제 실행 증거가 있을 때 완료 처리한다.
