## 1. 목표

**심전도 파형을 보여 주는 방식 자체**의 참신한 연출 후보를 찾아, 우리 분석 문법(효과 카드 + 공동 구상 선택지)으로 정리한다. 발행 세션은 결과를 받아 IDEA-R1-WAVE 보드와 구현으로 이어 간다.

지금 구현된 것(겹치지 않게): 2.5 s sweep + 잔광 + 지우는 쪽 국소 페이드, 심전도 용지 격자(번짐·머리 뒤 격자 잔광), R 피크마다 4분의 1씩 잡음 → 저장 출력 교차, 두 층 라벨, R 주석, 층 시차 등장. 보류: T3 초점 렌즈(마우스 위치만 깨끗).

탐색 방향(예시 — 사용자와 조정):
- 파형·신호를 주인공으로 한 수상작(Awwwards, Godly, FWA, CSS Design Awards)
- 오실로스코프·지진계·오디오 파형·주가·생체 신호(심박·수면·뇌파) 시각화의 연출
- 3D 리본·깊이 쌓기·시간 축을 공간으로 바꾸는 표현, 물리 기반 잔상, 파형이 글자·형태와 결합하는 표현
- 과학 시각화 사이트(중력파·전파천문 등)에서 신호를 보여 주는 방식

목표 분량: 후보 6–10개를 훑고 → 사용자와 3–5개를 골라 → 효과 카드로 분석 → 선택지 행으로 번안.

## 2. 사용자 참여 지점 (D-039 공동 구상)

1. 후보 목록(사이트명·URL·보는 법·한 줄 요지)을 먼저 보여 주고 사용자가 고른다.
2. 분석한 효과마다 "우리 파형에 옮기면" 선택지 2–4개(하나는 과감하게)를 내고 사용자 반응을 받는다.
3. 사용자 반응을 원문 인용으로 남긴다. 자동 진행(대리 판단)으로 건너뛰지 않는다.

## 3. 확보 방법 (R-016)

- DOM·SVG·Canvas 2D 사이트: curl로 HTML·JS·CSS·필요 자료를 받아 **작업 공간 밖(scratch)**에서 로컬로 띄우고, 제3자 요청을 차단한 헤드리스 캡처(구간마다 최소 6장, 권장 12장). 인증서 검사를 끄는 옵션은 쓰지 않는다.
- WebGL·영상·실제 휠 감각이 핵심인 사이트: 사용자에게 녹화를 요청(`tools/reference-capture/README.md` 촬영 규칙 D-017, 필요하면 `capture-site.mjs`를 사용자 PC에서 실행).
- **사이트의 코드·에셋·캡처는 저장소에 커밋하지 않는다.** 수치·구조·짧은 인용만 기록.

## 4. 산출물과 파일 소유 범위 (충돌 방지)

| 파일 | 탐색 세션 | 발행 세션 |
|---|---|---|
| `docs/uiux_system/references/REF-011_*.md` ~ `REF-019_*.md` | **새로 작성**(이 번호 대역만 사용) | 읽기만 |
| `docs/uiux_system/rounds/R1/EXPLORE-WAVE-DISPLAY.md` | **새로 작성** — 후보 목록, 사용자 선택·반응 인용, 선택지 행(IDEA 보드 형식: 보는 것 / 만드는 법 / 위험, ★ 추천 한 줄), 발행 세션에 넘길 기록 초안 | 병합 후 IDEA-R1-WAVE로 옮김 |
| `prototype/spikes/wave-explore/` | 선택 — 작은 독립 spike만 | 읽기만 |
| `docs/uiux_system/references/README.md` 색인, F/D/O/R 기록, PLAN·WORKLOG·WORK_STATE, `prototype/v2/src/**` | **수정하지 않음** — 필요한 색인 행·기록 초안은 EXPLORE 문서 끝에 적는다 | 병합 때 반영 |

기록 번호가 두 세션에서 겹치지 않도록 탐색 세션은 F/D/O/R을 만들지 않는다(초안만). 레시피 번호는 `RCP-40`부터 쓴다.

## 5. 데이터 계약 (모든 선택지에 적용)

- 파형 꼭짓점은 저장값(시간·진폭 변형 금지). 발광·흐림·색은 스타일 층.
- 시간·진폭 눈금은 파형과 같은 층에서 함께 움직인다.
- 장식 곡선을 데이터처럼 보이게 하지 않는다(가짜 실시간 금지).
- 수치는 저장값, 등장 효과가 숫자를 지어내지 않는다.
- 선택지마다 "계약 위험" 칸에 위 항목과의 충돌 여부를 적는다.

## 6. 완료 기준

- 효과 카드 파일이 `npm run records:check`를 통과한다(루트 `npm test`에도 포함).
- EXPLORE 문서에 사용자 선택·반응 인용과 선택지 행이 있다.
- 커밋·푸시하고 원격 반영을 확인한다(커밋 메시지는 저장소 규칙대로).
- 마지막에 사용자에게 한국어 요약 + 브랜치 이름을 알린다. 사용자가 발행 세션에 "탐색 브랜치 병합"을 요청하면 발행 세션이 가져간다.
