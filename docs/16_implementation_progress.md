## R2 완료 및 R3 구현

- 2026-09-12: 손상 1조건과 미완성 46조건을 생성하여 98조건 완료. 원본 112자산 해시도 재확인했다. 학습은 실행하지 않았다.
- 98×600초, 150,000samples/조건, 1,274 trace arrays, 1,078 처리 출력 지표 검증. 1,960개의 30초 청크를 재결합하면 원 인코딩과 byte-identical이다. 지표 tolerance는 SNR 0.05dB, CC 0.001, RMSE 0.001mV, α 0.01; 모두 PASS.
- 패키징 첫 시도는 마지막 D0 파일 생성 완료 전에 시작되어 필수 파일 누락 검사에서 중단되었다. D0/D1 각각 49조건 완료 후 패키징을 다시 실행해 전체 PASS를 확인했다. 미완성 manifest를 완성본으로 사용하지 않았다.
- 앱은 이전/현재/다음 30초 구간을 로딩하고 9개 청크 캐시 상한을 둔다. SHA-256 및 byte length 확인 후 사용한다. Session 수치는 전체 600초에 대해 미리 검증한 값을 사용한다. Local은 현재 고정 sample interval을 사용한다.
- 추가 테스트: 30초/60초/300초/600초 경계의 청크 출력이 원 자료와 일치하고 변조 hash는 거부됨. Attract의 10초 범위 반복 및 같은 시각 인계 검증. 엔진/청크/Attract 합계 11개 PASS.
- 운영 기능: 고정 조건의 10–20초 시나리오 A/B/C, 개인 북마크, 명시적인 Attract 구간 반복과 인계, opt-in idle 안내, 표시 구간/북마크 timeline을 구현했다. 시나리오 구간은 고정 규칙으로 선정하고 input/Reference의 유한값·비평탄 조건을 확인했다. 출력 우세를 기준으로 고르지 않았다.
- 새 조건 성공 후 자동 재개는 유지된 사용자 재생 의도에 따르며, 중간 Pause/구간 고정/seek가 취소할 수 있다. 표시 범위를 벗어나는 샘플 수를 경고한다.
