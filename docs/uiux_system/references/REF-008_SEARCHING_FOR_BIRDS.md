## 6. 효과 카드

### EFX-008-01 고정 차트 + 지나가는 단계 카드 + 차트 안 강조 띠

**선정 이유**: 사용자 요청(글자와 시각 데이터의 배치 연구) `[대화]`, 재사용 메커니즘 — 데이터 화면을 움직이지 않고 설명만 흘려보내는 방식.
**지각**: 차트는 화면에 고정돼 있고, 설명 카드가 아래에서 올라와 차트 위를 지나간다. 카드가 가운데를 지날 때 차트 안의 해당 구간(예: 매년 4–5월 세로 띠, 2020–21년 구간)이 옅은 색으로 강조된다. 카드와 차트가 같은 이야기를 동시에 가리킨다.
**입력 모델**: 문턱 발동(scrollama 단계가 화면 50–75 % 선을 넘을 때).
**판별 근거**: `#scroll-dataviz-seasonality {position: sticky; top: 0}`, scrollama `onStepEnter` 4곳, offset 0.5/0.7/0.75, 강조는 d3로 `.pandemic-box` 사각형 추가 `[코드]`. 캡처 18–20에서 카드와 띠가 함께 바뀜 `[캡처]`.
**구현 메커니즘**:
```
<section> 안에 sticky 시각물(높이 100vh) + 그 뒤로 흐르는 단계 카드들(각 카드 사이 여백 수십 vh)
scrollama({step: '.step', offset: .7}).onStepEnter(({index}) => highlight(index))
highlight: d3로 강조 사각형(띠)의 x 범위·opacity를 전환, 카드 소제목 색 = 강조색
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 발동선 | 화면 높이 0.5 / 0.7 / 0.75 | `[코드]` |
| 고정 | sticky top 0(또는 2vw) | `[코드]` |
| 카드 폭 | 약 390 px(1600 폭 기준 화면 가운데) | `[캡처]` |
| 강조 띠 | 옅은 살구색 세로 사각형, 해당 기간 폭 | `[캡처]` |
**타임라인**: 카드가 발동선을 넘으면 강조 전환(d3 transition), 카드는 스크롤과 같은 속도로 지나감.
**에셋**: 없음(SVG).
**성능 기법**: 시각물은 고정, 강조 사각형만 갱신.
**접근성·폴백**: 카드 텍스트가 곧 설명(스크린 리더 순서 유지). reduced-motion 별도 처리 미확인 — 미확인, 코드에서 찾지 못함 `[코드]`.
**근거**: `[코드]`, `[캡처]`.
**재현 요구사항**: sticky + IntersectionObserver(또는 scrollama) + 차트 안 강조 층. 난이도 하.
**수용 기준**: (1) 카드가 발동선을 넘는 프레임에 강조가 바뀐다. (2) 차트는 스크롤 중 움직이지 않는다.
**ECG 번안**: 파형 무대를 고정해 두고, 설명("잡음이 섞인 입력", "R 피크", "잡음 제거 출력")을 카드로 흘려보낸다. 카드가 가리키는 구간(예: R 피크 주변 0.1 s, 잡음이 가장 큰 구간)을 파형 안의 옅은 세로 띠로 강조 — 띠는 시간축 위치가 정확해야 한다(저장값의 실제 시각).
**재현 상태**: `none`

### EFX-008-02 데이터에 붙는 주석: 사건 점선 + 기울임 주석 + 화면 끝까지 이어지는 곡선

**선정 이유**: 사용자 요청(글자·시각 데이터 배치) `[대화]`, 우리 라벨이 "덩그러니" 떠 있는 문제의 직접 대안.
**지각**: 차트 제목은 가운데 위에 짧게, 부제는 작은 기울임체. 곡선이 치솟는 바로 그 시점에 점선 세로선이 내려오고, 그 옆에 기울임체 두 줄 주석이 붙는다. 곡선은 축 영역을 벗어나 화면 양끝까지 이어져 차트가 페이지의 일부처럼 보이고, 삽화가 곡선 위에 앉아 있다.
**입력 모델**: 스크롤 위치(정적 배치, 스크롤로 지나감).
**판별 근거**: 캡처 01(1600×900): 제목 "Search Interest for 'Snowy Owl'", 부제 "in New York City", 점선 x = 사건 시점, 주석이 점선 오른쪽 20 px에서 시작, 곡선이 x = 0과 x = 1600까지 이어짐 `[캡처]`.
**구현 메커니즘**:
```
축 안: 실제 데이터 구간(눈금·값 축 있음)
축 밖: 같은 곡선을 연한 선으로 화면 끝까지 연장(장식 — 값 축 없음)
사건: 점선 세로선(x = 사건 시각) + 주석 텍스트 anchor start, 곡선 최고점과 같은 높이
제목: 가운데, 굵은 serif / 부제: 기울임, 옅은 색, 작은 크기
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 주석 글자 | 기울임 serif 약 13 px, 2줄, 옅은 갈색 | `[캡처]` |
| 제목:부제 크기 | 약 16 : 11 px | `[캡처]` |
| 점선 | 1 px 회색 점선, 차트 전체 높이 | `[캡처]` |
**타임라인**: 정적.
**에셋**: 삽화 PNG(올빼미).
**성능 기법**: 정적 SVG.
**접근성·폴백**: 주석이 본문 문장과 같은 내용을 반복 — 미확인, 대체 텍스트 구조는 확인하지 않음 `[추론]`.
**근거**: `[캡처]`.
**재현 요구사항**: 차트 좌표계에 주석 배치. 난이도 하.
**수용 기준**: 주석·점선의 x가 사건 시각과 1 px 이내.
**ECG 번안**: 라벨을 파형 밖 왼쪽 위에 따로 두지 않고 **파형 안의 사건에 붙인다** — 예: 첫 R 피크 위에 점선 + "R 피크 · 심장이 수축하는 순간", 잡음 구간 옆에 "백색 잡음 0 dB". 단, 곡선을 화면 끝까지 연장하는 장식은 **하지 않는다**(파형은 저장값의 실제 구간만 — ECG 계약). 대신 격자·시간 눈금을 화면 끝까지 이어 페이지와 한 몸처럼 보이게 할 수 있다.
**재현 상태**: `none`


### EFX-008-03 여러 파형을 한 판에: 가는 반투명 곡선 + 점선 가로 격자 + 반복 구간 세로 띠 (격자 비교용)

**선정 이유**: 사용자 요청(2026-09-30) — "birds 사이트의 파형 효과는 참조할 레퍼런스로 기록해놓을까? 이 파트가 아니더라도, 이후 격자 비교에서 유용할 수도 있잖아?" `[대화]`. 우리 도입부 격자(G3, 심전도 용지)와 **다른 격자 문법**의 기준 사례로 둔다.
**지각**: 새 50종의 주간 검색량이 가는 곡선으로 한 판에 겹쳐 있다. 곡선마다 색이 다르고 반투명이라 겹친 곳이 진해지며 "물결"로 읽힌다. 가로 격자는 옅은 점선 몇 줄뿐이고 세로 격자는 없다 — 대신 매년 4–5월 구간이 옅은 살구색 세로 띠로 반복돼 계절 리듬이 보인다. 띠 하나에 세로로 눕힌 기울임 글씨("April & May")가 붙어 있다. y축 제목은 세로로 눕히고 괄호 속 작은 보조 설명을 단다. 아래에 기울임체 각주("Lines normalized to …").
**입력 모델**: 스크롤 위치(정적 차트가 sticky로 고정되고, 단계 카드가 지나감 — EFX-008-01).
**판별 근거**: 캡처 19–20(1600×900): 가로 점선 격자 7줄(0–120, 20 간격), 세로 격자 없음, 연도 눈금만, 세로 띠 10개(연 1개), 곡선 50개 약 1.5 px 반투명 `[캡처]`. d3 SVG 경로·`.pandemic-box` 사각형 `[코드]`.
**구현 메커니즘**:
```
x: 시간(연 눈금만), y: 정규화 값(0–120, 20 간격 점선 가로선 1 px)
곡선: 계열마다 d3 line + 평활, stroke 1.5 px, opacity ≈ .6–.8, 계열별 색
반복 구간: 매년 같은 기간을 옅은 사각형(opacity ≈ .3)으로 — 격자 대신 "의미 있는 세로 구획"
라벨: 띠 하나에 rotate(−90°) 기울임 글씨, y축 제목 rotate(−90°) + 괄호 보조 설명, 차트 아래 기울임 각주(정규화·평활 명시)
```
**파라미터**:
| 이름 | 값 | 출처 |
|---|---|---|
| 가로 격자 | 점선 1 px, 7줄 | `[캡처]` |
| 세로 구획 | 연 1회 4–5월 띠, 옅은 살구색 | `[캡처]` |
| 곡선 | 50개, 약 1.5 px, 반투명 | `[캡처]` |
| 각주 | 기울임 약 11 px — 정규화·평활을 밝힘 | `[캡처]` |
**타임라인**: 정적(강조 띠만 단계 카드에 반응).
**에셋**: 없음(SVG).
**성능 기법**: 정적 SVG 50경로.
**접근성·폴백**: 각주가 데이터 가공(정규화·평활)을 명시 `[캡처]`.
**근거**: `[캡처]`, `[코드]`, `[대화]`.
**재현 요구사항**: SVG/캔버스 다중 경로 + 반복 구간 띠. 난이도 하.
**수용 기준**: 가로 점선 격자와 세로 의미 구획이 겹치지 않고 읽힌다, 각주에 데이터 가공이 적혀 있다.
**ECG 번안**: 격자 비교의 두 번째 안 — **심전도 용지 격자(G3, 물리 단위 정사각형)** 대 **최소 가로 점선 + 의미 구획 띠**(예: R–R 간격마다 옅은 세로 띠, 또는 QRS 구간 띠). 여러 방법의 출력(Lab·잡음별 장면)을 한 판에 겹칠 때는 이 문법(가는 반투명 곡선 + 계열 색)이 맞다. 단, 우리 파형은 평활하지 않는다 — 저장값 그대로(각주에 "저장값 · 250 Hz"를 밝히는 방식은 가져옴).
**재현 상태**: `none`

## 10. 열린 질문

- 전시 화면(키오스크)에서는 긴 본문이 없으므로, 카드 대신 짧은 한 줄 주석으로 줄여야 한다.
