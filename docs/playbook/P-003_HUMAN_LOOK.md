# P-003. 사람의 겉모습(표현 양식·머리·원본 메시)을 정할 때 — 품질 문제를 양식으로 피하지 않고, 실제로 쓸 자세에서 비교해 고른다

| | |
|---|---|
| 상태 | 유효 |
| 언제 읽나 | 사람이 "어색하다·불쾌하다·플라스틱 같다"는 반응을 받았을 때, 사람 표현 양식(고리·반투명·점 구름·실사)을 고를 때, 머리·얼굴을 다시 만들 때, 원본 사람 메시를 고를 때 |
| 도달 수준 | H5(젖빛 반투명 면 + 은은한 고리) + 원본 A 메시 + 마네킹 머리 B2 — 서고 거리 형태, 앉은 자세, 주먹 실루엣이 읽힘, 사용자 확정("얼굴은 괜찮아", "권장안으로 진행") `[대화]`. 증거 `verification/r1-archive-20261001/look/compare_h3b_vs_h5.jpg`, `verification/r1-head-20261004/head_B_variants.jpg` |
| 근거 여정 | J-001 T1–T5, T7, T11, T16 |
| 강제 장치 | `scripts/assets/slice-field-v3.py` (고리 값의 국소 극값 수·기울기 출력), 겉모습의 적합성은 수동 — 사람 판단이라 비교 시트 절차만 둔다 |
| 갱신 | 2026-10-09 (고리 값) |

## 권장 방법
1. 사람에 대한 불만을 받으면 먼저 **층을 나눈다**: 표현 양식 / 메시 형태(머리·손·비율) / 자세 / 골격·가중치. 사용자가 말한 층을 고치고, 다른 층으로 바꿔치기하지 않는다. 바꿔치기를 제안하려면 그렇게 보고한다(R-018).
2. 표현 양식 후보는 **서 있는 기본 자세가 아니라 실제로 쓸 자세**(앉기, 쥔 손, 주먹)에서 같은 카메라로 정지 렌더 비교 시트를 만든다. 예: `build_archive.py --look h3b|h5 --shots s3_aisle,s4_person,s6_grip`.
3. 지금 권장은 **H5**(젖빛 반투명 면 + 은은한 고리 42/m)다. 고리만 있는 몸은 가림이 없어 손·주먹이 엉킨다.
4. 고리 값(`_SLICE`)은 `slice-field-v3.py`로 만든다. 정수리에서 시작하는 한 나무 위에서 계산하고, 관절 영역은 조화 함수로 채운다. 리그·메시를 바꾸면 다시 돌리고, 출력되는 국소 극값 수와 기울기 상위 0.1 %를 확인한다. 기준은 끝점(손끝·발끝·정수리) 외 극값 20개 이하(2026-10-09: 16개, 모두 정점 하나짜리), 기울기 3 이하(2.07)다.
5. 원본 메시는 손가락 다섯 개가 온전한 CC0 사람 메시에서 고른다(현재 Blender Studio Human Base Meshes realistic = A). 후보를 같은 자세로 나란히 렌더해 사용자가 고른다. AI 추천과 사용자 선택이 다르면 둘 다 기록한다.
6. 머리는 원본 머리에서 **부피 방식**으로 이목구비만 지운다(`scripts/assets/head-vol-v3.py`): 2 mm 격자 부호 거리 → 닫기 → 열기(귀) → 얼굴 흐림 → 메시. 여러 단계(B1–B3)를 렌더해 이마·광대·턱 면이 남는 단계를 고른다.

## 도달한 품질
- 형태: H5는 서고 거리에서 몸 형태가 면으로 읽히고 심장 빛이 비친다. 앉은 자세와 주먹 실루엣도 읽힌다(J-001 T4, T11).
- 머리: B2는 이목구비 없이 사람 머리 면이 남아 사용자가 받아들였다(J-001 T7).
- 이 카드가 보장하지 않는 것: 자세의 자연스러움과 피부(P-001, P-004).

## 가지 말 길
- **덜 만든 실사 몸을 가장자리 빛으로만 보이기** — 눈 점·입 구멍·벌린 손이 불쾌한 골짜기를 만들었다(J-001 T1).
- **메시 품질 요구를 셰이더 양식 교체로 대신하기** — 요구가 반영되지 않았고 한 라운드를 잃었다(O-007)(J-001 T2).
- **얼굴 정점을 타원체로 투영한 달걀 머리** — 이목구비와 함께 머리의 면까지 지워 "억지로 둥근 계란"이 됐다(J-001 T3).
- **머리 매끈하게 하기(Taubin·Laplacian)와 구면조화 반지름 맞춤** — 이목구비가 강해지거나, 입 안 구멍이 드러나거나, 부리·뿔이 생겼다(J-001 T7).
- **고리 밀도를 올려 고리만으로 손·주먹을 읽히게 하기** — 더 복잡해지기만 했다(J-001 T11).

## 틀린 길이라는 신호
- 사용자가 지적한 층과 다른 층을 고치고 있다. 예: 메시가 문제인데 셰이더를 고친다(J-001 T2).
- 비교 렌더를 서 있는 자세로만 했다. 앉으면 수평 고리가 용수철처럼 늘어진다(J-001 T4).
- 두 표현 모두 같은 부분(쥔 손)이 안 읽힌다. 원인은 표현이 아니라 메시나 자세다(J-001 T4).
- 문제를 "없애는" 처리(투영·평활)를 했는데 형태가 사람에서 멀어진다(J-001 T3, T7).
- 고리가 엉덩이·견갑골·가슴에서 동심원 섬으로 맺히거나 관절에서 물결친다. 피부 늘어남보다 먼저 고리 값의 끊김·극값을 의심한다(J-001 T16).

## 타협하면 안 되는 지점
- 골짜기 지적이 멈췄다고 끝이 아니다. 달걀 머리는 지적을 멈췄지만 사람 머리로 읽히지 않았다. 원본 머리에서 이목구비만 지운 B2는 그보다 높은 수준에 도달했다(J-001 T3, T7).
- 고리 몸은 "골짜기 없음"과 "주제 적합"은 만족했다. 하지만 메시·손 품질 요구는 남은 채였다. 그 뒤 H5 + 새 메시로 형태와 손을 모두 읽히게 했다(J-001 T2, T4).

## 적용 범위와 재검토 조건
- 범위: 얼굴 없는 "빛으로 된 사람" 연출. 실사 인물이 필요하면(H4) 이 카드가 맞지 않는다.
- 다시 열 조건: 빛·카메라가 크게 바뀌어 H5 면이 형태를 못 보여 줄 때, 마네킹 머리가 서고 거리에서 사람으로 읽히지 않을 때(B1로), 이목구비가 다시 보일 때(B3로)(D-051).
